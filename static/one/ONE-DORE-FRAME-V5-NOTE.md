# ONE Doré Frame v5 — reference review

Selected reference: the restrained brown classical book cover (reference 4 supplied on 2026-08-18).

Reason: it has the strongest bookbinding character with the least ornamental noise. It keeps a double-rule structure, reserves decoration for the four corners, and lets the central engraving remain dominant. The lighter corner-only reference is useful as a line-weight check, but is too incomplete as a full binding system. The fully ornamented cream and burgundy references are too decorative for ONE, while the blue rounded frame reads more like a modern decorative template.

Adaptation rule: use reference 4 as the structural source, reduce the foliage further, remove dimensional relief, keep the foil flat and slightly worn, and omit all center/side badges. The result must read as aged hot-stamped bookbinding rather than a picture frame.
