# ONE cover coexistence production roadmap

This file replaces the former all-chapter illustration-completion plan.

## Permanent cover rule

Every canonical chapter already has a complete presentation through one of two equally valid modes:

1. **Illustration cover** — an approved Doré original, explicit editorial reuse, or approved ONE Studio plate.
2. **Book cover** — the canonical antique-green binding, original raster gilt ornament, and centered book typography.

A chapter using book-cover mode is complete. It is never classified as missing, backlog, warning, failure, debt, placeholder, or publication blocker.

## Phase one: first chapters only

The first production phase may consider only first chapters that currently use book-cover mode. The exact live candidate list is generated by:

```text
node scripts/one-cover-mode-audit.mjs
```

Canonical output:

```text
audit-output/one-cover-modes.json#firstChapterCandidates
```

Do not expand phase one to later chapters merely to increase illustration counts.

## Editorial gates

An illustration candidate becomes an illustration cover only after all gates pass:

1. chapter-specific biblical theme is correct;
2. historical, geographical and material details are researched;
3. the composition and engraving stroke satisfy the Doré learning rules;
4. the human editor approves the exact image revision;
5. the binary asset is stored in GitHub and registered to the exact chapter;
6. the public route is visually verified.

Until all gates pass, the canonical book cover remains the finished public cover. No provisional image, fuzzy Doré match or batch-generated placeholder may replace it.

## Reconciliation

- After an approved illustration is published, verify only its exact chapter key and public route.
- Re-run the cover-mode audit to remove that first chapter from the candidate list.
- Never maintain or decrement an all-chapter debt counter.
- Preserve approved illustration provenance and do not overwrite a fixed plate without a new editorial decision.
