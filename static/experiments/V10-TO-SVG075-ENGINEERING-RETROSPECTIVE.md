## 根因與有效解法

可見的深色平行帶不是單一曲線角度不對，而是某些相鄰輪廓線在局部形成過密、重複的視覺節奏。持續對整組線施加高斯位移、曲率修正或角度變形，會移動問題，卻不一定消除問題。

最終有效的做法是**局部刪減線群，保留少量線條作為過渡**：

```js
const inFirstGap = progress > .323 && progress < .367;
const inSecondGap = progress > .382 && progress < .429;
const inFinalParallelGap = progress > .465 && progress < .493;
if ((inFirstGap || inSecondGap || inFinalParallelGap) && k % 5 !== 0) continue;
```

以上數值屬於此版上半屏生成器的局部參數，**不可直接當作其他頁面或其他 SVG 的通用數值**。通用的是「定位問題線群 → 局部刪減 → 稀疏恢復連續性 → 實際畫面驗收」的方法。

## 工程教訓（適用於全站視覺工程）

1. **先定位、後修改**：區分線條密度問題、幾何曲率問題、線寬/透明度問題，不得以不同類型補丁盲試。
2. **先用最小結構性修復**：多餘刻線優先刪除或稀疏化；不要首先重寫生成器或疊加新的波形。
3. **保持已驗收資產不變**：只修改缺陷所在層與區間；V10 原始下半屏是受保護基準。
4. **提交不是驗收**：程式碼提交、部署成功、實際畫面確認是三件不同的事。未看過部署效果不得宣稱視覺完成。
5. **避免版本膨脹**：把同一問題的定位、修改、驗證合併為完整工作單位；不要為每個猜測建立新版本。
6. **記錄可復用方法，不記錄情緒或對話措辭**：復盤只保留技術事實、決策與結果。
