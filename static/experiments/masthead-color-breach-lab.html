01 / OBJECT

Bound edge.

把出版资料放在封面侧面，主画面最干净。但如果展开后仅剩装饰性的纸本厚度，网刊自身的意义不足。

02 / AXIS

Editorial hinge.

收起时沿封面左缘，打开时进入左右对页中轴。书脊成为刊名、期号和转场共用的稳定出版轴线，优先深入。

03 / NAVIGATION

Running index.

对开后沿阅读区域外缘保留期号。适合继续探索章节与阅读进度，但本版尚未假装具有完整导航功能。

5:8 与 4:5 单封面裁切的几何研究仍然保留在编辑手册，但不再与仿真实体书脊绑定。此处只作历史记录及新版实验入口；不变更 P2 正式版。
