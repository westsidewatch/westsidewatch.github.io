## 1. 術語：高刻線（此工程約定）

在此專案中，「高刻線」指 **局部較深、較短、順應水面曲率與流向的造型刻線**，不是把整條等高線加粗，也不是在畫面上隨機散布短線。一般版畫技法中的 hatching / cross-hatching 是更廣泛的排線概念；本專案的「高刻線」為具體視覺規範。

## 2. 位置與功能

1. **波峰背光側與轉折側**：短刻線沿局部切線排列，暗部密、亮部疏；受光波峰頂部應保留紙白。
2. **波谷、交疊流層與遮蔽區**：可增加密度或局部交錯，塑造凹陷和前後關係，但不能形成橫跨整幅的單條黑色粗線。
3. **曲率變化顯著處**：短線應與主流線同向、連續轉折，不應橫切水流、呈雜訊狀。
4. **局部生長刻線**：從符合上述條件的既有高刻線中選取一部分，沿母曲線切線方向伸長並順流橫向推進；動畫必須黏附母曲線，隨整個水面呼吸變形。
5. **視覺作用**：形成明暗、體積、曲面方向、流速暗示與前後層次；不是獨立裝飾。

## 3. 生成順序（不得顛倒）

`原始 v10 路徑 → 多線局部曲率與切線 → 波峰/波谷及光照判斷 → 陰影權重 → 刻線密度與長度 → 高刻線的母曲線位置 → 同步動畫`

- 優先從原始 v10 提取短刻線/局部暗部的**長度、方向、密度、線寬、透明度**分布；不能憑模數、隨機座標和固定數量亂撒短線。
- 使用**曲率、背光方向、遮蔽程度**決定生成位置；用弧長取樣而非全局 x 坐標隨機取點。
- 由相鄰流線的**局部距離**控制暗度：距離緊→暗；距離疏→亮。保持連續、可控、無突兀暗帶。
- 高刻線需有長短變化、漸細收筆、群組節奏與局部缺口；避免大量同寬同長的虛線。
- 生長刻線必須沿母曲線滑移/伸長，不可脫離水面漂浮。
- 上半屏新增線與下半屏共用時間相位和呼吸場；若兩個 SVG 容器分開，交界處需做位置、斜率、相位連續性檢查。

- SVG-057～058：短刻線按模數散布、缺少曲率與光照依據，呈碎屑狀；**此分布法禁止繼續沿用**。
- SVG-058：全屏呼吸與波動參數已調，但仍需錄影/動態驗收；單張截圖不能證明動效合格。

## 5. 驗收條件

- 上半屏與下半屏為同一個水面，無硬接縫、直線帶或過暗連續長線。
- 波峰亮、背光側暗，線距疏密產生漸變，而非平均鋪線。
- 高刻線成群附著在曲率/陰影合理位置，**不是任意短橫線**。
- 部分高刻線可沿流線生長並橫向運動，不漂移、不中斷。
- 上下屏呼吸同步、流動可辨、無過度抖動；保留原始 v10 下半屏的形態與尺度。
- 修改以一次完整工程提交，附預覽版本號；不把「已提交」當成「已驗收」。

## 6. 技法參考

- Getty Museum：engraving、hatching、cross-hatching 與明暗造型相關教學。
- 經典版畫：以線條方向、密度、交錯和紙白控制體積及光照。
- 程式方向：曲率導向刻線、流場導向排線、自適應線距；開源實作必須先確認授權與適用性，不直接將陌生演算法替換已確認的 v10 幾何。
