# 附錄二　原文字根一覽

**希伯來文**

**דָּבָר　davar**　話語·道·事情·事物
神創造萬物時說話的那種語言，帶著創造的能力。說出來，就成了。約1:1「太初有道」的希伯來文背景。整本舊約出現超過1,400次，翻譯成話語、事情、事物、命令、承諾等不同中文，但背後都是「說出來的現實」這個核心意義。

**שָׂפָה　saphah**　嘴唇·語言
創世記11:1「同一種語言」用的字。以賽亞書28:11「嘴唇」同一個字。天國語言在舊約最直接的名稱。巴別塔被收回的，是這個；以賽亞書預言要重新使用的，也是這個；新約方言的舊約根源，就是 saphah。

**לָשׁוֹן　lashon**　舌頭·語言
以賽亞書28:11「外邦人的舌頭」。對應新約希臘文 glōssa。

**רוּחַ　ruach**　靈·風·氣息
神的靈在舊約的稱呼。創1:2「神的靈運行在水面上」。同一個字，是靈，是風，是氣息——神的生命力量，以不同形式顯現。

**רָחַף　rachaph**　振翅·輕輕搖動
一隻鳥孵蛋的動作。創1:2，整本聖經只出現三次。帶著溫柔、期待、生命即將破殼的靜默喜悅。神的靈在混沌上的存在方式，不是猛烈的，是 rachaph。

**אָמַר　amar**　說話的動作·開口·表達
說話的動作本身，不帶創造力。蛇用的是 amar——「神豈是真說（amar）……」在 amar 和 davar 之間插楔子，是罪進入的方式。

**אַיֵּכָה　Ayekah**　你在哪裡？
創3:9，神對亞當說的第一句話，整本聖經第一聲嘆息。神找人的語言，從創世記走到啟示錄，從來沒有停止。

**אֵיכָה　Eichah**　這怎麼可能？
哀歌第一個字，與 Ayekah 同樣四個字母。神問人，人問神，隔著幾千年遙遙相對。

**נָחַם　nacham**　深深嘆息·哀痛憂傷·安慰
創6:6神「後悔」造人，不是犯錯的後悔，而是因愛而深深哀傷的嘆息。同一個字，詩篇23:4翻譯成「安慰」。愛的嘆息，不是冷漠的後悔。

**מָרַד　marad**　叛逆·反抗
寧錄名字的字根。世上英雄之首，名字叫叛逆。

**קוֹל דְּמָמָה דַקָּה　qol dememah daqqah**　靜默的細聲
列王記上19:12，神在洞穴裡對以利亞說話的方式。颶風、地震、火——神不在其中。靜默的細聲——神在裡面。

**希臘文**

**Λόγος　Logos**　道·話語
約翰福音1:1「太初有道」。davar 的希臘文對應。耶穌基督的稱號。整個希臘哲學追求的宇宙理性原則，和舊約神說話的 davar，在約翰福音第一章，都指向同一個人。

**ῥῆμα　rhema**話語在此刻的活化
這是最容易被誤解、也最實際影響日常信仰生活的那個字。
Rhema 和 Logos 不是兩種不同的「話語」，而是同一個神的話語的兩個維度：Logos 是永恆的整體，Rhema 是那個整體在某一個時刻對某一個人說活的具體事件。
羅10:17「信道是從聽道來的，聽道是從基督的話（rhema）來的。」
弗6:17「拿著聖靈的寶劍，就是神的道（rhema）。」
太4:4「人活著不是單靠食物，乃是靠神口裡所出的一切話（rhema）。」
Rhema 不是超越聖經的新啟示。真正的 rhema 永遠是 Logos 的活化，永遠在聖經的框架裡，永遠把人指向耶穌基督。當一節你讀過一百次的聖經，第一百零一次突然說進你心裡，那個「突然說進來」的時刻，就是 Logos 成了 rhema。

**γλῶσσα　glōssa**　舌頭·語言·方言
新約「方言」的主要用詞。徒2:4門徒說的是 glōssa；林前13:1「萬人的方言並天使的話語」也是 glōssa。是天國語言在新約的主要名稱。

**διάλεκτος　dialektos**　鄉談·地區語言
徒2:6「各人聽見門徒用各人的鄉談說話」。說者說 glōssa，聽者聽見 dialektos。這個區別，是理解五旬節神蹟的關鍵——神蹟不只在說者，也在聽者。

**ἑρμηνεία　hermēneia**　翻譯·解釋
方言翻譯恩賜的用詞。英文 hermeneutics（詮釋學）的字根。把天國語言的意義，用人類語言說出來，讓眾人能夠接收。

**ἀλαλήτοις στεναγμοῖς　alalētois stenagmois**　說不出來的嘆息
羅8:26。ἀλάλητος = 無法用語言表達的；στεναγμός = 嘆息、呻吟。聖靈在我們裡面，用一種超越人類語言的嘆息替我們禱告。天國語言在最深層，是這種超越詞語的溝通。

**καινὴ κτίσις　kainē ktisis**　新造的人
林後5:17。不是改良，不是進步，是全新的創造。kainos = 性質上的新；ktisis = 創造。神用 davar 創造宇宙，也用 davar 在人裡面創造新人。

**ἐξουσία　exousia**　權柄
馬可福音1:22「祂教訓他們，正像有權柄的人」。詞義是合法的權限、權力、權柄。在耶穌身上，那權柄不是借來的，而從祂自己的身份與使命流出。

**ἐσκήνωσεν　eskēnōsen**　搭帳篷·住在
約1:14「道成了肉身，住在我們中間」。字面是「搭帳篷」。和住棚節（Sukkot）的「棚」相呼應。人建 Etemenanki 讓神住，神自己搭了一個棚，住在人中間。

**ὁμοθυμαδόν　homothumadon**　同心合意
徒1:14，一百二十個人在樓上「同心合意恆切禱告」。字面是「同一種激情、同一種節奏」。五旬節之前的等候狀態。

**κατενύγησαν　katenugēsan**　心裡刺痛
徒2:37，彼得講道後眾人的反應。字面是「被刺穿」。天國語言進入人心最直接的描述——不是增加資訊，而是某個本來就在的東西被說中了。

**一條線**

創造：davar　→　「要有光」就有光
　　　　↓
伊甸園：saphah / davar　→　亞當命名，說出即現實
　　　　↓
巴別塔：saphah 被收回　→　語言破碎
　　　　↓
舊約等候：先知偶爾受 ruach 感動　→　門縫裡的光
　　　　↓
以賽亞28：saphah + lashon　→　預告歸還
　　　　↓
道成肉身：davar → Logos　→　語言有了一張臉
　　　　↓
五旬節：glōssa 歸還　→　聖靈充滿，天國狀態
　　　　↓
哥林多：glōssa 常態化　→　需要 hermēneia
　　　　↓
新造：kainē ktisis　→　davar 在人裡面重新創造
　　　　↓
天國：完全的同在　→　「神要擦去一切的眼淚」
