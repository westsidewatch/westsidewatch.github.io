# 序言

神的話是生命。

而有時候，我們看到僅僅是文字。有人說讀聖經是讀書會，至於為什麼會出現這樣的認知，根本原因還是在於，我們太過習慣用「人」的方式，去看待去理解去解釋這個世界。這是人的局限，也是生而為人的悲哀。

同一本聖經，同一個人，同一個早晨。昨天讀，有什麼東西從很深的地方說進來。今天讀，只是字。

這不是信心的問題，也不是努力的問題。這本書，是為了這個問題而寫的。

答案比我們想的要古老。它從創世記第一章就已經在了，藏在幾個希伯來文字根裡，藏在巴別塔的磚縫裡，藏在五旬節那天使徒行傳用的兩個不同的希臘文字裡。

這本書要說的，是一個語言的故事。神把語言給了人，人驕傲，神收回，道成肉身贖回，聖靈送回。

從創世記到啟示錄，是同一個故事。

我寫這本書，不是因為我是神學專家。我是因為有一個問題一直困擾著我，然後某一天，我開始追索一個希伯來文字根，那條線就從那裡展開了，一路展開到我沒有預期的地方。

這裡面有深水，我只是站在淺灘邊，把我看見的說出來。如果你讀完想要下水，後面的附錄和參考書目會指引你往更深的地方走。

但在你潛水之前，先讓我說一個故事。
