# Doré Image Architecture

Status: FOUNDATION CONTRACT
Version: 0.1

## 1. Separation of concerns

Doré Image is divided into six logical layers.

### A. Brief compiler

Input:

- product request;
- target surface;
- required text/data;
- reference images;
- brand/product context;
- rights/provenance constraints.

Output: `dore.image.brief.v1`.

### B. Style compiler

Input: brief + Doré visual memory + selected style family.

Output:

- `dore.image.style-spec.v1`;
- `dore.image.recipe.v1`.

The style compiler owns stable design decisions. The renderer must not silently rewrite them.

### C. Structure planner

Creates explicit composition controls:

- subject geometry;
- crop;
- focal region;
- negative/release space;
- typography-safe region;
- intended responsive crops;
- edge/depth/pose/line control when applicable.

Output: `dore.image.structure.v1`.

### D. Renderer adapters

Contract:

```text
render(brief, style_spec, recipe, structure, renderer_config)
    -> candidate asset + renderer manifest
```

Candidate adapters:

- ComfyUI;
- diffusers;
- future local Apple/MLX path if hardware acceptance supports it;
- optional external renderer adapter without changing upstream manifests;
- SVG-native/Doré Design structural renderer for non-painterly assets.

### E. Critic / correction loop

The critic does not ask "is this pretty?". It evaluates explicit contracts:

- subject fidelity;
- brief accuracy;
- visual hierarchy;
- style-family coherence;
- composition/negative-space fit;
- typography-safe area;
- artifact/anatomy defects;
- palette constraints;
- web/product placement fit;
- originality/reference-distance;
- responsive crop survivability.

Output: `dore.image.critique.v1` with `ACCEPT`, `REVISE`, or `REJECT`.

### F. Asset packager

Creates a production package with hashes and metadata and sends accepted assets to Doré Design or the website build path.

## 3. Doré Original grammar contract

Doré Original must remain plural and extensible.

Every subfamily must define:

1. visual thesis;
2. palette/lighting system;
3. line/material system;
4. space system;
5. image/type relationship;
6. allowed transformations;
7. forbidden shortcuts;
8. reference-distance rules;
9. product surfaces where it is valid;
10. acceptance examples generated by Doré itself.

A subfamily may not graduate from `EXPERIMENTAL` to `ACTIVE` without at least three accepted real-product outputs across at least two different subjects.

## 4. Renderer selection logic

Use the least expensive/least destructive path that can satisfy the visual requirement.

Decision order:

```text
Can Doré Design / SVG-native geometry make it directly?
  YES -> use structured SVG path.
  NO  -> Does a supplied source image only need deterministic treatment?
          YES -> use local image-processing path.
          NO  -> Does the task need painterly/semantic generation?
                  YES -> use generative renderer.
```

For generative rendering:

```text
Need structure/pose preservation? -> control adapter.
Need reference identity/style?      -> reference adapter.
Need localized change?             -> inpaint/edit adapter.
Need new scene?                    -> text-to-image.
```

## 5. Integration with Doré Design

Accepted assets must carry placement metadata rather than arrive as anonymous files.

Example:

```yaml
placement:
  product: ONE
  page: matthew-03
  role: chapter-hero
  focal_anchor: [0.61, 0.42]
  safe_regions:
    - [0.05, 0.05, 0.36, 0.28]
  crops:
    desktop: <asset>
    mobile: <asset>
  alt_text: <semantic description>
```

Doré Design remains responsible for final typography, structural layout and editable composition unless the image itself intentionally contains integrated type as part of the artwork.

## 6. Evaluation strategy

Foundation evaluation has three levels:

- **L1 image validity:** the engine produced a usable file and manifest.
- **L2 visual validity:** the critic verifies brief/style/technical constraints.
- **L3 product validity:** the asset survives real insertion, responsive rendering and user/product acceptance.

Only L3 evidence contributes to a durable Doré capability promotion.
