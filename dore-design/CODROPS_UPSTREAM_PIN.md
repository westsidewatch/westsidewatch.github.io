# Codrops P1 upstream pin

P1 runs the upstream `gwen-bo/codrops-grid-to-preview` built source at tree `1027ebb60e38cbb4e7ee7d10ef045b5627a035c2` directly. No iframe and no custom motion implementation. The HTML structure is reproduced in `motion_prototypes.py`; CSS, JS and product assets are pinned to that exact upstream tree through jsDelivr.
