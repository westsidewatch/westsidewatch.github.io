# Doré Design 2.0 — Production

Design 2.0 is considered production only when the Mac A2A rollout returns `ok:true` and `status:completed` for a head containing this file, the production specimen remains PASS, and `/api/design2/production-health` reports `version:2.0-production` with closeout `ok:true`.

Product surface includes the unified Design shell, Pages/Layers/Inspector, direct manipulation, resize, snapping/guides, multi-selection, alignment/distribution/spacing, atomic z-order, grouping metadata, frames, local images with size guard, fit/crop/replace, typography controls, and the structured Multiwrite Home and Cover pages.

External design resources remain learning material; the runtime stays Doré-native and dependency-light.
