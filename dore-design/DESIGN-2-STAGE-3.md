# DORÉ Design 2.0 — Stage 3 System Construction

Status: ACTIVE MAINLINE

Stage 3 is not a shared-workspace mutation project. A2A and resident workspace mutation are infrastructure beneath this stage.

## Governing chain

`World → Learning → Experiment → Expansion → Mature templates → Comparison → Discernment → Convergence → New Westside`

Executable continuation:

`Museum / external learning → materially different experiments → mature templates → browser evidence → critique → durable learning → broad comparison → user-led convergence → Design System foundations → Brick System → Living Wall → Homepage implementation`

## What Stage 3 owns

1. **Design-world expansion** — maintain materially different visual traditions rather than variants of an already-liked style.
2. **Maturity depth** — selected experiments become complete responsive bilingual web systems, not screenshots.
3. **Visual core** — structured assets/shapes, canonical geometry, interaction, image lifecycle, deterministic export and visual readback remain renderer-neutral.
4. **Comparison and durable learning** — experiments are compared as systems; reusable discoveries enter Doré learning without silently becoming Westside identity.
5. **User-led convergence** — technical PASS cannot set `style_acceptance=true`; only explicit human aesthetic acceptance can authorize identity convergence.
6. **System construction after convergence** — portable design-system foundations, Brick System, Living Wall and production homepage follow convergence rather than precede it.

## Permanent constraints retained from research

- Doré owns structured state; canvas libraries are replaceable projections.
- Absorb mature patterns from external tools; do not make a general-purpose editor SDK the product owner.
- Image and Design are capabilities of one Doré Visual faculty, not prose-chatting agents.
- Image assets enter Design as normal structured shapes; no manual download/upload handoff.
- Expansion breadth and maturity depth are independent axes.
- Visual DNA: Light · Line · Paper · Engraving · Architecture.
- Permanent editorial grammar: Brick · Battlement · Flow, 5:8 Editorial Gravity, Living Wall/Huarongdao motion.
- Website = city; Journal issue = exhibition inside the city.
- Technical PASS ≠ design maturity ≠ aesthetic acceptance.

## Stage 3 acceptance

Stage 3 may advance into convergence only when the executable gate reports sufficient expansion breadth and maturity depth **and** the user explicitly authorizes convergence. The initial machine thresholds are deliberately conservative workflow guards, not aesthetic truth. Final New Westside identity remains user-authorized.
