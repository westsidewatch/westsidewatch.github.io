# Living Water Homepage — Candidate 01 visual acceptance

This is a human-visible design candidate, not a technology proof.

## Visible in this cut
- full-page continuous river sequence rather than horizontal card rail
- immersive Scripture Cinema opening field
- depth through scale, texture, foreground/horizon, sticky worlds and scroll-linked transforms
- 8:5 worlds used as editorial spaces
- canonical existing surfaces only: Journal, Daylight Cafe, Watch Prayer, Dawn Library
- no invented `三更報導`
- shared spatial grammar with visibly different editorial identities
- scroll-linked approach/focus/recede behavior
- fixed river progress/orientation signal
- mobile translation and reduced-motion fallback

## Not yet claimed
- final Doré engraving imagery
- final typography/art assets
- book/chapter 2D→spatial→2D Scripture transitions
- full object-persistent cover→opening→return navigation
- measured performance or dependency reduction
- Red Dot-level acceptance

## Human gate
The candidate is allowed to be incomplete, but it must already be judged as a design rather than a component demo. If it still reads as generic sections/cards, reject and revise before optimization.
