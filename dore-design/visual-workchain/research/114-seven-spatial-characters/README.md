# R114 七種章法
使用者明確保留活水、橄欖山，疏密本身是識別特徵。兩枚 R113 fine/small 逐字節鎖定。以馬忤斯僅改內窗閱讀刻線密度，其餘幾何不動。其他四枚允許大改，原 R11–R113 完整保留，新增候選非覆蓋。首屏同墨去名七章比較及40px，五枚 III/IV 正反印及尺寸比較，完整家族及城牆校樣。
- 活水堂西區：保留六齒與上下相向的水道，以三至四刀形成可辨識的中央留白。
- 西望：錯落：階梯刊頭、左窄實欄與右側不對稱的空窗，主次鮮明，不再模仿兩欄小字。
- 以馬忤斯：交會：原雙方窗、外輪廓、對角結構及比例不動，左上密集閱讀刻線、右下疏朗單線，僅改窗內疏密。
- 橄欖山：保留山峰節奏及對稱留白，避免層線黏連。
- 黎明書局：展卷：五段城垛輪廓分置於雙葉，左葉實、右葉虛，中軸書脊成為窄負空間，右葉仍有刻線。
- 天堂電影院：圍合：五段城垛的 1、1、2、3、3 階梯外緣形成一整片遮幅，中央真透明 16:9 銀幕，以負形成為唯一視覺重心，細刻線只在大尺寸保留。
- 白晝咖啡館：疏放：上下開放的角落光路保留城垛節奏，以寬闊中央留白及少數筆畫區隔以馬忤斯的雙閱讀窗。
本輪設計選擇：西望不對稱、黎明雙葉虛實、影院負形圍合、白晝疏放。幾何測試不等於藝術通過；正式頁未改。
