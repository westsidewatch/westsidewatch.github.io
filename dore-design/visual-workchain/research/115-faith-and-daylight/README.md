# R115 信與白晝
使用者在 R114 西望名章辨認出「信」字，要求朝這方向調適；白晝仍不滿意。只改兩枚候選，其他五枚兩種尺度均逐字節保留。
- 西望：保留 R114 偶然形成的「信」字意象；左實柱及右下口形不改主結構，微調右側階梯中間的橫向刻線，讓亻與言的聯想自然可辨，不直接寫入字形。
- 白晝咖啡館：捨棄兩角相向的重複圖形。下方採白晝母版六段 3、2、2、1、1、2 的等寬階梯作低矮窗台，左上為單一敞開方窗，中央及右上留給日光。以不對稱、低重心和大留白區分其他名章。
西望保留原來自然生長的字形聯想，非套用字體或書法。白晝以一側敞開窗口及低矮窗台重新構成光線與空氣。首屏同墨去名七章，IV/V 正反印對比，64/40/32/24px，完整家族及城牆組合。候選設計待藝術評審；未改正式頁。
