# R110 — 放大母形的局部顯現，而非 icon
來源 9d7f3e5557738e45749b2121918809efdec4cd9d R13.5 church M0 8V1H8V2H16V1H24V3H32V1H40V2H48V8Z。R109 完整六齒接縫不符合使用者的要求。原版教會六段母形固定；空間裁切由 source x / y 變換生成。禱告以內容中央軸定位母形第24原始單位的深齒轉折，桌面一齒四欄，手機/平板一齒六欄；正負空間僅取放大圖形中間數段並在 y=4 截斷，紙面裁切露出真活水刻線，玻璃置於截取基線，文字區避開裁切。回應桌面以兩排 QR 的共同中軸為轉折，母形旋轉90度後在共享欄邊截取中段，露出底層水色；左側兩個紙面實際裁切，右側紙面保留連續閱讀；不再放四個城垛圖標。窄屏按真實閱讀功能單欄，暫不強制加入無理由的空間裁切，需後續人工設計。原字重、顏色、日期標記、兩個經文方塊、P2 與正式站不改。附錄在既有編輯手冊 §9.6 追加使用者原則。三尺寸 test 增加 source crop 小於完整 48 單位、實際瀏覽器 hit-test 正負形、回應裁切檢查；結果待新一輪實測。
