# R106 — 內容生成構圖，去品牌比較
基底 R105 5563b566462fe791528174dd5df3f0481801d5f0（已修正 01–07）。承接 R105 對 §9.6 八項比較的結論：主日、週曆、事工、回應的局部品牌識別不足。保留 R105 雙方塊、整體網格、首屏、禱告、OS 和真實資料。主日用實際七時間區間構成連續時間印版：按本次資料的最早及最晚時刻計算每段位置與寬度，單一時間點只顯示刻度，不補造結束時刻；左側三經文以咬合的紙面開口嵌入原活水刻線。週曆真實聚會星期控制色域與退讓，其他星期不標為沒有聚會。七事工沿原十二欄、右五欄用原刻線及紙墨開口嵌入 WORSHIP，非新增圖片或均等卡片；QR 回應四個功能方形按對角正負形組成同一印版。修正文案中的 Gate/工程收件用語，不虛構歷史、不更動表單可用性、資料或連結。所有修改僅 art=106 啟用，前版仍可比。新增真實時間比例/活躍星期驗證、原字重與雙方塊幾何驗證，以及不重排頁面、遮掉品牌與篇章名後的四個篇章獨立截圖。這些截圖是人眼藝術評審材料，不是自動識別度分數；需實際審視後才能宣稱設計成熟。
