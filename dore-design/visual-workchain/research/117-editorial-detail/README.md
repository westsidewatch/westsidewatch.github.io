# R117 逐頁推敲｜教會篇 01

## 多雷探索：證據與轉譯
- Whitney / Experimental Jetset https://www.jetset.nl/archive/the-whitney-tapes ：識別強度隨使用情境調節；https://segd.org/projects/whitney-museum-of-american-art-wayfinding/ ：識別轉譯為尋路。轉譯：不用每個轉跳都出現城垛；內容與行動主次決定重音。
- Philbrook / Pentagram https://www.pentagram.com/work/philbrook-museum-of-art ：實形與觀看反形。轉譯：小章、方窗、宏觀裁切各自有不同用途，不為填空而疊加。
- Awwwards https://www.awwwards.com/about-evaluation/ ：設計、易用性、創意、內容；Webby https://www.webbyawards.com/judging-criteria/ ：結構與導航、視覺、功能、互動、創新、整體體驗。轉譯：細節必須同時有美學理由、內容理由及功能證據；獎項只是目標，不能以主觀分數取代驗收。
- W3C https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum ：目標區 24 CSS px 或符合例外；44px 是本案獨立重點連結的內部目標，不是 AA 要求。小標記和點擊目標分離；鍵盤焦點可見。

## 本輪實際落地
教會頁七章逐項盤點：目錄起筆保留名章，走進教會獨立城垛結構線，修正手機 6:1；歷史保留大經文章與版面；主日地址獨立小城垛、時間軸與七段不改；週曆既有日期城垛保留，不重複加章；事工保留敬拜方窗，其他事工鏈接不加通用 icon；禱告保留放大裁切；四回應入口只在決志一處加選擇性城垛，QR、原路由及原文保留；聯繫保留收印，不重複地址小章。

## 推敲門檻（自訂內部標準）
每頁逐項存證：① 功能與內容主次、閱讀次序（重點唯一或有理由的多重）② 網格、對齊、比例與負空間（母形等比，不能任意拉伸）③ 字體實際載入、字重與斷行（OS）④ 全頁節奏與無品牌校樣（藝術人工評價）⑤ 真實連結、焦點、hover、touch、無動效與錯誤狀態（功能）⑥ 1440/1648、768、390 寬度及 320 / 放大字體補測（響應）⑦ 實際內容、圖像、地址、路由可核實；不能用佔位符冒充內容 ⑧ 性能與穩定性檢查。單項通過不等於全站成熟。此輪只針對教會頁微觀重音及手機比例執行；其他頁尚待逐頁檢查，320 與字體放大/真機性能尚待驗證。研究依據公開案例與評審標準，尚未作外部案例全尺寸逐屏截圖比較。

## 驗收
保留 R116 路徑，隔離分支預設 117。專項測試繼承 116 的文字、QR、經文章、時間軸與母形檢查，新增決志唯一性、三個其他回應不加 icon、地址非鏈接、原路由、小城垛原比例、44px 點擊區、focus 和局部截圖。正式站未合併。
