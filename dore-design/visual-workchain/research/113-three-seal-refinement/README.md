# R113 三枚名章
R112 Chromium 實際校樣已通過。檢視 1440 截圖：西望下部仍像小字排版、書局上城垛與雙葉分離、白晝的角窗與光路分離。R113 針對三者重整構造而非僅改線寬；其餘四枚 R112 SVG 逐字節保留。校樣前三列對照 R112 / R113 的同尺寸正、反印及小尺寸，接續七章家族與城牆組合。
西望：保留原刊頭的下降階梯，將鬆散的仿文字線改為相向的兩個開放欄窗及階梯實體，構成有主次的印面。
黎明書局：原五段收穫色城垛輪廓成為雙葉共同的外牆，頂端與書葉相連，取消懸浮厚橫條；中間的窄缺口及不等內部構造形成書脊與雙窗。
白晝咖啡館：以原階梯光路直接折入兩角方窗，使光路和窗成為一刀連續結構，留出中央的空氣；保留原有錯位，而非另加窗符號。
設計決定：保留原藝術母本，新增構造變體，不改正式網頁。比較頁的色底保持 OS 紙色，避免既有 scope 背景干擾同墨色比較。
