# C03 Rejection — 2026-09-09

## Decision
Candidate 03 is rejected. Candidate 01 remains the current visual baseline.

## Why C03 failed
C03 translated the Living Water idea into a regularized CSS Grid that changes spans. That is a structural re-layout demo, not a convincing living editorial field. The result is more rigid, more dashboard-like, and visually weaker than Candidate 01.

The failure is conceptual, not a matter of adding more animation.

## Baseline restored
Candidate 01 remains the reference for:
- overall visual completeness
- atmosphere
- section color worlds
- scale
- editorial confidence
- immersive opening

## Constraint for the next candidate
Do not start from Grid, Masonry, ticker, carousel, rows, lanes, or independently drifting cards.

Start from Candidate 01's full-page art direction and change only the second-page spatial behavior.

The user's sketch should be interpreted as a moving editorial composition whose visual hierarchy is continuously authored, not as a set of boxes whose CSS spans are recalculated.

Important content must feel physically heavier in the composition: it can occupy more rhythm, hold attention longer, bend surrounding spacing, partially occlude or reveal neighboring content, and become the current visual sentence without snapping into a conventional hero slot.

Static frames must already look art-directed before motion. Motion should transform one strong composition into another strong composition.

C03 is retained only as a negative reference: `grid reallocation != Living Water`.
