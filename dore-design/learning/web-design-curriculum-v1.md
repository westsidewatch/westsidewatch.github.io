# Doré Web Design Curriculum v1

Status: REQUIRED_LEARNING / exploration only. This curriculum exists to prevent Doré from confusing repeated house motifs with design literacy. White/stone backgrounds, gold rules, giant serif type, dark green, and monumental editorial composition are not an accepted Westside style and must not become defaults.

## Principle
Doré must learn the field before constructing a house style. The learning unit is not a screenshot or a palette. For every category: collect multiple real sites, inspect desktop/mobile behavior, decompose composition/type/color/material/image/navigation/motion/content hierarchy, identify historical/design lineage where useful, build a small editable experiment, test it in a browser, record what transfers and what should be rejected. No category is accepted as Westside style merely because Doré can reproduce it.

## A. Visual and historical languages
1. International/Swiss — grid discipline, sans typography, asymmetric order, objective hierarchy.
2. Modernist/Bauhaus — geometry, functional form, primary structure, reduction.
3. Editorial/Newspaper/Magazine — columns, headlines, captions, issue rhythm, dense reading hierarchy.
4. Book/Print/Typographic — page proportion, margins, folios, serif systems, long-form rhythm.
5. Brutalism — exposed structure, raw browser language, deliberate friction.
6. Neo-brutalism — bold borders, flat blocks, high contrast, playful anti-polish.
7. Minimalism — reduction, whitespace, few strong decisions; study both good restraint and generic sameness.
8. Maximalism — layering, collision, abundance, expressive typography and imagery.
9. Postmodern/New Wave — broken grids, quotation, irony, expressive type, controlled disorder.
10. Retro web / Y2K / early internet — browser-native texture, pixel language, windows, marquees, nostalgia.
11. Skeuomorphic/tactile — physical metaphors, depth, material cues, controls that feel handled.
12. Glass/translucent/spatial UI — layering, blur, light, depth and legibility constraints.
13. Flat/geometric illustration — shape systems, iconography, graphic storytelling.
14. Collage/zine/punk — cut-paper logic, annotation, photocopy texture, irregular image-text relations.
15. Luxury/fashion/art-direction — pacing, photography, silence, crop, type-image tension.
16. Arts/cultural/museum — collection logic, exhibition sequencing, archive and interpretation.
17. Sacred/liturgical/architectural — procession, threshold, repetition, symbol, material and light; do not reduce this to gold lines.
18. Vernacular/local/community — handmade signs, community notices, local photography, imperfect specificity.
19. Data/information design — diagrams, indexes, timelines, maps, dense structured information.
20. Experimental/generative — procedural layouts, variable systems, unusual cursor/scroll/canvas behavior.

## B. Composition and information architecture
Learn independently of visual style: strict grids; broken grids; masonry; single-column reading; split-screen; cinematic full-bleed; index/catalogue; spatial map; timeline; chapter/sequence; portal/dashboard; archive/search; card systems; cardless systems; nested editorial; horizontal narrative; scroll storytelling; one-page; multi-entry hub; progressive disclosure; nonlinear exploration.

## C. Typography
Study serif, grotesk, humanist sans, geometric sans, monospace, display, variable type, bilingual Chinese/Latin pairing, vertical type, extreme scale contrast, quiet scale systems, dense newspaper typography, captions/metadata, readable long-form, typographic motion. Doré must learn when giant type is wrong.

## D. Image and material systems
Photography-led, documentary, portrait, architecture, archival scans, engraving, illustration, collage, 3D, video, texture, paper, stone, fabric, ink, grain, monochrome, duotone, image-free typography. Study cropping, masking, sequencing, captions, art direction and responsive image behavior.

## E. Color and light
Monochrome, black/white, restrained neutral, saturated, primary, pastel, fluorescent, earth, photographic color, dark mode, light mode, gradient, high/low contrast. Gold is one color family, not a brand conclusion.

## F. Interaction and motion
Static clarity; hover disclosure; microinteraction; page transition; parallax; pinned/sticky narrative; horizontal scroll; kinetic typography; cursor interaction; drag; canvas/WebGL/3D; sound; reduced-motion alternatives. Judge whether motion serves orientation, narrative, emotion or merely decoration.

## G. Product/site genres
Editorial publication; church/community; museum/cultural institution; library/archive; news; portfolio; agency; fashion; ecommerce; SaaS/product; nonprofit; education; event; documentary/story; knowledge base; map/data product. Study genre conventions before breaking them.

## H. Reference museums
Use multiple independent museums rather than one taste filter:
- Siteinspire: styles/types/subjects/platforms; especially typographic, grid, unusual layout, art, photography.
- Land-book: explicit style filters including 3D, animation, background image/video, big type, black & white, brutalism, cards, dark/light, flat, gradient, illustration, parallax, pattern, visible borders; also industry/type/typography.
- Godly: contemporary interactive, web/app/UI/visual work.
- Awwwards: interaction, motion and contemporary award-site art direction; treat award taste as one lens, not truth.
- Httpster: minimal, typographic, brutalist and grid-oriented counterexamples.
- One Page Love: single-page structures and section-level patterns.
- Mobbin: real product/web UI screens and flows; useful for interaction conventions rather than art direction alone.
- Cola Skill and skill directories: executable methods are a separate Skill-learning loop, but may supply methods for this curriculum.

## Required loop
DISCOVER -> SAMPLE DIVERSE EXAMPLES -> BROWSER OBSERVE -> DECOMPOSE -> NAME THE LINEAGE/PATTERN -> REBUILD SMALL EXPERIMENT -> DESKTOP/MOBILE EVIDENCE -> CRITIQUE -> ACCEPT/REJECT PRINCIPLES -> DURABLE MEMORY -> CROSS-BREED WITH ANOTHER CATEGORY -> NEW EXPERIMENT.

## Diversity gates before future New Westside convergence
A design exploration round is insufficient if candidates share the same dominant typography, palette, layout skeleton, material metaphor or interaction model. Before convergence, Doré must demonstrate materially different experiments across at least: 8 visual/historical languages, 6 composition models, 5 image/material strategies, 5 color/light systems, 5 interaction models, and 5 site genres. At least one experiment must be image-led, one type-led without giant hero type, one dense editorial, one highly restrained, one maximal/expressive, one browser-native/brutalist, one documentary/local, and one spatial/interactive.

Every experiment records: sources studied; observations; hypothesis; what it deliberately rejects from Doré's recent habits; desktop/mobile evidence; transferable learning; failure modes; whether it broadened the design vocabulary. WESTSIDE_FIT and user acceptance remain false until explicit user judgment.
