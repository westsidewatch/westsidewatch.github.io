# New Westside — Style Translation Gate

Status: ACTIVE
Purpose: close the gap between approved design ideas and visible design quality.

The strategic line does not change: Visual DNA = 光・線・紙・刻・築; Editorial Grammar = 磚・垛・流; black-record-wall editorial gravity; 5:8 highest weight; Huarong displacement; crenellation by composition/negative space; time as flow.

## Required translation sequence

No homepage composition may be promoted to CURRENT unless it passes this sequence:

1. Reference territory — select concrete visual references for typography, composition, archival print, image treatment and motion. References define territory, not a composition to copy.
2. Translation decision — record exactly what is borrowed as a mechanism and what is rejected as foreign style.
3. Real material — use Westside masthead, real Westside content and real illustration/image material. No rough line placeholder may stand in for Doré/retro illustration at review stage.
4. Composition specimen — solve the page as a visual composition before mapping it to UI modules. Generic hero + cards is an automatic failure.
5. Typography specimen — test headline/body/metadata/Chinese/English collisions in the chosen composition.
6. Image-treatment specimen — establish crop, engraving density, ink mode, paper interaction, gold trace and overlap.
7. Motion specimen — animate editorial state change only after the still composition works.
8. Visual review — compare the result against the selected reference territory and Westside invariants. Reject average/generic AI output.
9. Doré Design implementation — only a passed specimen enters the editable production workspace.

## Doré illustration standard

Doré-generated illustration is a real visual asset, not a CSS texture or rough diagonal-line simulation.

Each production candidate must provide:
- a deliberate subject tied to Westside content;
- convincing 19th-century engraving / wood-engraving material language without copying a specific copyrighted modern work;
- controlled line density and tonal hierarchy;
- composition designed for a known crop/territory (5:8, panoramic wall fragment, portrait fragment, etc.);
- print treatment variants: Ink on Living Paper; Midnight spot ink; optional restrained First Light Gold trace;
- enough resolution/detail to survive desktop editorial display;
- provenance/asset metadata and a review state: candidate / approved / rejected.

Default subject family for the first asset pack: watchman, city wall, gate, dawn sky, road, stone, gathered figures, scripture/book, water/well. These are a vocabulary, not mandatory decorative motifs.

## Division of work

ChatGPT: owns visual direction, reference translation, composition, Doré Design mainline implementation and acceptance/rejection.

Doré: observes the full decision trail; generates bounded illustration candidates; performs local render/verification/deployment; records evidence; learns approved/rejected examples.

During the current training/build phase, Doré does not independently choose the final visual direction.
