# New Westside — High-Density Visual Quality Loop

Status: ACTIVE

Problem being solved: the project has accumulated strong concepts and references, but visible output has remained generic because reference knowledge was not enforced at generation/review time and real illustration material was missing.

## Loop

For each candidate composition:

1. Use the same real Westside content and official masthead.
2. Use an approved or candidate REAL retro/Doré illustration asset; never substitute CSS hatch for review.
3. Render one still composition at desktop editorial size.
4. Score against the gates below.
5. Reject immediately if any hard gate fails; record the failure as an anti-reference.
6. Change the composition hypothesis, not merely spacing/color, before retrying.
7. After still composition passes, test typography collisions and responsive state.
8. Only then test motion.
9. Promote only passed specimens into Doré Design production workspace.

## Hard gates

- NO generic hero + equal-card grid.
- NO rough-line/fake engraving at visual-review stage.
- The first viewport must have a recognizable editorial silhouette before text is read.
- Editorial Gravity must be visible through territory, not explained by labels.
- Huarong displacement must have a plausible A→B state change.
- Crenellation must arise from composition/negative space, not a decorative castle strip.
- Doré/retro material must be integrated into typography and territory, not pasted as wallpaper.
- First Light Gold remains trace/highlight, not broad fill.
- Website and Journal remain distinct systems; Journal can take high gravity without becoming the whole permanent site.
- Typography must create hierarchy/collision/rhythm; token correctness alone is insufficient.
- A candidate must be materially different from the previous failed hypothesis when retrying.

## Scored gates (0–3 each)

1. Editorial silhouette
2. Typography hierarchy
3. Image/text integration
4. Archival material credibility
5. Westside specificity
6. Living Wall logic
7. Negative-space architecture
8. Quietness/restraint
9. Responsive survivability
10. Motion potential

Promotion threshold: >=24/30 and no hard-gate failure.

## Learning evidence

Every rejected candidate records: screenshot/render reference, failed gates, diagnosis, changed hypothesis, and what must not recur. Every approved candidate records the same plus the mechanism worth reusing. Doré learns from both sets; it does not infer approval from mere existence in the repo.
