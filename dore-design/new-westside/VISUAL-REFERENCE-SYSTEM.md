# New Westside Visual Reference System / 新西望視覺參照系統

Status: ACTIVE
Established: 2026-08-31
Role: visual intelligence layer for Doré Design

## Purpose

這不是 moodboard，也不是要求複製任何參考作品。它把新西望已形成的視覺判斷轉成 Doré / ChatGPT 可以反覆讀取、生成、比較與驗收的 reference system。

核心目標：**New Classicism + Editorial Modernism + Archival Print / 復古印刷感 + Doré engraving + Living Wall**。

「復古」不是濾鏡，不是泛黃、噪點、做舊邊框的堆疊。它來自真實印刷與檔案物的物質邏輯：紙、墨、套色、網點、版畫刻線、字體年代感、裁切、留白、微小錯版與時間痕跡。預設仍然保持當代編輯設計的清晰度。

## Reference method learned from external design skills

- Reference defines **visual territory, not a composition to reproduce**.
- Lock a system before generating variants; change one variable at a time.
- Composition before decoration/tokens.
- One focal event + one release zone; avoid average-density AI layouts.
- Keep an explicit anti-pattern list and a visual quality gate.
- Heavy references live outside the short execution rules; Doré reads the relevant specimen only when needed.

## System 01 — Typography

Build a visible specimen board, not a token list.

Voices to test with real Westside content:
1. **Masthead / 刊頭** — official Westside Watch SVG; never re-typeset as a substitute.
2. **Monumental Serif** — Cormorant Garamond; restrained monumental scale for permanent brand/editorial moments.
3. **Chinese Editorial Display** — Noto Serif TC; compact leading, deliberate line breaks, no generic centered poster treatment.
4. **Scripture Voice** — quiet, spacious, book-like; distinct from headline.
5. **Metadata / Folio** — small caps or compact utility voice; issue/date/category/number.
6. **Engraved Caption** — small serif caption adjacent to image/engraving, museum/archive logic.
7. **Vertical / Rotated Note** — rare structural use only when it strengthens wall/crop/orientation.
8. **Body Reading** — long-form first; never sacrifice legibility for vintage effect.

Board must show: scale ladder, horizontal/vertical/rotated orientation, Chinese-English pairing, collision with image/engraving, line/rule behavior, metadata density.

## System 02 — Color + Material

Semantic roles:
- Living Paper — reading substrate.
- Ink Black — text / engraving / rules.
- Midnight Blue — watch / night / deep editorial field.
- First Light Gold — highlight & trace only.
- Sacred Surface — temple stone × pale-gold historical/biblical material.

Board must test:
- Paper/ink dominant states.
- Night/paper reversal.
- Gold dosage: trace / edge / numeral / focal line; never generic gold card.
- Ink density: 20 / 35 / 50 / 70 / 85 / 100% as atmosphere/image/rule, **not new colors**.
- One controlled historical plate collision at a time.

## System 03 — Archival Print / 復古印刷感

Target: **a living contemporary publication carrying material memory**.

Allowed mechanisms:
- Doré wood/steel engraving linework.
- Fine-to-medium halftone screening where reproduction logic calls for it.
- Single-ink or restrained two-ink image treatments.
- Slight plate misregistration only in selected image/trace states.
- Paper fibre / stone / archival tonal variation at low intensity.
- Cropped archival imagery, folio numbers, thin rules, marginalia, captions.
- Uneven ink density as image evidence, not as a global grunge overlay.
- Contemporary whitespace and hierarchy must remain intact.

Vintage intensity states:
- **Trace 5–10%** — daily website default; almost subliminal material memory.
- **Presence 15–25%** — editorial feature / Journal presence.
- **Image 35–50%** — Doré illustration or archival image becomes a primary visual field.
- **Immersive 60%+** — rare issue/feature art direction only; never permanent website default.

Forbidden:
- fake burnt paper edges;
- sepia applied to everything;
- random dust/scratches;
- decorative Victorian ornaments without information/structural purpose;
- faux old newspaper template;
- excessive distressed type;
- nostalgia that makes Westside look like a heritage gift shop.

## System 04 — Doré Engraving

Doré is not a pasted illustration category. It is a visual material.

States:
- Trace — fragments of linework enter edge/rule/negative space.
- Presence — partial figure/architecture crop shares field with typography.
- Image — engraving occupies a 5:8 or other high-gravity editorial territory.
- Immersive — issue-specific visual world.

Tests required:
- crop at edge;
- figure vs architecture;
- text crossing/collision without destroying readability;
- gold catching selected engraving edges;
- ink-density reduction;
- paper and midnight reversals;
- mobile crop behavior.

## System 05 — Composition / Living Wall

The composition library must encode the actual Westside evolution:

**黑膠牆 → Editorial Gravity → 5:8 → 華容道讓位 → 信息瀑布流 → 城牆垛 → 磚・垛・流**

Patterns to specimen-test:
1. 5:8 Journal Tower.
2. Heavy + light brick collision.
3. Huarong displacement — new high-gravity brick enters; neighbours yield rather than simply stack.
4. Crenellation skyline — different heights plus negative space form the wall.
5. Fragmented engraving field.
6. Central Gate — only one gate; architecture through negative space and proportion, not castle decoration.
7. Quiet waterfall — time order remains perceptible beneath editorial weight.
8. Archive sediment — older content becomes smaller/quieter without disappearing.
9. Mobile wall — preserve gravity relationships instead of flattening everything to equal cards.

## System 06 — Motion / Time

Living Wall is a state system, not constant animation.

Required state sequence:
- content arrives;
- gravity is evaluated;
- one brick promotes/demotes;
- neighbours yield;
- skyline recomposes;
- old content sediments;
- wall rests.

Motion must be quiet. No jittering realtime dashboard. Re-layout occurs only when editorial/time state warrants it.

## System 07 — Reference Library

Each external reference record must contain:
- source;
- what we learn;
- what we explicitly do not copy;
- which Westside system it informs;
- status: candidate / adopted principle / rejected / superseded.

Initial methodological references:
- yanliudesign/mono-color-skill — visual reference boards; typography/color/layout systems; one/two-ink print logic; vintage intensity as controlled process rather than default decoration.
- Open Design design-brief — resolve symbolic visual intent into concrete tokens before generation.
- editorial-vision-studio — interpret rather than decorate; model-independent visual direction.
- core-design-skills — short execution rules + heavier reference files + anti-pattern review.
- editorial-tech / frontend-design references — asymmetry, negative space, thin rules, issue metadata, editorial hierarchy.

## Quality Gate

A New Westside output fails if any of these is true:
- It could plausibly be a generic beige SaaS/editorial template after changing the logo.
- All content blocks have equal weight.
- Doré appears only as a pasted illustration.
- Vintage appears only as yellow paper/noise/sepia.
- Gold becomes a large decorative fill.
- Crenellation is drawn as a castle motif instead of emerging from layout.
- Mobile collapses to equal stacked cards.
- Journal visual identity replaces the permanent website identity.
- The official masthead is replaced by typed text.

A successful output should be identifiable even without the logo through: **editorial gravity + living wall silhouette + paper/ink/night/gold roles + engraving material + controlled archival print memory + quiet contemporary composition.**
