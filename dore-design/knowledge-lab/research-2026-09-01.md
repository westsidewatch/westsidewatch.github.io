# Design learning research — 2026-09-01

This is a candidate ledger, not an adoption list. Re-check before actual use.

## Storybook
Role: executable design knowledge workbench.
Learn: isolated component/page states, Autodocs, stories as test cases, visual regression, interaction/accessibility testing.
Use for Doré: make every learned pattern runnable and reviewable; provide stable baselines for product monitoring.
Disposition: ADOPT AS LAB INFRASTRUCTURE CANDIDATE.

## GrapesJS
Role: open-source web builder framework.
Learn: block model, Style Manager, Layer Manager, Asset Manager, commands, storage architecture.
Use for Doré: compare its mature editor abstractions with Doré's Pages/Layers/Inspector/Assets instead of rebuilding blindly.
Disposition: STUDY / SELECTIVE REUSE CANDIDATE.

## Plasmic
Role: visual builder integrated with codebases.
Learn: existing React components as visual building blocks, variants, slots, state, design guardrails, Figma import to DOM/CSS, publishing/codegen boundaries.
Use for Doré: strong reference for Design-in-Code and eventual online Doré Design.
Disposition: HIGH-PRIORITY ARCHITECTURE STUDY.

## Puck ecosystem
Role: component-driven React visual editor.
Learn: component registry, drag/drop composition, constrained editing around production components.
Use for Doré: compare with Doré's desired website-native component editor.
Disposition: STUDY.

## Figma / contemporary editorial templates
Role: visual composition source.
Learn, don't merely collect: editorial hierarchy; oversized display type paired with restrained metadata; asymmetric but disciplined grids; strong whitespace; image cropping as composition; responsive re-composition rather than proportional shrinking; modular story cards; restrained motion; progressive disclosure; clear thresholds between cover, contents and reading.
Use for Westside: combine modern editorial clarity with existing Westside dawn/stone/gold identity; avoid generic SaaS/card-dashboard aesthetics.
Disposition: CONTINUOUS RESEARCH STREAM.

## First synthesis hypotheses to test
1. Journal should use an editorial component grammar, not arbitrary DOM editing.
2. ONE should share typography/tokens but use reading/study patterns rather than magazine cards everywhere.
3. Doré Design inspector should expose semantic variants and content fields before raw CSS.
4. Assets must become first-class workspace objects with provenance and missing-asset monitoring.
5. Storybook stories should become a source for Doré product-monitor visual/behavioral invariants.
