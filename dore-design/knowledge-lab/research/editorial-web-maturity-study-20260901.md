# Editorial web maturity study

## Reference families

- User reference set: two-ink print systems, subject-led poster design, nine composition grammars, reference-territory rather than composition copying.
- Motion documentation: scroll-linked and scroll-triggered animation, progress, SVG and parallax. https://motion.dev/docs
- Anime.js documentation: ScrollObserver-driven timelines and synchronized scroll motion. https://animejs.com/documentation/events/onscroll/
- Kokonut UI: open-source React/Tailwind/Motion components and machine-readable registry. https://github.com/kokonut-labs/kokonutui
- Webby magazine/publication winners: current editorial-site benchmark set. https://winners.webbyawards.com/winners/websites-and-mobile-sites/general-desktop-mobile-sites/magazine-or-publication

## AI learning loop

1. Normalize references into subject, composition, palette, typography, material and motion fields.
2. Cluster by visual grammar, not platform or popularity.
3. Create a direction card before code; prohibit unscoped aesthetic adjectives.
4. Generate independent DOM and primary visual assets for each direction.
5. Render desktop/mobile and reduced-motion states in a browser.
6. Score meaning, distinction, hierarchy, interaction, responsiveness, accessibility and editability.
7. Reject, record the failure mode, and generate a structurally different direction—not another CSS skin.
