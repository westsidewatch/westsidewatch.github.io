# New Westside Editorial Web

Read [references/visual-grammar.md](references/visual-grammar.md) when generating or reviewing a direction.

1. Translate references into territory: subject, crop, grid, type hierarchy, ink behavior, paper, rhythm and motion. Never reproduce a reference composition.
2. Choose a New Westside subject: dawn, watchtower, water routes, city coordinates, scripture path, four thresholds, archive or gathering.
3. Write a direction card with one subject, one composition grammar, two ink colors plus paper, one type contrast and at most three motion behaviors.
4. Generate a new semantic DOM for each direction. A shared DOM with CSS overrides is not a distinct concept.
5. Motion must explain hierarchy or passage. Respect `prefers-reduced-motion`; avoid scroll hijacking.
6. Test desktop and mobile, navigation, Chinese/English reading, contrast, focus, reduced motion and editor bindings.
7. Reject candidates without a unique thumbnail silhouette, meaningful graphic subject, or structural difference from the baseline.

Build success is not design acceptance. Editor entry requires a named direction, traceable reference families, independent DOM, primary visual asset, responsive layout, motion rationale, Storybook story and browser review.



## Start with editorial identity BEFORE visual technique — R7 §6E.33

When asked **how to design a magazine's visual style, what matters most, or where to begin**, read the current **Vol.00 EDITORIAL_MAP.md** and **single OS Editorial Manual §6E.33 R7** before recommending fonts, squares, crops, grid, templates or kinetic effects. Priority: **editorial worldview and reader question → full-issue dramaturgy (WATCH 4 / WALK 4 / WITNESS 2 / WORSHIP 2 + 3 Video/Music interludes) → genuine visual materials + rights → recognisable invariant/variation grammar → complete reader path → actual spreads and typography → engineering/QA**. Never reveal the later Beersheba theological argument prematurely in early issue design. A distinctive magazine system must work for **different story tasks** (city history / human witness / worship), not only for The Gate's hero.

Complete the three **manual-stage** deliverables first: one-page editorial proposition, whole-issue visual score and identity stress test across unlike articles. Use existing R1–R6 research as tools *after* this creative foundation, not as substitutes for it. User-rejected Monocle stays negative only. No separate style guide, tokens, CSS or live homepage/P2 edits until actual art-direction selection and full §6A acceptance.



## The issue itself generates the visual rhythm — R8 §6E.34

The first production-level creative brief is **not a cover moodboard**. Read the actual [Vol.00 editorial canon](../../../../docs/projects/watch-city-vol00/EDITORIAL_MAP.md) and [single Design OS Editorial Manual §6E.34](../../../../docs/design/WESTSIDE-EDITORIAL-MANUAL.md) to obtain the completed **12 desks + 3 Video/Music interludes visual score** and three distinct test briefs **Elim engineering/history, Esther human witness, Maranatha prayer/quiet**. Do not invent an absent devotion, portrait, closing prayer or source/citation. A real Westside identity must have recognisable constant components while the creative silhouette changes meaningfully by task; a single Gate opener at three image ratios is not evidence of identity. R5 full digital-spread and R6 oversized-English are instruments to use where subject warrants; not repetitive templates. Check actual desktop/phone/zoom/keyboard, full article middle/end and one issue Contents using existing §6A. **No production edits or new style OS from this research alone.**

## Publication-design book routing — manual-first task

When the brief asks for magazine identity, complete editorial design specifications or a Doré exploration of magazine design books, read **§6E of docs/design/WESTSIDE-EDITORIAL-MANUAL.md** before proposing layouts. It is part of the only Westside Design OS, not another style guide or token owner. Route the task through B01–B11 source evidence, editorial anatomy, actual manuscript/image provenance, bounded master-grid hypotheses, CJK and responsive typesetting, figure/caption/navigation and real release QA. An artistic detail such as a square image or article end mark is **not** the main deliverable while the complete brand grammar remains unapproved. Keep future research in that chapter rather than starting parallel handbook files. Current §6E.17–22 includes 17 source-based magazine cases and S01–S32 production specification sheet requirements. The §6E.23–27 six-original Doré atlas distinguishes original publication, digital scan rights, actual subject, crop math and live page safe zones; DO NOT assume a local engraving-style image is a Doré original. **§6E.28–R4.8** is the current production research protocol: source-pixel-to-CSS `cover` inverse, protected subject+signature+axis masks, text/figure collision and CJK/Bodoni optical checks. Maintain explicit ORIGINAL-PIXEL-UNKNOWN status; crop geometry is not subject-safe clearance, browser tests or art-direction approval. Distinguish externally verified editorial practice from Westside's translated methods, and never claim private magazine styleguides were acquired unless actually obtained. Preserve label distinction [BASE] / [METHOD] / [TRIAL] / [OPEN] / [BLOCK], and never imply full copyrighted books have been read when only their public contents or publisher summaries were checked.


## Digital spread-first editorial art direction (R5 manual §6E.29–31)

When a design brief concerns a magazine **spread**, a square, a cross-column image or modern editorial art direction, study the **full-width digital composition canvas first**, not the source photograph's aspect-ratio crop. Use the existing manual's \`SpreadCanvas / CompositionalAxis / CrossAxisObject\` method with no physical binding gutter. A single **true square** can extend **50/50, 30/70 or 70/30 across a virtual axis**, and can be a geometric field, mask, live-type register, focus image or negative-space device. Distinguish the **square's distribution across an axis** from a **30/70 division of the whole spread**. Test square/no-square/landscape/full-bleed on the **same content**, including artwork integrity, image/type layering, publication silhouette, longform continuation, semantic DOM order and mobile re-composition. Do NOT impose printed left/right pages or three independent panels on the browser. R3/R4 crop math is still vital whenever artwork is cropped, but it is **only one component** of full editorial design. Use only the existing Design OS type/color authority and preserve the signed homepage film and live P2.

## Award-calibre acceptance loop — use the existing Design OS §6A

For Westside magazine, Journal, Church and First Look art direction, 15/20 is **exploratory minimum only**. The existing \`docs/design/WESTSIDE-EDITORIAL-MANUAL.md\` §6A is the single release authority: a *provisional internal goal* of ≥18/20 across this skill's same ten 0–2 criteria, no zero and no unresolved block, **plus independently working** navigation, Chinese/English reading, performance, focus, reduced-motion, tablet, phone and actual zoom. This is not an official Awwwards, Webby or FWA score or promise of winning.

For every meaningful iteration: use the currently deployed render and real copy → inspect desktop/tablet/phone screenshot → note block/important/polish by owner → fix one meaningful structural defect → re-render and compare → reject/retain. If an actual viewport, user path, source asset or browser behavior wasn't checked, say **NOT VERIFIED**. Green CI and generated screenshots are not equivalent to an art-direction signoff. PR #1352's shared-content square/wide/full mode is a **controlled one-axis geometry comparison**, not three distinct authored directions; genuinely distinct concepts require independent semantic DOM.
