# New Westside Editorial Web

Read [references/visual-grammar.md](references/visual-grammar.md) when generating or reviewing a direction.

1. Translate references into territory: subject, crop, grid, type hierarchy, ink behavior, paper, rhythm and motion. Never reproduce a reference composition.
2. Choose a New Westside subject: dawn, watchtower, water routes, city coordinates, scripture path, four thresholds, archive or gathering.
3. Write a direction card with one subject, one composition grammar, two ink colors plus paper, one type contrast and at most three motion behaviors.
4. Generate a new semantic DOM for each direction. A shared DOM with CSS overrides is not a distinct concept.
5. Motion must explain hierarchy or passage. Respect `prefers-reduced-motion`; avoid scroll hijacking.
6. Test desktop and mobile, navigation, Chinese/English reading, contrast, focus, reduced motion and editor bindings.
7. Reject candidates without a unique thumbnail silhouette, meaningful graphic subject, or structural difference from the baseline.

Build success is not design acceptance. Editor entry requires a named direction, traceable reference families, independent DOM, primary visual asset, responsive layout, motion rationale, Storybook story and browser review.
