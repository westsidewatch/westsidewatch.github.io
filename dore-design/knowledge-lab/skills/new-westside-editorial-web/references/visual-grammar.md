# Visual grammar

- A reference set defines territory, not a composition to copy. Rebuild subject, crop, grid, hierarchy and print treatment.
- Paper is not an ink. Use no more than two dominant ink plates; create depth with halftone density, opacity, overprint and line work.
- Composition families: edge-cropped hero, framed field, ruled collision grid, archival axis, repeated path, central overprint, vertical title frame, diagonal hybrid and fragmented field.
- Typography participates in the image through crop, rotation, collision, repetition or axes. A centered large heading is insufficient.
- Each direction needs a New Westside subject and a silhouette distinct at thumbnail size.
- Prefer responsive SVG paths, masks, patterns and type fields. Motion may reveal information, trace routes, show progress or connect layers.
- Use Motion or Anime.js when their timeline/scroll primitives reduce complexity. CSS and IntersectionObserver are preferred for small effects.

Score 0–2 each: New Westside meaning, subject, composition distinction, typography, two-ink discipline, hierarchy, interaction meaning, mobile, accessibility, editability. Reject below 15/20 or any zero in meaning, distinction, accessibility or editability.
