# Multi-Loop Control Plane 1.0

Only Thin Runtime, Agent Core, and this Control Plane remain resident. A Loop is a durable goal with state, checkpoint, triggers, evidence, and policy.

The Control Plane owns `Wake / Route / Priority / Yield / Resume / Share / Record`. A2A is a capability-recovery path available to every workflow, not a peer business Loop.

Initial business workflows:

- Storybook reference expansion: continue from 21 toward 40 without false completion.
- Dawn Library enrichment: normalize, deduplicate, preserve provenance and rights state, then publish a reusable KnowledgeAsset.

The first acceptance requires an event trace proving Storybook work starts, Dawn wakes with higher information value, Storybook checkpoints and yields, Dawn shares one deduplicated asset, and Storybook resumes by consuming that asset instead of repeating the research.
