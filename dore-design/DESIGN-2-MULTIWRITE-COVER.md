# Design 2.0 — 多寫 Cover

Status: native editable page.

`multiwrite-cover` is now a first-class page in the same structured Design workspace as `multiwrite-home`.

It contains editable frame, kicker, title, subtitle, rule, and note nodes. The page uses the Design workspace revision/history model and is exposed at `/editor?page=multiwrite-cover`.

This is intentionally structured rather than a flattened bitmap. Local image assets can be added/replaced through the Frame · Asset controls from the preceding slice.
