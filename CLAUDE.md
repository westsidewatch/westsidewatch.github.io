# Westside / Claude Code project entrypoint

This is a short **routing pointer**, not a new design system or a substitute for the single Westside Design OS.

- Read [AGENTS.md](AGENTS.md) for task-sensitive tool activation.
- For any **《西望》/ Xi Wang A or B poster** work, open [Design OS Editorial Manual](docs/design/WESTSIDE-EDITORIAL-MANUAL.md) and [the Poster Toolchain Execution Contract](docs/design/XIWANG-POSTER-TOOLCHAIN-EXECUTION.md) **before** generating a design or editing P2.
- Explicitly read the upstream [mono-color-skill/SKILL.md](https://github.com/yanliudesign/mono-color-skill/blob/main/SKILL.md) for editorial print art direction (code/skill MIT; example image rights differ), then run `node scripts/xiwang/poster-toolchain.mjs plan a|b` in a real checkout. Reading the skill is not the same as installing or running the tools.
- Only claim a specific glyph, engraving, or SVG tool was **used** if there is actual output and an execution receipt. Keep the Draft and official P2/cover intact until actual human-reviewed visual acceptance.

All other project work remains governed by existing user instructions and the single Design OS.
