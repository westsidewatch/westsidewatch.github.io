# Doré Game Art Direction Lab — Foundation v0

Status: PREPARATORY / NON-CANONICAL
First real consumer: 《羊走迷》

## Purpose

Build a long-running, observable art-direction research loop for Doré games without creating a second cognitive core, a second Italian Editorial Atlas, or a parallel Skill Growth pipeline.

The Lab consumes existing Doré organs:

`Italian Editorial evidence/grammar + cross-domain evidence -> game visual genome -> candidate -> fixed benchmark -> evaluation -> retain/reject -> Skill Growth observation`

## Hard boundaries

1. Beauty is an admission floor. Mechanically valid but visually unresolved output is rejected.
2. Historical evidence remains evidence. Generated work can never become historical authority.
3. Italian editorial/illustration history is a primary longitudinal lineage, not a predetermined final style.
4. Global design exploration may combine with, compete against, or outperform the Italian lineage.
5. No candidate self-promotes into canonical design capability or production art direction.
6. Human art-direction judgment and Scripture/theological authority remain above generated candidates.
7. No second learning/evolution pipeline. Reusable learning is emitted through existing `dore/skill-growth` observations.
8. Research progress is not image count. Progress means stronger reproducible grammar and better game candidates.

## Fixed benchmark 01

**羊第一次进入世界 / The Sheep Enters the World**

Every retained generation must be testable against the same benchmark. Later fixed benchmarks may add collision, 2D→3D folding and Prayer Revelation, but benchmark 01 must remain stable so visual evolution is directly comparable.

## Research topology

### Longitudinal loop

1930s Italian editorial / illustration → postwar evolution → contemporary descendants.

`evidence -> decompose -> abstract grammar -> reconstruction test -> similarity rejection -> retained grammar -> mutation`

### Horizontal loop

Games / editorial / illustration / architecture / film / animation / typography / art / installation / stage / other relevant visual systems.

External evidence is not required to agree with the Italian lineage.

### Game loop

`lineage grammar + cross-domain grammar -> visual genome -> candidate -> static beauty -> touch -> collision -> recomposition -> 2D→3D -> distinctiveness -> retain/reject`

Game-test results write observations back to the existing Skill Growth spine.

## Visual Genome

A candidate is not just a prompt. It records at minimum:

- historical lineage
- composition grammar
- geometry grammar
- line grammar
- palette grammar
- typography grammar
- material grammar
- motion grammar
- collision grammar
- spatial grammar
- Scripture compatibility
- distinctiveness
- evidence provenance
- mutation parent(s)

## Temporal Beauty

A successful direction must remain composed through time:

`t0 -> drag -> contact/collision -> recomposed state -> rotation/folding -> 3D state`

**Every legal game state must remain composed.**

## Observable research states

`DISCOVERED -> STUDIED -> DECOMPOSED -> UNDERSTOOD -> EXPERIMENTED -> GAME_TESTED -> RETAINED`

Finding an image does not count as understanding it. A grammar is UNDERSTOOD only after Doré can reproduce the transferable rule in distinct, non-copying experiments.

## First engineering cut

Foundation v0 only establishes contracts and provenance. It does not declare an art-direction winner and does not production-promote anything.
