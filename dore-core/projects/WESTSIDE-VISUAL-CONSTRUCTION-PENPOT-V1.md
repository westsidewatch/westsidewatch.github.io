# WESTSIDE VISUAL CONSTRUCTION — PENPOT V1

Status: ACTIVE / CANONICAL DESIGN WORKSPACE
Established: 2026-08-26
Owner: Westside Watch / 西望
Executor / learner: Doré

## Platform decision

Penpot is the canonical production design workspace for the new Westside visual system.

Figma is retired from the production workflow after the bounded migration of already-established Westside design work. It is not a required dependency for future design production, storage, component authoring, review, or delivery.

Figma may still be observed as a **learning/reference source only**: public templates, editorial systems, interaction patterns, component logic, typography, spatial systems and other design examples may be studied by Doré as external case material. No Westside production workflow may depend on Figma access, paid Figma MCP quotas, or a Figma file remaining editable.

## Canonical production loop

`human editorial intent → Doré judgment/research → Penpot MCP execution → canvas evidence → human correction → Doré learning retention → reusable Westside system`

## Migration rule

The bounded Figma migration does **not** mean pixel-copying every node. The goal is to preserve already-established Westside design decisions and useful experiments while removing Figma as a dependency.

Migrate and reconstruct in Penpot:

- Living Paper / Ink Black / Midnight Blue / First Light Gold material hierarchy;
- Cormorant Garamond + Noto Serif TC typography intent;
- Visual DNA: Light / Line / Paper / Engraving / Architecture;
- Editorial Grammar: Brick / Battlement / Flow;
- 5:8 editorial container rule;
- night → dawn → great light narrative;
- city / gate / wall / watch language;
- temple-stone materiality where semantically justified;
- Doré source-grammar principle and purpose-built asset families;
- the emerging Visual Language Lab concepts already established before Figma retirement.

Do not migrate Figma-specific implementation artifacts merely because they exist.

## Free-first rule

The canonical visual-production path must remain usable without a paid Figma plan. No future Westside design milestone may require Figma quota or Figma paid access.

## Figma role after migration

Allowed:
- study public Figma templates and examples;
- inspect design-system patterns when free access permits;
- extract transferable hypotheses into VIS-LEARN;
- compare Penpot output against high-quality external design references.

Not allowed as canonical workflow:
- storing the master Westside design system in Figma;
- requiring Figma MCP for execution;
- using Figma as the handoff source of truth;
- blocking Doré design work on Figma call limits;
- paying for Figma merely to continue Westside production without an explicit future human decision.
