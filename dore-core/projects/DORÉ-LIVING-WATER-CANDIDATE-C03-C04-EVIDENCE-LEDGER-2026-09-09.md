## Canonical visual-doctrine conflict

The current C04 source still declares and implements:

- `dore-public-original-background`
- `per-current-dore-original`
- reuse of the Doré Search 241 registry
- Wikimedia Commons redirect URLs for original Doré images as tile/background surfaces

This conflicts with the already-established canonical split:

- original Doré works = curated reader-facing content under `DORE-EXHIBITION`;
- Westside interface/brand grammar = purpose-built fresh Doré-derived marks, light fields, textures, strokes, sky/water/stone/city/star motifs and other website assets under `VIS-GRAMMAR`.

Therefore C04 is valid as a spatial/motion/light-engine experiment, but its use of original works as routine interface surfaces must not be mistaken for the target visual grammar. That part is now design migration debt.

## Live-direction refinement — complete Doré website-asset family

The current product direction sharpens the earlier “first coherent set” language into a broader durable requirement:

1. Doré should author a **complete, reusable website-material family** from the current New Westside visual principles rather than decorate pages with crops from Doré originals.
2. The family should include, at minimum, purpose-built treatments for **light, Bethlehem star/star, water, sky/cloud/dawn/night, wall/stone/city-edge**, plus compatible textures/strokes/background fields where useful.
3. These are not standalone illustrations whose job is to imitate an old plate. They are interface/material primitives designed for recurring use across Westside surfaces while retaining Doré-derived engraving logic, restraint, paper/light behavior and brand recognizability.
4. Original Doré works remain reader-facing collection objects. Their routine use should be a **curated card in the flowing editorial stream** with context/provenance/rights, not a default background, tile skin or generic website texture.
5. The rejected placeholder-style A/B/C experiment is not evidence for this family. A valid comparison must render actual authored assets in the same real content/layout context and persist visual readback.

Classification: `VIS-GRAMMAR` asset-family requirement = `ACTIVE / BUILDING / UNKNOWN_NEEDS_EVIDENCE`; original-art-as-routine-interface = `SUPERSEDED_DIRECTION` for New Westside visual grammar; original-art curator-card use = `READY / CURATED-CONTENT` under `DORE-EXHIBITION`.

## Light-engine evidence boundary

The native C/D light runtimes are legitimate implementation evidence that a dynamic light layer can be integrated into the C04 composition without relying on a third-party demo iframe. They are not yet evidence that Doré has produced a coherent purpose-drawn light asset family or that the effect is visually correct for Westside.

A generic god-rays / light-rays runtime may become a substrate for a Doré-authored light treatment, but the final grammar still requires authored motif behavior, restraint, responsive verification, reduced-motion/accessibility review, and real visual readback.

## Durable lesson

A design candidate can prove layout, motion or rendering infrastructure while still failing the governing visual doctrine. Sweep classification must separate implementation novelty from earned brand-language evidence. New Westside should absorb Doré into a purpose-built visual grammar; it should not become an exhibition wall made from Doré originals.
