## What the experiment actually proves

`living_water_third_alive_lab.py` is a real executable Design experiment. It implements four moving content currents — WATCH / WITNESS / WALK / WORSHIP — with a `5:8` atomic card unit, weighted spans `1 / 2 / 3`, deliberately different flow speeds/directions, keyboard-focusable cards, responsive sizing and `prefers-reduced-motion` fallback. The later registration commit makes the experiment a first-class standalone editor page while explicitly keeping Candidate 01 untouched.

This is therefore legitimate **interaction/composition exploration** rather than a memo or static concept.

## Evidence boundary

The experiment is **not evidence that the current Doré-derived Westside visual grammar has passed**.

Its visual treatment presently uses:

- a blanket near-black/night field (`#171817` plus darker radial-gradient stage values);
- card bodies dominated by dark rectangular fills;
- a generic repeating-linear-gradient named `engraving-lines`;
- a CSS-style radial glow as the principal light event.

Those choices directly match several automatic FAIL conditions in the current `DORÉ-VISUAL-DESIGNER-01-LIGHT.md` if they were presented as finished Westside visual assets: repeated parallel lines presented as engraving without form/air/value logic; generic CSS-like glow/gradient without spatial cause; and large dead-dark fields outside a proven true-night semantic requirement.

The correct interpretation is therefore:

- **4W weighted-length / flowing-current navigation concept:** `DISCOVERY / ACTIVE_PARALLEL`, real executable experiment;
- **visual surface treatment inside this lab:** `SUPERSEDED_AS_BRAND_EVIDENCE / REVISIT_BEFORE_PROMOTION`;
- **Candidate 01:** not modified by these commits;
- **VIS-GRAMMAR:** remains `ACTIVE_PARALLEL / BUILDING`; no promotion earned;
- **LIGHT-01 gate:** still unpassed; the experiment must not be used to bypass the one-accepted-asset sequence.

## Durable learning

The useful retained idea is structural, not stylistic:

`four semantic currents + variable 5:8 length/weight + independent flow rhythm + focus without freezing the whole river`

This can later be re-rendered using the accepted Westside asset grammar. The current dark/repeating-line skin should not be propagated merely because the interaction prototype works.

This separates two kinds of success that Doré must not conflate:

`interaction prototype works` ≠ `visual language accepted`

and preserves the stronger learning rule already established by Visual Designer 01:

`software/design mechanism success` ≠ `design-quality completion`.

## Revisit trigger

Revisit Third Alive only after `LIGHT-01` has passed and at least the first small purpose-built Doré asset set is available. Then re-skin the **same weighted-current interaction** without changing its structural behavior and judge whether the visual grammar improves recognition, restraint, readability and semantic meaning.

Do not use original Doré plates as the default skin. Original works remain curated content cards; the interface layer must use purpose-drawn Doré-derived Westside assets.
