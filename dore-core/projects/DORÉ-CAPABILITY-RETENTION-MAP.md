## CAP-001 — Persistent sensory learning and reconciliation

**Learned from:** `CW-001 — Sensory-loop consolidation / D1 reconciliation milestone`

**Reusable capabilities retained**
- convert a raw observed query/signal into a claimable research task;
- connect the task to a durable brain node;
- reconcile consolidated knowledge back to persistent state;
- make signal handling idempotent/deduplicated;
- distinguish implementation state from persisted learning state;
- verify a live loop with external heartbeat/probe evidence instead of equating commit with completion.

**Useful in current/future work**
- autonomous Project Runtime checkpoints;
- Search/Ask learning and reader-query observation;
- future Doré conversation memory;
- Library ingestion deduplication/provenance;
- distribution experiments that must preserve evidence and avoid duplicate event interpretation;
- any future continuous-learning mechanism where a transient event becomes durable knowledge.

**Boundary / caution**
This capability does not yet imply broad-volume robustness or truth/quality of every learned answer; those require separate evaluation.
