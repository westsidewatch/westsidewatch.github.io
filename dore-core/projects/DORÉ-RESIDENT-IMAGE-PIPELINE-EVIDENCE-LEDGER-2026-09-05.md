## Classification

### Resident image generation substrate

**Current classification:** `ACTIVE_PARALLEL / FOUNDATION` with `VERIFIED_COMPLETE_SUBMILESTONE` implementation evidence.

The repository now contains a coherent provider-bound image path that can:

1. compile a Doré visual recipe into a ComfyUI workflow without leaking provider syntax upward;
2. render through the resident provider seam;
3. fetch returned image bytes into Doré-owned storage with content-type, emptiness and maximum-size checks;
4. hash those bytes and persist a stable artifact identity plus provenance, recipe and brief;
5. emit a critic input that explicitly refuses to claim visual acceptance before real vision observations exist;
6. accept correction direction back into a later generation prompt.

This is a real architectural/implementation milestone. It is stronger than a prompt-only or ephemeral-image path because image bytes, checksum, provenance and generation inputs become durable evidence.
