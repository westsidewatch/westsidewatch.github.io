# DORÉ NERVOUS SYSTEM IMPLEMENTATION

Status: ACTIVE_PARALLEL
Started: 2026-08-25
Architecture: `dore-core/architecture/DORE-OPERATING-NERVOUS-SYSTEM.md`

## Objective
Turn the newly established operating-nervous-system contracts into executable, tested Doré infrastructure without interrupting P01, Memory Sweep or Conversation Alpha.

## Priority 0 — immediate integration into convergence lines
P01, Memory Sweep and Conversation Alpha must begin emitting or preserving, as applicable:
- evaluation evidence;
- observable run/state evidence;
- cost/free-tier signals when measurable;
- authority/escalation classification for state-changing actions;
- provenance/rights decision for external resources;
- Capability Frontier outcome/blocker classification.

## Priority 1 — executable foundations
1. **Authority policy** — machine-readable action classes A0–A4 and escalation contract.
2. **Evaluation registry** — capability → eval suite → pass criteria → evidence → re-evaluation trigger.
3. **Provenance/rights schema** — one reusable record consumed by Library/P01/Search/ONE/Journal.
4. **Run telemetry schema** — common run/job/project trace envelope with privacy/redaction policy.
5. **Cost Frontier registry** — services, free limits, usage, warning thresholds, alternatives, approval state.
6. **Capability Frontier ledger** — longitudinal autonomy/blocker/retest records.

## Priority 2 — first real integrations
- P01 is the first full integration test: video source provenance + subtitle rights decision + acquisition/transcription cost + job trace + subtitle eval + authority gate + E2E verification + capability-frontier record.
- Memory Sweep integrates evaluation/revisit evidence and identifies historical capability-boundary events.
- Conversation Alpha integrates context provenance, tool/action trace, authority gate, conversation eval and automatic durable-decision consolidation.
- Library ingestion consumes provenance/rights and dedupe/eval contracts.

## Priority 3 — ecosystem observability
Instrument Search, ONE, Main, Library, subtitle pipeline and runtime for bounded health/quality signals. Prefer existing/free infrastructure. Do not introduce paid observability services merely for convenience.

## Priority 4 — audience learning
Only after baseline analytics/data governance are defined, implement aggregate privacy-respecting discovery/return/depth/subscription measurements across Search, Journal, Library, ONE and Devotional. Do not create identifiable religious profiling.

## Cost rule
Implementation is FREE-FIRST. Any approach that would require a new paid service must first produce a Cost Frontier decision record containing: demonstrated need, free alternatives, expected limit, minimum paid option, benefit, exit path and required human/church approval.

## Completion criteria
This program is not complete when schemas exist. It reaches first operational completion when:
1. all six Priority-1 foundations are machine-readable/versioned;
2. P01 produces a complete evidence bundle through them on a real job;
3. Conversation Alpha produces a complete internal-meeting evidence bundle;
4. Memory Sweep has reconciled historical records into the evaluation/capability model;
5. at least one observability signal has detected a real or injected failure and driven diagnose → repair/escalate → verify;
6. free-tier/cost status is queryable without manual reconstruction;
7. authority tests prove prohibited A3/A4 actions cannot silently execute.

## Anti-patterns
- Do not claim architecture text equals implementation.
- Do not buy an AgentOps platform by default.
- Do not log hidden reasoning, secrets, unnecessary personal data or sensitive spiritual profiles.
- Do not let a successful run bypass evaluation.
- Do not let a recommendation become authorization.
- Do not make one composite score conceal quality, cost, rights or authority failures.

## External engineering alignment
Current agent-engineering guidance independently reinforces this direction: production agents need traceability, explicit authority/least privilege, continuous evaluation, cost controls, versioned behavior and human oversight proportional to consequence. Doré should use such external guidance as comparison/evidence, not as a vendor-dependent architecture.
