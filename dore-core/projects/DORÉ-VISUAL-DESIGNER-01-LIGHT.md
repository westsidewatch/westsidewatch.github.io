# DORÉ VISUAL DESIGNER 01 — LIGHT

Status: ACTIVE / REQUIRED GATE
Established: 2026-08-26
Owner: Westside Watch
Learner / executor: Doré
Production surface: Penpot only
Reference role of Figma: learning/examples only, never production

## Purpose

Teach Doré to distinguish software-operation success from design success.

The gate is not passed by creating boards, layers, names, containers, rectangles, SVG shells, or successful MCP responses. It is passed only when Doré can research, design, render, inspect, critique, revise, and deliver one real reusable LIGHT asset for Westside Watch.

## Failure evidence that triggered this curriculum

Previous LIGHT attempts produced named elements, display cards, color blocks, thin lines, and empty/near-empty containers. MCP and workflow calls succeeded, but the visual result was not a usable asset. This is classified as a design-learning failure, not a Penpot transport failure.

Core defect:

`create object -> name object -> API success` was incorrectly treated as `design complete`.

## Governing visual constitution

- Living Paper is the canvas.
- Papyrus/material behavior makes the paper live.
- Ink Black carries form and internal structure, not the whole page background.
- Midnight Blue becomes a field only in true night.
- First Light Gold is rare: important names, stars, and edges actually touched by first light.
- Doré engraving is source grammar, not a pasted page template.
- Darkness must retain internal line/structure; no dead black masses.
- Atmosphere, scale, air, directional light, architecture, cloud, water and terrain are structural visual language.
- Original Doré works remain Editorial Content, separate from the website asset library.

## Training loop

1. REVIEW — read all current Westside visual constitution / VIS-GRAMMAR / Journal historical evidence.
2. RESEARCH — study external visual references for atmospheric light, engraving-derived contemporary identity, editorial/museum systems, and digital use of historical visual grammars.
3. DECOMPOSE — write transferable observations about direction, occlusion, value hierarchy, atmosphere, edge treatment, line density, negative space, scale, and material behavior.
4. PROPOSE — produce at least three LIGHT-01 compositional hypotheses before drawing.
5. BUILD — create only one candidate in Penpot; no family batch.
6. RENDER — export or otherwise obtain an actual visual rendering of the asset, not node metadata.
7. SELF-CRITIQUE — compare render to constitution and reference observations. Empty shell / color block / generic glow / decorative ray = automatic FAIL.
8. REVISE — repair or rebuild.
9. HUMAN GATE — only after Doré self-pass, show actual visible result for editorial judgment.
10. RETAIN — convert accepted corrections into reusable visual-design rules before creating LIGHT-02 or any other family.

## LIGHT-01 assignment

Working concept: dawn entering from the edge of a page / surface.

The asset itself must have transparent background and be separable from the Living Paper demonstration canvas.

Required visual properties:

- obvious directional cause: light comes from somewhere;
- non-uniform beam geometry, with occlusion/breakup rather than a flat triangle;
- atmospheric depth: at least foreground/mid/deep behavior or equivalent value layering;
- internal structure inside dark areas;
- edge illumination concentrated where form is touched by light;
- First Light Gold subordinate to the light event, not used as a gold wallpaper;
- usable when scaled and cropped at a website edge;
- composition survives both Living Paper and a true Midnight Blue test field;
- no dependence on labels, card borders, or explanatory text to look intentional.

## Automatic FAIL conditions

Any one condition fails the candidate:

- empty group/container;
- named layer with no meaningful visible geometry;
- zero-area or effectively invisible content;
- only rectangle/color-block composition;
- generic CSS-like glow/gradient without spatial cause;
- repeated parallel lines presented as "engraving" without form/air/value logic;
- solid dead-black area with no internal structure;
- gold used as a large fill instead of first-light accent;
- asset cannot be recognized without its label;
- no actual rendered visual inspection;
- no self-critique evidence;
- MCP/tool success used as design-quality evidence.

## PASS gate

Visual Designer 01 passes only when one LIGHT-01 asset satisfies all of the following:

- exists as real non-empty editable/vector content in Penpot;
- actual rendered output has been inspected;
- Doré records what changed after at least one critique/revision cycle;
- transparent-background asset can be used independently;
- demonstrates directional light + atmosphere + structured darkness;
- works on a representative Living Paper test and a true-night test;
- can plausibly be placed on a real Westside website edge/hero/card transition without becoming a decorative illustration;
- human editorial review accepts it as a real website visual asset.

Until this gate passes, SKY / STAR / WATER / CITY / EARTH / TRACE production is prohibited.
