## Reconciliation findings

### 1. Three Morning Star is correctly ACTIVE_PARALLEL, not complete

The master-teacher v0.1 document explicitly says the first autonomous discovery pass must **expand, verify, and saturate**. It also names concrete undercoverage: women scholars/teachers, Orthodox/Catholic traditions, African/Latin American/Middle Eastern/broader Asian scholarship, Jewish/Hebrew-Bible evidence nodes, archaeology/geography specialists, Second Temple specialists, manuscript/canon specialists, Chinese OT/church-history specialists, Cantonese/Hong Kong/Taiwan/Southeast-Asian Chinese corpora, and stronger canon-wide book coverage.

The document explicitly forbids declaring `LIBRARY/M1.5` until a fresh non-seeded pass reaches the saturation criterion. Therefore the canonical `3MS = ACTIVE_PARALLEL` classification is evidence-consistent and must not be promoted from the existence of a long candidate list.

### 2. Curated status is not doctrinal endorsement

Three Morning Star is a priority curation/study tier, not infallibility or blanket doctrinal approval. The corpus intentionally includes teachers from materially different traditions and interpretive positions, with explicit `ACCEPT`/`PROVISIONAL` distinctions and domain-specific cautions.

Durable rule: future Library UI/search/ONE integration must not collapse `Three Morning Star` into “Westside endorses every claim by this teacher.” Provenance, tradition/location, limitations and work-level evaluation remain necessary.

### 3. Live ingest contract is architecture/governance, not live-ingest completion evidence

`LIMING-LIVE-INGEST-CONTRACT-v1.md` defines the intended production path:

`discover → verify source → classify → write Liming Registry → build teacher/series/scripture/product edges → expose to Liming/ONE/Search → use → feedback → Doré learns`

It also establishes the correct storage boundary: external media remains at official/authorized source where linking is sufficient; D1 stores the mutable bridge/registry; R2 is for Westside-owned/derived assets or materials requiring durable self-hosting; GitHub stores contracts/schema/code/evidence rather than the growing live catalogue.

However, the contract itself is not runtime proof. This confirms the current canonical `LIBRARY-INGEST = ACTIVE_PARALLEL` interpretation and the existing requirement for one persisted authenticated ingest/readback cycle before any completion promotion.

### 4. Resource identity must survive subtitle/accessibility work

The curation project and live-ingest contract agree that subtitle/translation output is a derivative accessibility layer of the same library resource, not a second unrelated resource identity. Official Chinese access should be bridged first when available; Doré-generated accessibility is conditional on value, missing/inadequate Chinese access, and rights compatibility.

This is a durable cross-product constraint for P01, Library, Search, ONE and Westside Stories: canonical resource identity, provenance and rights state must survive the subtitle loop.

### 5. Search submission is a controlled discovery sensor, not an uncontrolled transcription queue

The Project 01 memory establishes a semantic biblical-domain gate before expensive subtitle processing. `ACCEPT_BIBLICAL` means in-scope for evaluation/possible ingestion, not automatic Three Morning Star status or publication approval. User-submitted URLs should first dedupe/enrich the existing registry and may contribute discovery provenance without conferring editorial authority.

This doctrine remains compatible with the currently blocked P01 critical path. Sweep 01 did not modify or resume P01.

### 6. P01 visual-upgrade brief is historically important but no longer governing as a single bundled priority

The August 24 P01 brief bundled subtitle preflight with a broad first ecosystem-wide visual-upgrade preparation track. Subsequent canonical decomposition now governs separately:

- `P01-PREFLIGHT` — active critical path, currently `BLOCKED / ENVIRONMENT_BLOCKED`;
- `VIS-LEARN` — `ACTIVE_PARALLEL` design education with explicit unfinished gates;
- `VIS-GRAMMAR` — separate purpose-built Doré-derived visual grammar workstream;
- `LIBRARY-V1` / `BRAND-V1` — later propagation stages.

Therefore the old brief remains valuable project-history evidence, but any reading of “P01 now proceeds on two connected tracks” as current sequencing authority is **SUPERSEDED** by the canonical Master Work Register. This avoids accidentally re-coupling visual-system work into the blocked subtitle critical path.
