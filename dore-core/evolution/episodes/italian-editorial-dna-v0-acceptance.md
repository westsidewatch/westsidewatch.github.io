# Italian Editorial DNA v0 — Evolution Acceptance

Status: IN PROGRESS
Parent capability: `publishing.dimensional-writing`
Episode: `evolution:italian-editorial-dna-v0`

## Purpose

Prove that Doré can turn a substantial research programme into a reusable capability without creating a parallel memory architecture.

This episode is not complete when the research corpus is large. It is complete only when the learned judgement can be recovered and used in a later task without method re-teaching.

## Acceptance sequence

1. **Corpus provenance** — issue evidence remains source-addressable, confidence-bearing and conflict-preserving.
2. **Same-source differentiation** — freeze one source image; selected editorial families/eras must produce materially different editorial intelligence rather than font/colour/crop variants.
3. **Cross-source transfer** — repeat on a semantically different source; a grammar passes only if the underlying judgement survives without historical motif copying.
4. **Unprompted task recall** — give Doré a real Journal/design task without naming Italy, Campo Grafico or any grammar ID. Relevant learned judgement must be selected from the task/content ontology.
5. **Negative selection** — give Doré a task where the learned Italian grammar is not justified. Correct refusal/non-use is required.
6. **Provenance backtrace** — an applied judgement must resolve backward to grammar, supporting issue evidence and source provenance.
7. **Later blind transfer** — after the episode is admitted and returned to Registry/Memory/System Atlas, a later materially different-domain task must reuse the capability without procedural re-teaching.

## PASS / FAIL discipline

A styled output is not a PASS.

A model saying it remembers Campo Grafico is not a PASS.

A successful named-style prompt is not a PASS.

PASS requires observable task behaviour plus evidence traceability.

FAIL includes:

- identical composition with only cosmetic style changes;
- automatic use of Italian-derived grammar on irrelevant content;
- invented historical rationale;
- requirement to remind Doré of the research before each task;
- creation of a second memory/index subsystem solely for this corpus.
