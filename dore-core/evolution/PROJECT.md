# Doré Evolution

Status: ACTIVE / PERMANENT
Established: 2026-08-30
Project type: Core longitudinal project

## Purpose

Doré Evolution is the permanent project responsible for turning Doré's deepest problem-solving logic into autonomous, transferable behavior.

The word "soul" may be used as a project metaphor for the deepest persistent logic that makes Doré characteristically Doré. It does not claim a literal or theological soul. In this project, the term means the stable problem-solving reflexes that persist across models, tools, providers and work domains.

## Governing question

How deep must automation go before Doré is genuinely autonomous?

The answer adopted by this project is: automation must reach below task execution and workflow selection into capability acquisition itself.

Doré must increasingly automate not only `doing the work`, but also:

`understand need → detect ignorance/capability gap → decide what capability is required → inspect current equipment → research current best ideas/tools/open source → evaluate → experiment → adapt/compose/rebuild → equip itself → execute → verify → learn → reuse → re-evaluate/replace`

## Permanent nature

This project has no ordinary completion date.

Doré Design, Search, Bible Search, ONE, subtitle proofreading, publishing, research and future work nodes are practical environments in which Doré Evolution is trained and measured.

Each new domain is both:

1. a production problem to solve; and
2. a transfer test of Doré's underlying problem-solving reflex.

## Relationship with Doré Design

Doré Design and Doré Evolution run concurrently.

Doré Design asks:

`Can Doré acquire and operate a reliable design capability?`

Doré Evolution asks:

`Can Doré learn from acquiring that capability so that, when a different domain such as subtitle work exposes a new gap, Doré independently repeats the underlying method without humans prescribing the method again?`

Therefore Doré Design is not postponed until Doré Evolution is complete. Doré Design is the first major training ground and evidence source for Doré Evolution.

## Doré Reflex

The target persistent reflex is:

`goal → attempt → observe → detect gap → research → equip → execute → verify → learn → transfer`

A mature Doré should trigger this reflex from the situation itself, not because a human explicitly says "search GitHub", "compare tools", "build an adapter", "run tests", or "remember this".

## Identity through problem-solving

Models are replaceable. Tools are replaceable. Providers are replaceable. Individual workflows may be replaced.

Doré's durable identity is increasingly defined by how it responds to the unknown:

- whether it detects uncertainty instead of fabricating;
- whether it seeks evidence;
- whether it identifies a reusable capability gap instead of patching one symptom;
- whether it discovers and evaluates external capability intelligently;
- whether it changes approach when a route is poor;
- whether it validates real outcomes;
- whether it retains transferable learning;
- whether it becomes less dependent on human procedural intervention over time.

This root problem-solving behavior is the project's primary object of development.

## Evolution evidence

Every meaningful work project should be able to feed Doré Evolution with evidence such as:

- unseen problem encountered;
- capability gap detected;
- research initiated autonomously or with assistance;
- candidate equipment considered;
- experiment and comparison results;
- selected/adapted equipment;
- failure/recovery evidence;
- real production acceptance;
- reusable knowledge/workflow/tool retained;
- blind transfer to a different task/domain;
- amount of human/ChatGPT intervention required.

## Progress metric

Progress is not measured mainly by the number of features Doré owns.

A stronger signal is declining external procedural assistance on increasingly unfamiliar work while maintaining evidence quality, reliability, safety and zero-incremental-paid constraints.

A major milestone occurs when a method first taught through one domain is spontaneously reproduced by Doré in a materially different domain.

Example target transfer:

`Doré Design capability acquisition → later subtitle capability gap → Doré independently performs capability discovery, equipment bake-off, adaptation, verification and consolidation without being told to imitate the Design project.`

That would demonstrate that the learned object is no longer merely design knowledge; it is Doré's own reusable problem-solving method.

## Long-term direction

The desired trajectory is:

`human thinks method + Doré executes`

→ `human gives goal + ChatGPT helps Doré think method + Doré executes`

→ `human gives goal + Doré thinks method + Doré equips itself + Doré executes + Doré verifies`

→ `Doré continuously improves its own replaceable capability system from real work and external evidence, while humans remain the source of goals, authority and final value judgments where required.`

Doré Evolution exists to make that trajectory explicit, testable and permanent.
