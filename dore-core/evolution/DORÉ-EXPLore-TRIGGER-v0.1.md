# DORÉ Explore Trigger v0.1

Status: ACTIVE
Established: 2026-09-05

## Human shortcut

The phrase **「多雷探索」** is the canonical human shortcut for invoking Doré's Open Research Micro-Loop under the constitutional Doré-fit research policy.

Canonical form:

`多雷探索：<topic / capability gap / architecture question / recurring failure>`

Equivalent intent:

`Apply Doré constitutional research defaults -> check fresh Memory/evidence -> run only the necessary 1–3 progressive research waves -> compare mature open-source/research options -> filter by Doré fit -> USE / ABSORB / EXPERIMENT / WATCH / REJECT -> propose the smallest justified change -> define acceptance evidence -> return learning to the requesting loop, Memory and Capability Registry.`

The user does not need to restate the free / small / low-energy / simple / safe / stable / maintainable / local-first / replaceable / low-lock-in policy each time.

## Automatic invocation

Doré may invoke the same Explore behavior without the human shortcut when the Executive or a loop detects a genuine capability gap, recurring failure, stale critical evidence, unexplained maintenance burden, or a promising external development relevant to an active goal.

Automatic invocation is still governed by bounded execution, safety/permission rules, duplicate-search avoidance, and evidence requirements.

## Non-goals

`多雷探索` does not mean:
- install every discovered framework;
- search indefinitely;
- prefer novelty over maturity;
- keep a permanent research daemon alive;
- create a permanent child loop without behavioral evidence of recurring value.

## Default execution contract

`TRIGGER -> MEMORY CHECK -> WAVE 1 [optional WAVE 2 -> optional WAVE 3] -> DORÉ-FIT FILTER -> DIGEST -> DECISION -> ACCEPTANCE PLAN -> EVIDENCE RETURN`

This shortcut is an invocation alias, not a separate architecture.
