# Asset Migration Milestone — Closure Criteria

The milestone is complete only when all of the following are true:

1. Batch 001 canonical Matthew 3 motion asset migrates to R2 and is registered in D1.
2. Batch 002 priority ONE media migrates to R2 with D1 registry verification.
3. Runtime/reference audit identifies which GitHub copies remain required during rollback and which are redundant.
4. No obsolete Matthew 3 revisions are reintroduced.
5. Canonical brand/UI vectors remain in GitHub.
6. Search/corpus JSON artifacts are explicitly excluded from media migration and deferred to a data-runtime milestone.
7. Inventory is updated from ACTIVE to COMPLETE with migrated/retained/deferred counts and no unresolved Priority A items.
8. Cleanup never removes a permanent/canonical asset without a verified R2+D1 replacement.
