# Hellenistic scaffold: shared registration package

The existing Hellenistic generator now publishes district, road, block, parcel and building records into the shared TemporalCityCore. Stable IDs bind the finished geometry; this package does not replace or refine the architecture.

Provisional district/road parents are staged together with residential children. Validation or ID collision publishes nothing. Disposal removes only the publisher's owned records. Re-entry uses cached geometry without duplicate publication. Roads as well as houses obey shared lifecycle visibility.

District and road records copy transformed geometry, not Herodian source identities, lineage or confidence. They remain inferred and reference-layout-derived, with geometryVerified=false. Their illustrative generation event belongs to the Hellenistic phase; fate in the following Herodian phase is unresolved. There is no inferred reuse, burial or historical continuity link.

Browser evidence: 32,754 visible Hellenistic components, all bound, zero unbound components and zero out-of-phase bindings. These are rendering counts, not an ancient building census. Existing full-timeline browser regression still reports fullTimelineReady=false. Foundation acceptance remains false; early and later unregistered generators still require coherent batch integration.

Validation includes atomic publication/collision rollback/owned cleanup, cancellation, parent relations, road and house event visibility, distinct rebuilding, return identity, 18-era desktop/portrait rendering and evidence filtering. No additional source download, image, terrain service or model generation was added; no measured network or token saving is claimed.
