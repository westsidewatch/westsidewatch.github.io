# Remaining later footprint batches

The existing Aelia, Byzantine, early Islamic, Ayyubid/Mamluk, outside-walls and modern illustrative masses now use the same shared publisher as Crusader/Ottoman morphology. The existing 18-entry footprint constants and mass builder move intact into legacy-era-fabric.js so the real generator can be tested without mounting WebGL. Positions, box dimensions, rotations and counts are retained.

All six batches are inferred block masses. Stable phase-scoped IDs bind generated components; they are not semantic buildings, surveyed district boundaries or named historical landmarks. There are 28/34/32/32/48/58 mass records respectively (234 total). Each has its illustrative generation event, with unresolved fate in the next phase where one exists. The modern phase ends the timeline; no imaginary future phase/event is added.

A shared scene registry survives rebuilding and refuses changed recipes or conflicting IDs atomically. Rebinding preserves event edits. Static mass visibility restores correctly when evidence/event filters change; animated Crusader/Ottoman construction remains governed by its existing progress before shared visibility gates. Owned records are cleaned up at scene disposal.

Provisional inherited layers remain separate. Their legacy retention ratios and reused geometry are not validated object survival. Foundation inspection continues counting these components as provisional/unbound even when a source phase now has registered mass IDs. This package does not fabricate successor links, burial or ancient ground, and does not certify complete adjacent-era transformations.

Validation extends the real-generator registration suite to all eight later batches: exact rebuilt transforms/IDs, geometry definition drift rejection, late collision rollback, event changes surviving rebuild, evidence off/on, unknown next-era fate and foreign ownership cleanup. Full browser checks require each six-era mass batch to be registered, with remaining unbound components accounted for by explicit provisional inheritance. Step 1 and foundation acceptance remain incomplete.

Existing data and geometry are reused. One small local module is added, without new external image/terrain/model service calls; no measured bandwidth/FPS/token saving is claimed. Architecture detail remains paused.
