# CITY-MASS-01B — 住宅批次繪製

本包只改繪圖提交方式，沒有重新排屋、縮放城市、細雕住宅或改寫歷史資料。具名地標、城牆、道路仍保持獨立。背景住宅的原始 Mesh、物件 ID、幾何、證據與生命週期綁定保留。

## 方法與邊界

- 在 96 公尺空間格內，合併材質、證據、生命週期狀態與緩衝格式相容的完整住宅；每批最多 64 個來源、32768 頂點，至少 4 個來源。
- 建立世界座標的渲染代理；每段頂點記錄來源 ID。只在 renderer.render 期間暫時關閉來源繪圖 layer，finally 恢復；檢查工具仍看到原始城市。
- 部分建造裁切、透明、特殊回呼、不支援的幾何／材質及近鏡頭住宅退回原 Mesh。鏡頭微移且成員不變時重用批次。
- 額外合併緩衝僅保留目前時期，切換時期或停用即釋放。這不是減少原始城市快取；希律總覽額外約 7 MB，換取較少提交。
- 播放後回到手動檢視時，在當幀視覺樣式套用前回收建造裁切材質，恢復共用原材質，避免每戶各留一份動畫材質。
- 研究工具提供「住宅批次繪製」開關與 inspectHousingBatches；不增加首屏操作負擔。

## 驗收方式

Node 驗證世界座標／法線完全一致、頂點範圍可追溯、來源不變、裁切／證據／材質回呼退回、相機快取、變形失效及資源回收。

瀏覽器逐一對比 18 期開關：實際提交、三角形、畫素差異、住宅數、地標、邊界、相機、證據篩選、逆向切期與手機版。暖快取計時只量 CPU 批次準備與 renderer 提交，不代表 GPU 完成、FPS 或首次載入提速。

上一包 CI run 44335745899 在 25 分鐘上限取消：基礎、全時代視圖與導覽組已通過，末組尚未完成。依實測調整為 35 分鐘，不能把被取消的 CI 記作全綠。新提交仍須獨立追蹤完整 CI。

後續應量測各時期首次生成、資產讀取與快取成本，再決定預建／按需載入；不以增加一般住宅細節作為下一包。
