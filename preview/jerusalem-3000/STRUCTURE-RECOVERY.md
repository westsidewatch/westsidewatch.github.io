# 恢復城市結構工程

2026-10-25。前一包統一了住宅表示，未完成城市結構；18米方格內院不是後八期的歷史街區。共同語法／相機測試只能證明渲染一致，不能作為城市基礎驗收。

## 本包實際修正

後期生成器從同一期的道路、住區和宗教核心共同產生場景。新增 `later-sacred-cores.js`，沿用原有共同帳本、地形、證據篩選和生命週期發布，不另建平行城市。宗教核心只有粗主體，不做門窗或材質雕刻。

**來源支持類型和時代語境，沒有提供本包採用的坐標、邊界、尺寸與高度。** 這些參數是編寫的概覽示意，登記為 inferred / geometryVerified=false，不能稱為測繪模型。共同現代DEM逐頂點適配也不是古代台基。未建立未經證明的跨期重用連結。

住宅區塊不得佔用核心示意包絡。既有示意路徑若穿越包絡，交疊的顯示路段暫不繪製；不擅自補出歷史繞行道路。骨架圖保留原始路徑語境線，表示層的這一缺口仍需配準解決。

## 接續工作順序

1. 全線城界、城門與核心—主街關係：先補來源支持的輪廓和簡單量體。現有缺口矩陣保留；每一期須交代可繪、待配準、年代有爭議的項目，不能把「未知」長期當作「完成」。鄂圖曼等已知有城牆的階段仍缺配準線，不能回退為規則矩形圍牆。
2. 在上述結構上修正住區範圍、街區邊界、道路接續與密度，替換後八期固定方格住宅表現。此包**沒有完成方格替換**，不以增加宗教量體宣稱城市已修好。
3. 再驗證17段相鄰變遷與反向重建；來源支持的保留、新增和毀壞才產生對應事件。
4. 18期同尺度全景、街區尺度與手機對照均通過結構審查後，才恢復代表建築細化。

## 驗證界線

後八期整合測試要求核心數、同一期綁定、來源披露、住宅／顯示道路避讓、證據篩選往返、穩定重建、無假重用關係和清除完整；共同骨架圖能讀取新增的核心。全18期瀏覽器驗證維持帳本範圍完整及無執行錯誤。這些測試不是歷史認證；foundationAccepted繼續為false。
