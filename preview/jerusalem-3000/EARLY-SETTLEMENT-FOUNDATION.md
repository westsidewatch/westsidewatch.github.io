# B17: four early settlement model relationships

All four early owners now publish a residential model envelope with their existing dwelling/path batch. It is the convex envelope of actual displayed roof bounds, not a new city wall, excavated district, measured occupation extent or claim that all enclosed land was built. It does not generate houses, roads, civic buildings or recolour a large area of the terrain.

Each existing dwelling keeps its object ID, geometry and lifecycle. Its source now references the model district, and its metadata records the nearest existing model path, projected point and centre-to-path distance. There is no drawn connector or asserted house entrance/road access. A path-distance relation can cross obstacles; it is an index for review, not proof of traversable access.

The first three contexts reference their existing footpaths. David/Solomon uses only already-published David-stage royal path IDs and the existing spatial definitions. Solomon-stage roads are excluded from this early housing relationship. Existing royal regions, walls, temple, courtyards and routes are not replaced. If the royal source IDs are not published (such as an isolated unit fixture), the missing relation stays unresolved instead of inventing a road.

The district has its own stable phase-specific ID and explicitly unknown next-phase fate. No physical inheritance/reuse link is created. Publication, collision validation and ownership cleanup remain atomic with the existing residential publisher. The district has no city mesh; no new 3D landmark, footprint or boundary is asserted.

The existing “空間骨架對照” map shows the model envelope with a dashed green stroke and the house/district/path accounting below the map. Inferred filtering removes the context. The common foundation inspector reports the same relationships, including missing paths, without generating inactive scenes. The normal city continues to show the same roofs/paths at the same scale and on the original DEM.

Tests compare published versus unpublished mesh coordinates byte-for-byte, verify actual roof containment, existing path references, exclusion of future royal routes, phase/evidence isolation, collision rollback and cleanup. The full18-period runtime includes assertions that each of the four active settlement owners has all model dwellings district-linked and route-related. These counts do not constitute historical acceptance; the18 source reviews and17 physical transition reviews remain pending.
