# Early settlement shared object registration

The existing four early landscape runtimes now publish their illustrative dwellings and footpaths to the shared TemporalCityCore. IDs and finished geometry are retained. Each semantic building represents its existing composite footing/wall/roof components; bounds are descriptive and do not become box building geometry.

Publication stages the entire batch and validates before replacing shared maps. A collision, including one after earlier records have staged, changes neither ledger nor scene. Disposal removes owned records only. House component IDs are deterministic. Source context and illustrative authority remain explicit; confidence stays inferred.

Generation has an illustrative build event in its own phase. The following phase records unresolved fate, with no inferred survival, demolition, burial or reuse links. Visibility and house counts read the shared event state, while evidence filters and phase isolation continue to apply. Return preserves mesh geometry and transforms.

Water-defense components retain their existing separate source adapter. Spring location symbols, disputed stepped support, and the royal location symbol are excluded from this publisher; no archaeological identity is invented for those markers. District and parcel parentage is not fabricated for these point-layout illustrations. The common foundation remains incomplete and unaccepted.

Tests: four-era batch publication, composite identity, road and house event visibility, explicit next-era unknown fate, exact return, evidence filters, first/late collision rollback, scene resource cleanup, foreign ownership preservation, existing terrain/earliest/water-defense regressions and full timeline browser acceptance. The new test runs in city runtime CI. Existing settlement JSON, terrain and meshes are reused; the small local JS adapter adds one module load, with no new external service/data request or measured traffic-saving claim.
