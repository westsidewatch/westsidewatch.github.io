# 生成住宅的共同帳本接線

M1／M2 第五批，限定獨立配置的第一聖殿晚期與波斯重建。希律 canonical 原有住宅已在主 Core；其他時期的住宅 adapter 尚未統一。這不是所有時期的完整住宅帳本。

生成器仍先在暫存 Core／隱藏 group 完成建築。`generated-residential-ledger.js` 驗證共同地區、物件型別、ID 衝突及完整住宅→地塊→街區→地區鏈，再一次替換主 Core 的索引。未完成／已取消的模型不發布；失敗不留下半套帳本。修正地塊來源的街區 ID 前綴，使每一層父物件都可解析。每棟住宅記錄 standing bounds、推定來源、生成時期及幾何／再利用未核定標記。實際組件使用同一住宅 ID 與穩定 component ID。

晚期住宅：建造示意→毀城示意→波斯可選前代遺存；波斯新住宅為不同物件 ID。街區／地塊在波斯期的具體留存未核定；後續幾何去向一律 unresolved，不把本次模型帶往下一時期。沒有建立物理復用鏈，廢墟比例、埋深與住宅形制均未考古核定。render projection 的可見性從主 Core 事件讀取；倒塌量仍由共用進度引擎控制。資料去向與示意倒塌幅度不是同一件事。

完成模型留在快取，往返不重複發布。釋放時只移除該生成器擁有的住宅、地塊與街區，保留原有地區與其他主體記錄。驗收涵蓋中途取消、身分碰撞、帳本去向修改、父鏈解析、倒退、分期重建與清理後索引。

Evidence 新增「住宅分區 · 推定示意」表：街區數、住宅模型數、當前顯示住宅數。毀城保留同身分，波斯開啟前代遺存可對照三個前代區與兩個重建區；證據篩選會更新顯示數。數量不代表古代人口／實際建築數。資料尚未生成／失敗時不把它顯示成完整驗收。表格不對使用者暴露組件／ID／生成器細節。

診斷只提供每區摘要與少量樣本，不在每次畫面更新序列化整份帳本。`inspectCityObject(id)` 是按需的唯讀診斷副本，用來追查父鏈／來源／事件；沒有新增遠端資料或模型調用。既有共用 JSON 仍只請求一次。沒有 Jev 入口或 token／硬體 FPS 測量的新結論。

相關 Node 與18期桌面／手機視窗瀏覽器回歸通過；`fullTimelineReady:false`。仍待完整來源定位、古地表、各期住宅形制、早期其他城市 adapter、城防與水系。下一包依既有空間配置盤點城防／取水缺口及可定位來源，保持整體主線。
