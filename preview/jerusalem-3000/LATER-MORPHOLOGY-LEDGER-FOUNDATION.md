# Later morphology shared registration

This package registers the existing Crusader and Ottoman morphology batches in TemporalCityCore. It does not refine their architecture or certify historical plans. Each generator's deterministic recipe order gives stable phase-scoped IDs. The shared registry survives renderer teardown; returning rebinds freshly generated geometry without duplicating records or overwriting edited lifecycle events.

Anonymous quarter, market, sacred and civic box masses remain provisional blocks with their generator role recorded. Roads, walls and explicit gate-role components retain inferred role types. No mass becomes a semantic single building or named monument; semanticBuildings stays zero. Confidence remains inferred even where the legacy generator used an observed-colored material. No archaeological source location or district/parcel parentage is invented.

Each record has an illustrative generation event in its phase and unresolved fate in the next phase. Existing procedural construction timing is animation, not historical dating. Shared event visibility and evidence filters apply after the construction projection, without changing geometry, terrain or animation progress. Rebuilt IDs, transforms and definitions are checked; altered recipes require an explicit migration rather than silently overwriting stable identities.

Whole-batch validation and ID collision checks occur before publishing or binding meshes. First or late collision leaves existing records and incoming mesh identities unchanged. Owned records persist for inactive inspection and are removed only on scene disposal. Existing source records and other generated publishers retain ownership.

Validation covers both real generators, exact return IDs/transforms, preserving shared event edits across rebuild, road/wall/block role scope, evidence filters, recipe migration rejection, late collision rollback and owned cleanup. The new test is included in city runtime CI, alongside the full 18-era desktop/portrait browser test.

The common foundation remains unaccepted. Legacy footprint eras, provisional inherited layers, named landmark verification, ancient ground and source-specific districts/routes still need work. A bound rendering component does not establish a historical building count or verified survival. Existing geometry/data are reused; this package adds a small local JS module, no external service or image/model generation request. No measured bandwidth, FPS or token saving is claimed.

Browser evidence at phase progress 0.9: Crusader 74/74 visible components bound; Ottoman 171/171 bound (174 registered recipe objects, with three not yet visible at that progress). Both have zero unbound and out-of-phase bindings. Full 18-era desktop/portrait regression passes with errors=[] and fullTimelineReady=false. These are model scope counts.
