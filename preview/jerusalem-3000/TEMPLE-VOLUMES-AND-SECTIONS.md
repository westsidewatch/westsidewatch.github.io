## Viewing the space

A `聖殿剖視` button enables an interpretive horizontal presentation cut across first/Persian/Hasmonean/Herodian temple meshes. This is NOT historical destruction or an assertion of a missing roof. It clips displayed upper geometry and its construction shadows while preserving source geometry, object IDs, evidence filters, lifecycle, cached models and original materials. Closing it restores the original materials/depth materials and full geometry display. No cut is applied to houses, terrain or later Islamic monuments. The cut height is an authored inspection choice4m above each principal temple floor; it is not an ancient floor level.

Herodian close view now uses a nearer desktop framing, so the temple/court relation is legible. Portrait framing remains more conservative. User rotation/zoom still works; landscape overview geometry and camera are unchanged.
