# 早期第二聖殿與時期空間帳本

M2 第三批，未完成全部 M2 或歷史全城。

`first-temple-persian.spatial.v1.json` 的波斯 `sanctuary` 節點是獨立形制配置。主殿使用分面牆、門洞與平屋頂，另有前廊、示意祭壇、院牆及入口。尺寸、位置、屋頂及院落形制均為設計推定，不引用第一聖殿組件、希律形制或已核定地基。

[以斯拉記六章](https://search.biblegateway.com/passage/?search=Ezra+6&version=KJV) 提供重建敘事。詔令的高度／寬度數字不在此當作建成平面。宗教制度延續也不證明具體建築原樣留存。因此共享主體 ID `j3k:object:second-temple-early` 保留既有後期事件，但 `geometryValidityPhases` 只含波斯期；後期不顯示這套幾何。

## 共同空間來源

`period-spatial-ledger.js` 由同一配置衍生晚期／波斯地區、道路、聖區保留、波斯院門及聖區入口的帳本 ID 與示意顯示事件。原始 anchor/lifecycle JSON 不重複編輯這些記錄；renderer 把同 ID 的世界座標幾何綁到 canonical Core。所有消費者仍共用一次 period JSON 請求。

入口步徑從現有波斯北部道路的末端接到院門，末端由主殿前廊入口參數衍生。配置編譯器拒絕門寬、院界、保留區與入口衝突；實際三角形不穿地面院牆、殿牆或祭壇。整塊聖區用於排除住宅；外部道路僅避開實際主體障礙，避免保留區邊界裁掉最後一段接入道路。已驗證執行器生成的道路抵達入口步徑起點。這是步行動線示意，不是水渠。院牆亦非尼希米城防線。

近看按鈕在波斯期使用第二聖殿焦點；離開該時期恢復原先鏡頭約束。Evidence 明列來源和形制未核定；只選實證層會隱藏推定構件。第一聖殿在波斯期仍為去向未核定，不重現成第二聖殿；沒有增加物理复用鏈。

## 驗收與限制

Node：共有來源去重、獨立 ID、地形接觸、實際步徑避障、無效門／道路／保留區拒絕、入口跟隨殿參數、後期形制隱藏、往返身分及資源釋放。Browser：一次 period JSON 請求、兩聖殿分離、過濾、近看、往返及18期桌面／手機視窗回歸。全時間軸 ready 仍 false。

修復 CI 依賴安裝順序：Three.js/Playwright 安裝先於匯入 Three.js 的帳本／幾何測試。上一提交 CI 在安裝前執行幾何測試而失敗；本機既有依賴沒有暴露這個問題。

主體仍是推定量體，住宅仍以沿街骨架為主。住宅完整帳本、水系、經核定城防、古地表及後期聖殿改造沒有完成。下一包改善多區住宅連片與全景可讀性，仍以同一空間配置和時期 ID 為約束。
