# B11 · 城內量體 → 城牆 → 逐門形態

先驗收實際城市量體，才深入城防。`inspectCityEnclosure()` 逐一讀取當前可見住宅、街區及公共核心的實際投影三角形，與同一期既有選定城界比較；只讀、不以隱藏越界公共建築取得通過。門樓和城牆可跨城界，標示不算建築；最早無完整城界仍列未定，後期明確登記城外擴張另列。通過表示模型與選定城界一致，不表示歷史城界已測繪核定。原 DEM、米制尺寸及公共預留不變。

站立中的推定包絡牆改為連續牆段，仍以赭色區分推定。毀城殘牆、1219拆牆與未定候選帶繼續保留相應缺損，不把所有年代補成完整高牆。晚期沿原七條地圖牆線增加垛口；原始來源開口仍另列，未任意改動牆線。

## 現存八門的粗形態參照

只在奧斯曼、城外擴張、現代三個選定階段使用較晚／現代形態。八個名稱、位置來源及逐門尺寸／形態權限記在 `data/urban/named-city-gates.v1.json`；凍結 OSM 節錄與 SHA256 一起保存。門寬深高是公尺制示意設計，並非立面測繪。地圖建築多邊形僅作位置與量級參照，尚未直接復原不規則外輪廓。

| 門 | 本批辨識量體 | 明確限制 |
| --- | --- | --- |
| 雅法門 | 方形彎折門樓、正面入口接側面出口 | 不含1898鄰接馬車缺口等完整變遷 |
| 大馬士革門 | 大型門樓、前側雙塔、彎折通路 | 內院、精確塔形及裝飾未復原；羅馬下層門另屬早期模型 |
| 錫安門 | 方形彎折防禦入口 | 不刻畫1948等戰損細節 |

## 實際通口、道路與成本

門樓沿原牆切線及城內法向放置。節點來源是入口，建築來源是量體中心，兩者不混用；原有雅法／大馬士革門 ID、來源座標保留。以門樓外廓及局部通口切除穿過入口的牆體；七座開放門以實際空洞連接同期主街，金門沒有通路。彎折門先進內部再從側面出口轉向街道。道路依通口寬度收窄，預留門樓與通路後再生成住宅。近看選單只列當前可見門。

一份小型 JSON 啟動時讀取一次；八門幾何在三期之間共用且倒退重用。不新增圖片、模型或 DEM 下載。新增三維幾何／通路成本，不宣稱測得速度、流量或模型用量節省。

下一批仍應先完成所有時代城防／門的來源矩陣與共同驗收，再按可考證程度做古代個別門形。古代方位入口仍是候選位置，不套現存八門、不宣稱全時代城門已完成。歷史幾何及實體構件繼承仍不驗收。
