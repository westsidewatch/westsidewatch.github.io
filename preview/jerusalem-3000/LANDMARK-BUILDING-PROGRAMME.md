# Jerusalem 3000：全18時代建築群主規劃

2026-10-29。依使用者要求，本輪先列建築群與場所／路線，再決定建模；一般住宅退為背景。本文件與 `data/landmark-building-programme.v1.json` 是建造前主清單，不是另一套城市或可執行生命週期帳本。本輪不新增城市模型，不宣稱66項候選都已核定，也不把清單通過當作歷史驗收。

## 工程改向：先建立可辨識的城市主體

現有小房子主要是推定住宅或街區模組。前幾批雖補上邊界過濾和公尺比例，城防假說、住宅區範圍、公共核心與現代地表仍各有來源／配置，沒有完成同時代空間整合。城內大片留白也不能直接解釋成歷史山地：其中包括尚未配置的公共／宮殿群、未建模住宅區、未配準區域，以及缺乏古地表／台地資料的坡面。

接下來不再以增加小房子、提高屋頂覆蓋率或放大模型作為主要進度。每期先完成「聖域／祭祀—王室／軍政—供水／公共—門路／朝聖」的可辨識建築群與相互關係。來源不足時明列缺口，不為每期硬造同樣數量的地標。

## 每個建築卡都要回答的問題

1. **身分與版本**：建築、建築群、自然場所、水工或路線？是否同址不同建築？每個可分期子建築有獨立身分。
2. **時間**：何時開始、何時完成；毀壞／改建／重建是哪一部分。精確年份、約略世紀、故事展示進度不能混用。
3. **位置**：經定位的出土平面、可靠的歷史區位、現代傳統位置還是爭議候選？不能隨意填GPS或搬位置配合城牆。
4. **尺寸與高程**：實測公尺、文獻肘數及換算方案、推定高度分開。不得因地標不顯眼便任意放大，古地面也不能直接等同現代DSM。
5. **城市關係**：當期城牆內外、城門、主街、跨谷路徑、山脊高差、院區與其他地標的距離。
6. **表示等級**：可建粗量體、只能畫不確定區／候選、只放場所標記，或僅保留研究卡。文獻建築可以有明示假說，但不冒充精確考古復原。
7. **下一期去向**：保留、功能改變、擴建、拆除、廢墟、重建、未知。不能一到下一期就清零；也不能憑同址宣稱原構件保存。
8. **准入狀態**：已存在的示意模型不等於已通過上述審查；先核對，再替換表示，不重造另一份物件／事件帳本。

## 七條優先跨期鏈

- **北部聖域**：第一聖殿／586毀壞 → 早期第二聖殿 → 哈斯蒙尼變更 → 希律重建擴張／70毀壞 → 後續場所狀態 → 伊斯蘭聖域建築 → 十字軍用途轉換 → 後期修復。場所連續不等於同一建築。
- **王室—軍政**：大衛王室候選 → 所羅門複合群 → 晚期王室／586毀壞；另一條是哈斯蒙尼軍政候選 → 希律宮／三塔、巴里斯／安東尼 → 羅馬以後個別去向，不能混成一座城堡。
- **西部城堡**：各期出土層 → 希律三塔的個別遺存 → 後來軍事／王室城堡 → 阿尤布／馬穆魯克變更 → 奧斯曼整修 → 博物館／保存；逐部分核對。
- **各各他／墓園—聖墓群**：一世紀事件場所 → Aelia相關建築層候選 → 335建築群 → 614損壞／修復 → 1009毀壞 → 1048重建 → 十字軍改建 → 後期火災／修復 → 現代保存。依[聖墓守護機構的分期敘述](https://www.custodia.org/en/sanctuaries/basilica-of-the-holy-sepulchre/)逐階段配準，不以同一完整堂體跨越所有時期。
- **取水—蓄水—朝聖通路**：泉與防護 → 古代供水／蓄水構件 → 第二聖殿期大池與街道 → 拜占庭水池／教堂 → 後續變更，參考[國家公園構件說明](https://en.parks.org.il/reserve-park/jerusalem-walls-city-of-david-national-park/)。
- **樓房—早期教會—中世紀紀念建築**：事件與傳統位置先分清，再決定能否建立同址／同建築關係；不預先宣告實體繼承。
- **近現代可核對鏈**：胡爾瓦舊堂 → 1948毀壞 → 2010重建，作為具體分期示範，參考[官方文化遺產出版品](https://services.israelpost.co.il/postboolaee.nsf/all/8A2B339645B84B30C2258C730052175A/$file/%D7%94%D7%97%D7%95%D7%A8%D7%91%D7%94.pdf)。

## 建造順序：全期按層推進

|步驟|交付|檢查條件|
|---|---|---|
|A 建築群目錄（本輪）|18期主表、候選卡、場所／路線分層、17段審查邊|使用者點名項目不得漏列；未核定項目如實標示；不新增一般住宅。|
|B 位置與城市骨架|各期地標—城牆—城門—主街—山脊谷地疊圖|先解決內外矛盾；城內留白逐塊分類，不把未建模當作歷史空地。|
|C 主體量體|來源允許的聖域、王室、軍政、水工／公共群|同一公尺比例、同一地形；以可辨識輪廓／材料／標籤突出地標，不放大；不在單一期陷入細雕。|
|D 跨期事件|分對象的建立、毀壞、重建、改用途與未知去向|回寫既有來源生命週期；覆核全部17段，而非只有希律能看到建造。|
|E 背景街區|依已核定核心／通路／院區補住宅背景|住宅不能先占掉王宮／公共區，也不能用屋頂覆蓋率代替歷史正確性。|

C、D均按所有適用時代橫向補齊同一基礎層；不表示每期必有同樣的地標，更不表示一次就能完成66項實測復原。已核定或來源允許的主體先做；爭議建築用明示假說／候選區，研究缺口繼續保留。

## 城牆與大片山地：這輪尚未解決的實體問題

本輪完成的是建築群規劃，不是宣稱現行城市空間已正確。下一步B必須把同時代地標與牆線交叉註冊：一世紀各各他／墓園的城門外關係、王宮與三塔在西部上城、泉—山脊—北部聖區的相對位置，以及聖墓／Nea／聖域行政群的院區／主街。當它們與現行模型相衝突，應回到來源修改錯誤的城廓／分區，而非搬地標、擴牆、壓平山地或再塞小房子。

現代期窗口也須另查；[死海古卷館的館方建築資料](https://www.imj.org.il/en/exhibitions/architecture-%C2%A0shrine-book)和[城外拓展項目](https://jerusalemfoundation.org/old-project/mishkenot-shaananim-cultural-center-guest-house/)不構成把西部城市地標搬進舊城的理由。

機讀清單：`data/landmark-building-programme.v1.json`。清單驗證僅表示期別、引用和區分規則完整，不表示候選幾何已准入。`historicalGeometryAccepted=false`，網站不載入這份候選生命週期，亦不覆寫既有執行事件。


## 執行包 B1：同址地標配準與住宅形制修正

- 聖墓教堂（拜占庭起）與岩石圓頂建築（早期伊斯蘭起）共用各自的固定地理展示錨點，修正進入奧斯曼期的座標跳動。位置引用凍結現代圖資；早期建築平面、古地面及構件繼承仍未核定。這不表示現代建築中心就是古代聖墓或岩石的實測座標。
- 四室住宅類比現在影響總覽屋頂：兩側長屋與後側橫屋圍出開放中軸；不再只掛四室名稱卻畫成完整環形院落。大衛期屬較晚形制的推定類比；晚第一聖殿期有 Area U 的四室平面參考。屋頂安排不宣稱考古復原。
- 巴比倫毀城沿用第一聖殿住宅，羅馬毀城沿用希律住宅；不得為了區別時代重造全城。波斯與希臘／希律的住宅類比仍須與來源分別核對。
- Aelia、拜占庭、早期伊斯蘭、十字軍、阿尤布／馬穆魯克、奧斯曼、城外拓展與現代的住宅目前仍是粗街區院落。尚未完成各期住宅建築准入；後續按同一輪次查證屋頂、層數、臨街界面及新舊城區混合，不能把所有穆斯林住宅一律加圓頂，也不能把現代舊城全部換成高樓。

本包沒有新增住宅密度、放大建築或改動地形。B 的牆門街配準、C 的其餘地標主體及全期住宅差異仍在後續待辦，不因本包通過測試而視為完成。

## 執行包 B2：地標—當期主街的共同接入規則

既有聖墓／岩石圓頂建築的全部適用期（拜占庭至現代，共7期）現在由共同配準器建立「當期主街 → 示意院區邊界」的連接。原先只有奧斯曼及其後2期有這條規則，較早4期缺少同等接入／住宅避讓。Aelia及更早各期不因此出現未建成的教堂或圓頂建築。

連接選擇當期既有西部／東部軸線的最近外部投影點，而不是只選折線頂點，終點停在核心邊界。它是設計接入，不指認古代入口，也不是新考證的歷史街道。住宅分割沿用既有道路淨空規則，渲染沿用核心排除區，避免為接路改動地標位置或尺度。後期牆門參照仍只適用最後3期，未向前投射奧斯曼城牆。

本包只覆蓋目前已有量體的兩組宗教地標；不是66項候選地標的配準全部完成。其他地標、各期住宅類型、同址建築內部版本及古地面仍待來源准入。


## 執行包 B3：全期住宅形制狀態與總覽對齊

[RESIDENTIAL-ERA-PROFILES.md](RESIDENTIAL-ERA-PROFILES.md)登記全部18期目前表示與來源缺口。波斯開放院落及鐵器四室類比的總覽對齊既有低層模型；毀城階段保留原模型形制。頁面及診斷可查當期狀態，全部18期檢查實際網格而非只查標籤。後期住宅多樣性仍未完成，地標配準及公共核心仍優先，不增加住宅密度替代地標建造。

## 執行包 B4：全18期共同地標表示與實際量體對照

所有生成器使用同一套地標標示：只從本幀真正可見、綁定到帳本且分類為公共核心的量體產生標記；依證據篩選、建造裁切及毀壞投影更新。這不是在空白候選位置補標籤，也不把地理參照當作已建造建築。標記指向模型中心，不是實測入口／基址。桌面最多6個、手機最多3個，與地形／城門標籤及控制列避讓；使用者可用「地標標示」切換。沿用現有建造掃描結果，不新增第二座城市或重新生成模型。

CI 由18期實際渲染報告產出`landmark-execution-audit.json/.md`，逐期對照規劃建築群、既有物件ID與可見公共核心量體。18期缺一期、畫面與當期不符、量體與帳本綁定數不符均使檢查失敗；有示意對應不自動通過歷史幾何驗收。每包仍需跑共同18期／17轉場基準，而不是只驗一個時代。

本輪對照顯示：希臘化／哈斯蒙尼、Aelia的公共核心量體層仍空缺；拜占庭只有聖墓，其餘後期多半只有聖墓與岩石圓頂兩組。現有王室／聖域也多屬示意，不能算完整建築群。最早三期沒有可核定具名地標時，不為湊數補宮殿或神廟。下一輪依同一18期建築群表優先補來源與主體缺口，不再靠住宅細節或數量抬高完成度。

## 執行包 B5：阿克薩南部禮拜堂主體，跨6個適用期

新增的是可見建築量體，不是研究卡標記：長形七廊主廳、較高的中央坡屋頂、南端穹頂；十字軍期起另有東側增建示意。六個時期各自持有物件ID，接入共同地標、路網、院區預留及住宅避讓；其他12期不出現這座建築。

[MWNF／聖域考古主管的建築條目](https://islamicart.museumwnf.org/database_item.php?id=monument%3Bisl%3Bpa%3Bmon01%3B3%3Ben)記述主廳現狀約50×80公尺、早期反覆改建、十字軍改用及後期修復。此處只借現狀尺寸作選定較晚形態的比例參照；早期伊斯蘭概覽明示選取十一世紀法蒂瑪重建後語境，不把它當作七世紀／伍麥葉原貌。六個大分期內的每次地震、改建與修復尚未逐事件建模。

展示錨點在岩石圓頂建築以南的既有聖域語境內，是相對區位設計，尚未轉錄考古平面／測繪座標。模型屋高、廊寬分配及東側增建形體未經測繪核定。上部量體保持水平，底部接同一現代DEM；這是落地適配，不是古平台標高復原，也沒有修改地形。不能用現存主廳大小推定每個前代版本。

各期仍沒有接受歷史幾何或原構件繼承。全18期量體矩陣、住宅邊界、手機、逆向快取與17段轉場按共同基準覆核；希臘化／Aelia及其他地標缺口繼續保留，不因六期新增一組建築而宣稱全線完成。

## 執行包 B6：Nea 新聖母教堂與南部 Cardo

拜占庭概覽新增543年後的Nea示意主體：五廊巴西利卡、較高中央屋身及坡屋頂、三個朝東後殿、開放前院。主教堂115×57公尺參照[外交部考古概述的轉載](https://jewishvirtuallibrary.org/jsource/Archaeology/Nea.html)，建造背景交叉參考[希伯來大學所錄文獻](https://dig.corps-cmhl.huji.ac.il/literary_sources/jerusalem-old-city-new-church-theotokos-nea-church-4)及[基金會遺址說明](https://jerusalemfoundation.org/old-project/nea-church/)。前院尺寸、屋高、內部比例、中央後殿半徑及相對位置仍是設計，不是發掘平面轉錄。

Nea使用西側Cardo接入，不套用東側聖域動線。整個建築及前院落在共同預留區內；住宅和道路避讓依既有規則執行，不擴城牆、不改地形、不縮放建築。上部保持水平，底部接現代DEM，不宣稱地下基座或古地面已復原。

本期是選定的543年後概覽，不表示四世紀已建成。後來延用、受損與停用分期仍需原始發掘報告核對；下一期既有生成帳本標成unresolved，不繪製一個捏造的614年全毀版本，也不把完整堂體直接延伸到後世。未顯示不能讀作歷史不存在。後續需將有日期的子階段接入既有生命週期，這一點尚未完成。

全18期的量體—帳本對照、住宅邊界、手機、逆向快取及17段轉場仍一起覆核。Nea只有符合所選歷史語境的時期加入主體；其他時期不為湊數新增同樣建築。公共核心和歷史幾何完整性仍未驗收。

## 執行包 B7：羅馬北部紀念門與門內廣場

Aelia及拜占庭北部入口沿用既有`defense:gate:north`物件，替換通用門框，增加三孔拱門、兩側高量體、門內鋪地與紀念柱示意。城門仍分類為gate，未為抬高公共建築數另建一個monument；主街連接沿用既有物件。兩期相同幾何可共用緩衝，但不據此核定原構件存續。後期不直接複製這個版本。

[遺址營運機構](https://www.pami.co.il/en/attractions/the-roman-square-museum-at-damascus-gate/)記述超過40公尺寬、約20公尺高的羅馬門，及拜占庭Madaba圖中的門內紀念柱；[IAA發掘](https://hadashot.iaa.org.il/Report_Detail_Eng.aspx?id=26040)確認羅馬鋪地，僅推測可能屬廣場。此處44公尺門體為量級參照，三孔細部、柱高和廣場範圍為設計。沿用的入口線位仍為現行示意城防帶，沒有宣稱已定位到大馬士革門下的發掘平面。

城牆模型為完整門體留空，不用舊的12公尺中央門洞封住側孔；住宅同時預留完整門體與廣場範圍。地形不修改，未把上部水平量體的DEM落地適配當作古地面復原。

共同地標表示現在可包含有明確旗標的gate，仍保留原始語義分類。18期執行矩陣v2分列`visibleLandmarkIds`及原有`visibleMonumentIds`，不把指定城門冒充聖域／公共monument。Aelia的神殿、營區和其他公共建築仍有缺口。來源、位置及歷史幾何均未正式驗收。

B7接街補充：紀念門通路先垂直穿過中央孔進入門內，再轉接主街；主街接點限定於門內一側。既有源線保持不動。對測試路網與實際生成路網都以三條平行射線檢查整條通路，避免斜線切過門墩或紀念柱；路徑仍是設計接入，非新核定古街。


## 執行包 B8：希臘化—哈斯蒙尼聖所與道路／住宅整合

原有第二聖殿制度物件已登記希臘化期 `transform`，但波斯量體明確只准用於波斯期，導致本期沒有可見聖域。新增獨立示意版本（非第二套生命週期帳本），指回原制度物件，保留波斯期幾何與事件權限。[《瑪加伯上》4:36–61](https://bible.usccb.org/bible/1maccabees/4)支持聖所修復、祭壇重建與庭院重新奉獻的語境，不提供此處的平面、尺寸或定位。

本期選取前164年重新奉獻後語境；不代表整個4至1世紀。殿堂、門廊、圍院與祭壇使用既有保守展示包絡，沒有為了製造年代差別放大聖殿：殿堂30×15×12m、庭院118×104m都是既有示意尺寸，不是哈斯蒙尼實測值。這是共用施工語法的獨立時期表示，不證明原建築一直保存，也未宣稱實際擴建。亞克拉、巴里斯與希律建築不混入。

南側入口通路從當期既有主街的實際折線接入，穿過留空院門後到達門廊；住宅避讓整個院區及入口通路，原有道路越過院區的部分停止顯示，城門接街同樣避讓。所有尺度仍是同一DEM座標下的一米單位。反向返回使用原快取，證據篩選同步作用；進入希律期撤下這個表示，不等於宣告當時整座毀滅。

新增實際通路三角形與門牆避讓、地表落地、主街接點、生成地塊預留、證據／時期隔離與快取檢查，接入共同18期可見地標矩陣。全線建築群、古地表、精確形制及17段原構件繼承仍未驗收；後續持續按全18期矩陣補缺口。
