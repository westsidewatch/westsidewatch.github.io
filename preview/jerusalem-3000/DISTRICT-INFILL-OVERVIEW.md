# 多區住宅連片與本期全景

M2 第四批。只對獨立配置的第一聖殿晚期／波斯期開啟 `district-constrained`，不改希律或其他時期的既有地塊生成。

原先短沿街塊無法覆蓋西丘內部；切換時代又沿用大希律城市鏡頭。現在 `district-infill.js` 在同一區界內分割出示意街區：凹區先作凸片分解，按現有道路避讓帶裁切，較大片再遞迴分割。區塊分割線／間隙是設計示意，不是新發現或核定的街巷；道路線段在局部區塊內的避讓延伸也沒有當作道路繪出。區塊不宣稱 roadBounded。地塊仍使用共用住宅 grammar。

整塊聖區、王室主體及道路空間排除住宅；各地塊拒絕與已接納地塊重疊。地區 ID、分割路徑形成確定性的區塊／住宅身分；毀城與時間倒退沿用本次生成物件。這次會改變上一版本的示意住宅 ID，不代表考古住宅更換。晚期／波斯仍為兩份獨立配置，不推定住宅物理復用。

`city-overview.js` 按區域世界座標、地形高度、建築餘量及畫面比例取景，在下方時代卡上方留出空間。晚期到毀城不重新重置全景；進入波斯換其範圍，開啟前代遺存則涵蓋兩期。離開這兩期恢復先前鏡頭；聖殿近看仍獨立工作。取景依據是設計 envelope，不是核定城界。鏡頭在入期／遺存切換時調整，不宣稱任意視窗縮放後自動重構取景。

驗證包括：確定性、凹區邊線內含、全區地塊無重疊、道路與聖區留空、西丘內部超出舊沿街帶的住宅、桌面／直向視窗投影範圍；實際18期瀏覽器回歸、前代遺存、聖殿近看、倒退、失敗閘與共用資料只載入一次。

住宅新增僅改善示意城市形態，不代表人口、密度或歷史建築數。分割最大面積是工程參數（12000 m²），不是古代街區數據。仍使用現代 DEM 與共用推定住宅形制；古地表、經核定城牆／水系、完整住宅共同帳本及各期住宅細部仍未完成。`fullTimelineReady` 保持 false。

沒有增加外部模型、圖像或地圖下載，配置仍只請求一次、快取生成城市供往返。幾何較多，並不等於 GPU／記憶體成本較低；本輪不宣稱模型 token 節省、手機硬體 FPS 或 p95 改善。
