# Seven source lifecycle declarations and runtime accounting

Seven remaining Herodian entries intentionally have no own physical lifecycle events. Five describe relational districts/roads referencing existing source objects: Temple Mount, southern approach and Antonia districts, plus western street and southern pilgrimage road relations. The other two are withheld eastern access records. This package declares those exact scopes instead of inventing construction events to eliminate a diagnostic count.

A validated atomic batch declares source-context-only or withheld status under herodian-source-scopes-v1. Context relations require existing anchors with declared events; withheld geometry must remain withheld. Scalar built/destroyed values are cleared for these non-event scopes. Missing references, conflicting physical events or invalid withheld geometry reject the entire batch before mutation. No geometry, source event, confidence or lineage link changes.

inspectSourceLifecycleContext(id) exposes live anchor states separately from the relation's own history. It can show a changed source event without copying that event into a district's construction date. Different anchor states remain separate. Withheld entries remain unknown and unrendered. Returned context snapshots cannot mutate source records.

Foundation lifecycle inspection retains the original no-event IDs, adds explicit scope IDs/counts, and separately lists unclassifiedWithoutDeclaredEventIds. Source declarations are accepted only for the exact seven registered IDs/statuses/authority, not as a generic flag to conceal missing events. registrationAccounting.visibleScopeAccounted checks that visible unbound components are accounted for by separately identified annotations or provisional inheritance. Neither measure certifies historical completeness.

The 18-era browser regression requires zero unclassified no-event records and accounted visible scope in every active phase. It still requires foundationAccepted=false. Existing historical uncertainty, provisional inheritance, modern terrain limitations and missing district/route/defense foundations remain open. The accounting gate is a finite engineering checkpoint before further spatial skeleton work.
