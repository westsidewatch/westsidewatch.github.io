# V2 — 全时期城市结构的显示层次

2026-11-01。基于V1主视图，统一显示已有城防、道路与公共核心；不新增或补全历史建筑，不扩大城墙、地标、街道或住宅。

## 共用规则

使用既有共同帐本类型和构件标记分类，所有时期走同一规则：

| 显示角色 | 处理 | 不代表什么 |
|---|---|---|
| 住宅/住区背景 | 提高基础明度，关闭住宅投射的密集微小阴影；保留实体轮廓、法线、受光与其他建筑投影 | 不改变密度、人口、屋顶形态或地块 |
| 已登记道路 | 增加铺面与街区的明度区别 | 不核定古代主次街等级，不画出缺失线路 |
| 城墙/城门 | 降低基础明度，提高轮廓可读性；推定对象采用较克制的调整 | 不提高高度/厚度，不把残墙变成完整城墙 |
| 公共核心 | 稍加深主体，令其区别于浅色住区背景 | 不夸大尺寸，不新增地标或室内 |
| 争议/范围补足/候选边界 | 保留原表示，不套用上述强调 | 不用美化掩盖不确定性或缺段 |

只调整材质基础明度，保留其色相和饱和度；证据筛选、可信度、生命周期和原有几何仍由各自来源控制。图中缺失的墙/门/核心不会因显示处理而补出。西侧市场作为街道对象的附属店室组件按背景处理，不被提亮为道路或升级为公共核心。

## 实现与对照

独立显示层按来源材质和角色缓存少量派生材质，避免共享材质令公共核心与住宅一起变色。复制来源建造着色器回调；不改透明度、裁切平面或自定义深度材质。既有建造/剖视机制复制的带标记材质继续沿用正确角色。释放时恢复原材质和阴影状态。

默认启用。二级“检视与研究”内的“结构层次”可开关，支持相同镜头比较原始显示。开关不切换年代或更换模型。没有新增远端纹理、模型或地形请求。

## 全期检查

所有18期均做真实画布像素开关对照；启用与停用画面必须不同，再启用必须逐字节还原同一画面。对照前后登记住宅数量与可见地标ID必须相同，未新增越期对象。诊断分别记录角色对象、材质变体和不确定对象；这些计数不是历史建筑总数。

最早三期的核心/城防类别可以为零，表示当前未绘出，不填造历史空白。后期相似住宅底纹和现代矩形外扩覆盖仍然存在；V2的材质分层不能解决这些V3几何表示问题。

独立Node检查覆盖共享材质分离、原材质不被污染、来源着色器/透明度、裁切归属、色相/饱和度、不确定对象、缓存、几何/变换/可见性与资源恢复。继续运行18期主视图与比较、17段转场、手机、证据、圣殿和圣墓剖视回归。

## 阶段边界

这是V2的共用显示层施工候选，不是各期完整城防、主街或公共建筑的考古验收。缺失的来源/定位仍保留。确认整体层次之后，按顺序进入V3街区体量与时代轮廓，继续暂停店室、门窗和室内细节。
