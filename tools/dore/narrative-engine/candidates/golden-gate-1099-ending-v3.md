# 〈金門〉｜1099年最後攻城（候選續稿 v3）

> 編輯候選稿。已核對可公開取得的《法蘭克人事蹟》拉丁文段落及阿吉萊爾的雷蒙選譯；尚非全面學術校勘，未寫入 canonical，也不是多雷本地模型生成。

七月十三日、十四日，攻城者又從城外向耶路撒冷發起攻擊。木塔已經造好，木料、鐵件和繩索從遠處運來，卻還要靠人把整座塔送到牆邊。守軍看見城外的器械成形，便在夜裡加高城牆和塔樓。兩邊都在築造：一邊想跨過石牆，一邊想讓石牆再高一些。到了星期五清晨，攻擊仍沒有打開缺口。

十五日，戈弗雷和他的兄弟歐斯塔斯在攻城塔上繼續作戰。《法蘭克人事蹟》的匿名作者記下一名叫萊特霍爾德的士兵攀上牆頭。接著，守軍從這段城牆退走，十字軍追入城中。三年前，這些人從歐洲啟程；在安納托利亞失去馬匹，在安條克忍受飢餓，到了耶路撒冷又為水與木材耗盡力氣。此刻，所有漫長的道路都縮到城垛上的一個立足之處。那不是東牆金門的門洞。

城的另一邊，雷蒙的人還在同壕溝較量。《法蘭克人事蹟》記載，為了填平木塔前的深溝，軍中許諾每搬來三塊石頭便給一枚錢幣。有人連續三天三夜搬石。塔能否靠近城牆，先取決於腳下的空地是否容得下輪子。北面已有人登城，南面的士兵仍得在守軍射擊之下完成自己的工作。勝負並沒有在城牆每一處同時決定。

城破後，攻城者的記述轉向追擊與殺戮。有人退往聖殿山一帶，仍遭殺害；也有人被俘或在投降後得以離城。阿吉萊爾的雷蒙和《法蘭克人事蹟》的作者用血流的意象描述這場勝利，這些句子揭示了敘述者的立場，不能直接換算死亡數字。穆斯林與猶太居民的遭遇還留在其他文字裡，與勝利者的讚美不屬於同一種記憶。攻城者終於進入了他們盼望的城市，城裡許多人的生活卻在同一天被毀掉。

大衛塔一帶仍有人守著最後的據點。根據《法蘭克人事蹟》，守方將據點交給雷蒙，獲准離開。七月二十二日，距破城已經過了七日，十字軍領袖推舉戈弗雷掌管這座城。奪城的日子與決定誰來統治的日子，並不是同一天。城牆打開之後，留下的是另一種難題：誰來駐守，誰能活著留下，誰有權把勝利寫成這座城市的歷史。

金門仍在東牆上。1099年七月十五日的入城，不是穿過這扇門。它所承載的等待、進入與歸來，並不能抹平北面城牆的突破，也不能遮住城內的死者。對城外的人，那一天是漫長遠征的終點；對城裡的人，卻可能是所有道路的斷處。一座城有不止一個入口，也有不止一種記憶。
