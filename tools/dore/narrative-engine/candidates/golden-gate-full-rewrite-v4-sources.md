# 〈金門〉V4 史料核驗與修訂紀錄

## 已直接核對的敘事節點

1. **六月強攻、梯子不足**：`Gesta Francorum` 的圍城敘述記載強攻失敗及梯子不足；現稿不應把「如果梯子足夠便能攻下」寫成已證實的反事實結論。
   - https://sourcebooks.web.fordham.edu/source/cde-jlem.asp
   - https://warhistory.org/article/jerusalem-june-august-1099-part-i
2. **萊特霍爾德先登城**：`Gesta Francorum` 記述戈弗雷與歐斯塔斯在塔上，Lethold 先攀上城牆。保留史料敘述的歸屬，不虛構其台詞或內心。
   - https://sourcebooks.web.fordham.edu/source/cde-jlem.asp
3. **雷蒙南面填溝**：同一敘述記下三塊石頭換一枚 denarius，填溝三天三夜；守軍投擲石塊與火；大衛塔守將在得知北面入城後向雷蒙投降。
   - https://sourcebooks.web.fordham.edu/source/cde-jlem.asp
4. **亞實基倫社群書信**：Princeton Geniza Project 的 T-S 10J5.6 + T-S 20.113，推定 1100 年夏，亞實基倫卡拉派猶太人致福斯塔特猶太人，詳述贖人、贖書與救援；包括 230 部聖經抄本、100 部未裝訂書籍、8 卷妥拉、尚欠約 200 第納爾。
   - https://geniza.princeton.edu/en/documents/1560/
   - https://www.posenlibrary.com/entry/letter-capture-jerusalem

## 已在 V4 正文執行的改寫

- 取代 V3 對亞實基倫書信的一段概述，展開為五段以書信具體帳目和救援行動推進的敘事。
- 不把這封書信誤寫成所有耶路撒冷倖存者的統計；它反映寫信社群的遭遇與救援工作。
- 不把拉丁攻城敘述對屠殺的誇飾語句當作精確人數。
