# 〈金門〉｜1099年最後攻城（候選續稿）

> **編輯狀態：候選續稿，尚未通過逐句史料核對；不得直接替換 canonical 正文。** 本稿由編輯助手撰寫，**不是多雷本地模型的生成結果**。前文截至「真正的攻城還在後面」，下文承接這一段。

七月十四日，城外的攻城塔終於向牆邊移動。木架上的人要靠近城垛，地面上的人卻得先把輪子推過坑壕與崎嶇的石地。北面，戈弗雷的人已經為攻擊作了最後準備；南面的雷蒙也把木塔推向城牆。兩處營盤隔著整座耶路撒冷，誰也不能代替另一邊的人攀上牆頭。城內的守軍沿著城垛迎擊。圍城者花了數週尋找木材、搬運石塊、填平壕溝，到這一天，這些工作都只為了一件事：讓人能從塔上跨到牆上。

十四日的攻勢沒有立即打開城門。到了十五日，北面的攻城塔終於靠近城牆，塔上的橋板搭向牆頭。守軍試圖阻止攻擊者登上城垛，城外的人則沿著木架繼續向前。關於最先登城者的姓名，不同記述的歸屬需要逐一核對；可以確定的是，突破發生在北面一線，而不是東牆的金門。守軍在這一段牆上失去立足之處，攻擊者湧入城內。南面的雷蒙仍在對付自己的防線。那道圍了三十八天的城牆，終於沒能再把兩邊的人隔開。

城破不等於戰鬥停止。十字軍進入耶路撒冷後，城中發生大規模殺戮；穆斯林居民和猶太居民都在這場災難的記述之中。中世紀作者用極端的語言描述流血，有些文字意在彰顯勝利或引述宗教意象，不能直接拿來換算死者的人數。但即使不採用那些誇張的數字，攻城之後的暴力也無法從這場勝利中刪去。城牆外的人用了三年才走到這裡；城內的人在七月十五日迎來的，卻不是同一個故事的終點。

守城的伊夫提哈爾·道拉最後與雷蒙一方議和，從大衛塔一帶撤出。十字軍在城中重新分配權力，戈弗雷成為新政權的領袖。這座城市隨即成為拉丁耶路撒冷王國的中心，而埃及援軍尚未使這場戰爭結束。遠征軍原以為抵達聖城就是誓願的終點；真正取得城市之後，他們還得決定由誰守住它，又以什麼名義統治它。

金門仍在東牆上。七月十五日的突破不在這裡。門前的汲淪谷沒有替圍城者開出道路；戰爭繞向北面和南面，靠木材、石頭、飢渴與人命打開了另一條入口。從東面望去，這座門依舊把後來的人帶回更早的盼望：有人在此等待進入，有人在此等待歸來。1099年的軍隊已經入城，但城門與城市所承載的故事，沒有因此結束。
