# 〈金門〉｜1099年最後攻城（候選續稿 v2）

> 編輯候選稿，尚未寫入 canonical；不是多雷本地模型生成。下方「史料核對」屬工作附錄，不得帶入正式正文。

七月十三日、十四日，攻城者再度向耶路撒冷城牆發起攻勢。城外的人已經用幾週時間砍木、製塔、搬石，現在還得把高大的木架推到守軍能夠射擊的地方。城上的人並沒有坐等。圍城者的記述說，守軍趁夜加固城垛，抬高塔樓。每向前挪動一段距離，木塔便離城牆更近，也離火與石塊更近。

十五日是星期五。北面的攻城塔上，戈弗雷與他的兄弟歐斯塔斯仍在督促攻擊。編年史記下一名叫萊特霍爾德的人首先攀上牆頭；守軍從這段防線退開，後面的士兵接連登城。那是一場從木塔到石牆的跨越：三年前在歐洲許下的誓願，經過安納托利亞的道路、安條克的饑餓與耶路撒冷城外缺水的山坡，最後縮成牆頭上一處可以站穩腳跟的地方。這一處突破不在東面的金門。

南面的雷蒙還有另一道障礙。他的攻城塔與城牆之間隔著深溝，軍中許諾搬三塊石頭填溝便給一枚錢幣。三天三夜，石塊不斷填進溝底。等塔終於靠近牆邊，守軍仍用火與石塊抵抗。雷蒙聽見北面的人已經入城，才催促部下繼續進攻。北面的突破與南面的艱難，發生在同一座城的不同防線上。

城門一旦失去作用，城內的人便無處再依靠那道牆。十字軍入城後發生大規模殺戮。編年史作者用血浸腳踝乃至更誇張的意象描寫勝利；那是他們書寫征服的方式，不能據此計算死者的數目。可以確定的是，城破並非平民苦難的結束。有人躲向聖殿山一帶，仍未能免於殺戮。十字軍將這一天稱作聖城的收復，對城內許多居民而言，七月十五日卻是生命終止的日子。

大衛塔附近的守將最後與雷蒙達成投降條件，得以離開。城市已經被攻下，卻還沒有決定由誰統治。數日之後，領袖們推舉戈弗雷掌管耶路撒冷。從此，遠征不再只是通往聖城的道路，也成為守住一座城、分配權力並面對埃及軍隊的另一場戰爭。

金門仍在東牆上。這一天，士兵不是從它的門洞進入耶路撒冷。北面的木塔、南面的深溝，以及城破後街道上的人，才是1099年七月十五日的現實。金門承載的等待與盼望沒有替任何一方免去歷史的重量；一座城被奪取的時候，進城的人與留在城裡的人，從來不是同一個故事的主角。

## 史料核對（僅供編輯）

1. **7月13–15日與首次登城者：** 《法蘭克人事蹟》卷十 §38.2（Dickinson College Commentaries, William Turpin 編，2025）：https://dcc.dickinson.edu/gesta-francorum/10-38-2 。記載星期三、四的攻勢，星期五的突破；記載萊特霍爾德（Laetholdus）、戈弗雷與歐斯塔斯。注意這是十字軍立場的編年史。
2. **雷蒙填溝、三塊石頭一枚錢幣、三天三夜：** 同書 §38.3：https://dcc.dickinson.edu/gesta-francorum/10-38-3 。其編者指出拉丁文敘事時序有倒敘，不能把所有動作硬套在十五日同一時刻。
3. **大衛塔投降、戈弗雷受推舉：** 同書 §39.1–2：https://dcc.dickinson.edu/gesta-francorum/10-39-1%E2%80%932 。原文稱戈弗雷在攻城後第八日被選為城市的 prince；不要寫成攻陷當天即被加冕為王。
4. **殺戮及編年史修辭：** 同書 §38.2 與富爾徹《耶路撒冷陷落記》選段：https://sourcebooks.web.fordham.edu/source/fulk2.asp 。不由血流意象推算人數；平民及不同社群的細節仍需跨來源審查。
5. **對照來源：** Fordham Medieval Sourcebook 收錄《法蘭克人事蹟》、阿吉萊爾的雷蒙與富爾徹不同敘述：https://sourcebooks.web.fordham.edu/source/cde-jlem.asp 。
6. **未核准的細節：** 本稿對木塔移動的連續鏡頭、城內平民個體經驗沒有額外具名見證，不應進一步寫出人物對白、姓名或內心獨白。若正式出版，需核對拉丁文原文與不同譯本，並補充非十字軍立場史料。
