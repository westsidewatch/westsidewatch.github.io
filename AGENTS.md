2. Retrieve the smallest explicit candidate set needed for the task.
3. Prefer symbol/ranked bounded excerpts over whole files.

7. Whole-repository search/read is the last fallback, not the starting action.
8. Never create a parallel memory/authority system. Canonical Doré records remain authority.
