# 本站及所有產品：資源選取原則

狀態：生效。依使用者 2026-09-12 指示，適用 Westside Watch 全站、黎明書局、ONE、多寫 / Doré Folio、Doré Search、Design Preview，以及 A2A / 學習與推薦所採用的外部資源。產品、語言、格式、來源或免費授權都不能豁免。

## 第一關：內容是否採用

爭議性資源不採用、不持久化為可用資源、不推薦、不展示、不作訓練素材。包括以現代政治立場、政治宣傳、民族對立、現代國族衝突、戰爭倡議或地緣政治表態為主要目的的資源。已遭撤回的資源不能透過翻譯、改名、重新包裝、另一個來源或 EPUB 轉檔重新进入。

不能確認適用性的項目一律待審，不能以「沒有命中黑名單」作為核准。判斷依內容的主旨、年代、文類及用途，不單凭「以色列」「巴勒斯坦」「戰爭」等字樣；聖經地理、古代史、正常教會史不因此被誤判。對爭议邊界不確定時，保留審核理由，停止採用，等待編輯確認。

## 第二關：它是否真的是書

只有通過第一關，才進行書籍身分審核。公開書架必須有：

- 可確認的完整作品身分與正式書名。
- 作者、編者或可識別的翻譯／版本責任資訊；古籍和聖經版本不強求現代 ISBN。
- 來源書目／出版或版本紀錄，足以確認它是一部完整出版作品、專著、正式編著、參考書或聖經版本。
- 可核查的來源連結、內容範圍與權利證據；內容核准、書籍身分、授權分別判斷。

新聞報導、社論、政治文宣、聲明、公報、傳單、單篇演講、單篇文章、摘錄、明信片、搜尋結果及一般網頁不能列入書籍館藏。確為正式出版的論文集／講道集須核驗整部作品與版本，不能把一篇文章改標為集子。

公版不等於適用；可讀不等於可採用；有封面或可轉 EPUB 不等於書；來源網站可靠不代表其每一筆都是書；關鍵字相關性和來源的 `Text` 類別不構成書籍證據。

## 選取與更新

先做內容審核，再做文類／完整作品核驗，最後確認版本與權利。任何一關未確認，即進入非公開待審佇列。資料庫、索引、書架、搜尋、推薦、匯入入口及既有館藏參照都必須遵守；新產品必須沿用此政策，不能另開寬鬆入口。

取消最低館藏數和以增長數量為成功的驗收。寧可少收，也不能以不合格項目補數。重新建索引時必須重新驗證已收錄條目；撤回／待審資料不留在公開 JSON 或快取供產品再取用。

`data/resource_selection_policy.json` 是機器政策；`data/resource_book_reviews.json` 是逐作品、逐來源的核定書籍紀錄。上游資料自行填入 `approved` 不授予資格。新增核定紀錄須附作品、版本與內容審核依據；生成資料不得自行改寫核定紀錄。Python 與瀏覽器共用同一份版本化政策，兩端測試必須一致。

目前保留的九筆是已核對來源書目的歷史／靈修著作與原有明確指定的聖經版本。其他原有自動館藏先回到 `dore-core/review/resource-selection/` 待審；待審不代表全部已被判定有爭議。審核資料不參與公開產品選取。

本規則管理本站選取與提供的外部資源；不把使用者自己的私人書稿等同本站核定館藏，也不藉此刪除使用者原創資料。
