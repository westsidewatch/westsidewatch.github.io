# Jerusalem 3000：製作能力、用途與下一階段施工順序

2026-11-18。城市程式基線：2d8e93ab6；PR1271尚未合併。完整城市CI44313954520已成功。這是現況盤點與後續製作規格，未新增影片、模型匯出或拍攝控制功能。

## 定位與完成程度

目標是同一地理座標上的歷史城市場景庫：18期共享山脊與谷地參照，觀眾能辨認城市範圍、重要地標和相鄰時期的變化。網站、講解影片與未來拍攝資產從同一份時期／位置／來源資料派生。

目前是可運行的歷史城市原型，已有互動教學和概念分鏡的素材基礎；尚未達到完整城市復原或通用電影場景的程度。不提供缺乏依據的完成百分比。

## 現在可以用來做什麼

1. 互動歷史／聖經地理講解：在同一地形上對照山脊、聖區、城牆和路線，保留推定說明。
2. 講道、課程或研究展示的城市示意素材：總覽、地標關係、前後對比與剖視圖。
3. 短片的概念預演與分鏡：先選時期和鏡頭，再判斷畫面需要補哪一區；目前適合中遠景及風格化表現。
4. 影片的地理建立鏡頭素材：可先做樣片評估，不保證目前任意角度錄製都達到正式交付品質。

以上不是已交付的影片或已完成的全城虛擬製片服務。

CITY-MASS與CITY-CHANGE可按依賴交叉推進；樣片的鏡頭清單可先寫，但不為樣片逐棟雕刻整城。30—60秒、1080p或30fps等均須在拍攝試驗中驗證；目前不把它們標成已通過的輸出規格，也不提供未經資源估算的工期。

## 第一段樣片的驗收思路

先以現有固定尺度總覽及九章主線可用的視角作基線，選少量能說明山脊、擴建與重建關係的鏡頭。第一段是技術／敘事試驗，通過後再擴成覆蓋18期的歷史短片；不把大衛至希律九章誤稱完整3000年導覽。

鏡頭紀錄至少包括：程式／資料版本、時期與時間位置、相機位置與目標、視角、畫面比例、光照、證據篩選、準備狀態，以及是否使用推定幾何。載入與鏡頭移動的等待不應吞掉故事停留時間。正式輸出需有獨立時間控制，不能依賴人工拖時間軸或瀏覽器當下幀率。

第一個樣片用來找出最影響畫面的共同問題；片子好看不能替代18期整體工程驗收。

## 進一步擴展

- 主題導覽：城市供水、防禦、聖殿發展、朝聖路線或宗教公共核心；從同一資料庫派生，不另造城市。
- 雙語教學／課程：保存導覽章節、課堂對比畫面與有來源的圖版。
- 博物館與展覽：觸控時間線、地標查詢和前後對比；展場運行需另測。
- 選景與虛擬製片：保存鏡頭和時期場景，逐鏡頭決定需要提升的區域。
- 步行／VR／AR：可能的後續介面；目前Orbit觀看和門洞射線檢查不等於已具備完整步行碰撞、VR舒適性或現地AR定位。
- 研究比較：把同一地標不同復原假說並列，將不確定性變成可檢視的內容。

角色、群眾、任務系統和AI輔助故事可建立於場景之上，但屬新增工程；不應讓它們先於城市可靠性與變遷敘事。

## 共用資產與成本控制

網站保留輕量表示，拍攝依鏡頭按需提升局部細節，兩者共用地點ID、米制座標、年代和來源。不要維護兩套會漂移的獨立耶路撒冷。先量測再決定合併、預生成、快取或分包策略；不可把已生成快取與所有時代預載混為一談。

先有鏡頭清單，再為近景製作資產；遠景不承擔室內等無用細節。保存可重播的場景狀態，使製作失敗可以重做同一鏡頭，而不是每次重新調整整城。現有來源標註及推定說明也應隨圖版或影片交付保留。
