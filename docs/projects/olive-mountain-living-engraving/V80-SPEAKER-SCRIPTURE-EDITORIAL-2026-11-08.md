# Olive Mountain / V80 經文編輯與資料來源（2026-11-08）

## 視覺指令
- 中文版塊名 **橄欖山** 與英文 `OLIVE MOUNTAIN` 必須同屬一本刊物的 OS 字體系統；不能只有英文醒目、中文隱藏。
- 版塊主題經文選用 **羅馬書 10:17**：`可見信道是從聽道來的，聽道是從基督的話來的。` 置於版塊名下。此節為**編輯選擇**，不是宣稱原專案以前指定的唯一經文。
- 十二幅卡背保留原來的作品文字版位，但以**中文經文節錄 + 經卷章節**替代 `KIDRON DESCENT / THE FIRST BRANCH` 等工作標籤。兩張共用的實際卡片要按當前講員 `id` 更新，不能只按版次 `Math.floor(id/2)` 更新字句。
- 文字只使用現有 OS 的中英字體和紙／黎明金色系。保護既有姓名排版、卡背 SVG 圖形、翻面力學及 01–03 不變。
- 使用和合本繁體短節錄，`……` 表示為了卡片閱讀而節錄省略；必要時查整章，不得以短句冒充完整經文。

## 版塊經文原則
羅馬書 10:17 對應「誠邀聽道」的章節意義，放在 English/中文刊頭下方。為避免與各講員卡背的主題經文重複，康來昌改用其有直接講道來源的馬可福音 1:38。
