# 王室城市幾何接回共同帳本

本包延續 PR #1251。取用 #1249 的草模參數與構件，再改為共同帳本投影；#1249 不宜再原樣合併。尚未完成詳細聖殿建模或整座城市總平面。

## 綁定

每個構件保留 componentId，另以 objectId 綁到共同 Core：第一聖殿、大衛城防假說、所羅門北向城防假說，以及兩個推定王室院落。推定王室院落與大型石構考古候選區使用不同 ID，不把院落設計當成候選遺構的核定復原。

Core 登記 component-assembly、ENU bounds、構件清單與 geometryVerified:false。資料仍保留 literary／inferred authority；接到 renderer 不升級成測繪成果。適配器不另寫一套建造日期，以共同 lifecycle evaluator 判斷可見性。

## 跨代行為

- 大衛段：城防假說與大衛院落。
- 所羅門段：同一前代構件，加北向城防、王宮院落與第一聖殿。
- 第一聖殿晚期：同一聖殿與推定王室主體繼續顯示；個別前代牆段延續未核定，停止顯示這組牆線，不表示當期沒有城防。
- 毀城：同一組聖殿／院落構件以示意頂點壓縮顯示毀壞；每個地面頂點維持 DEM 位置，避免整體縮放後穿地。
- 波斯：第一聖殿與王室特定遺存 unresolved，不顯示為第二聖殿。早期第二聖殿仍是另一物件，尚未接詳細幾何。
- 倒退：恢復原始頂點，保留原 componentId；沒有重新生成另一座聖殿。

城防路線、宮殿院落與聖殿位置仍為推定。毀壞形態不是考古倒塌測繪，也不是物理模擬。

## 與背景城市協調

第一聖殿晚期／毀城的地塊生成排除聖殿與兩院落的推定範圍；程序道路亦略過穿越該範圍的片段。這是防止幾何重疊的保留區，不是核定古代街網或完成道路繞行。波斯不套用第一聖殿幾何作“再利用”證據。

共享城市在生成期間不顯示舊佔位大方塊，保留真實已接主體與進度訊息。聖殿近看支援站立與毀壞階段；離開場景恢復先前鏡頭／距離限制。

## 驗證與剩餘工作

Node 驗證共同綁定、未知牆段不被投影、倒退精確恢復、倒塌不穿地、證據過濾、道路保留區與銷毀。瀏覽器核對五個時間點的帳本／幾何一致、component identity、近景、毀壞，以及既有 18 期桌面／手機回歸。

下一包先做 M2 城市空間骨架：地區、道路、門、水系、聖區與王室區的共同配置和進入關係，再補早期第二聖殿幾何；待全鏈一致後才大批深化細部。目前主體仍為草模，fullTimelineReady 保持 false。
