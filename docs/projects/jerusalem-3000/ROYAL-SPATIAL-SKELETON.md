# M2 城市空間骨架：大衛—所羅門第一批

這一批補連接關係，不宣告全城市平面、古代道路或水系復原完成。整體主體仍為推定草模。

## 同一配置

`data/settlement/david-solomon.v1.json` 的 royalCity.spatial 是門、道路節點、動線、地區與共同來源的配置。座標是基訓泉近似現代位置為原點的東向 x、南向 z（米），不是緯經度，也不是出土道路座標。

配置含 2 個推定地區、3 個示意入口、14 個動線節點、13 個道路關係。門洞從牆段與比例位置計算；王室院落入口由院落中心／開口計算；聖殿入口由主體長度、門廊與模型肘長計算。移動牆線或建築參數會改變相應道路端點，不維護另一套入口位置。

- 大衛：泉點 → 東入口 → 山脊住區；山脊分支連接王室院落與北入口。
- 所羅門：保留大衛動線；經北入口 → Ophel 王室區 → 聖殿前方與入口；另接北側入口。
- 道路避開住居、牆體、柱與祭壇；院落南側保留實際開口。住宅位置做少量示意調整，數量不表示歷史人口。
- 道路是行走／取水動線，不是水渠。古代水流設施、儲水、階梯與沿線密集街區尚未完成。

## 共同帳本與節流

anchor pack 只引用 spatialObjectPack。`anchor-ledger-loader.js` 依共同配置產生門、道路與地區記錄，給時間整合與 Core 使用；不把同一配置再手寫一次到 anchor／lifecycle JSON。

衍生物件有穩定 ID、來源、限制與推定證據狀態。它們以既有城防假說的生命週期作顯示模板，保留 templateId；這是示意顯示依賴，不證明古代道路或城門的建造年代。後期連續性未核定，不能直接把這條路沿用到其他時代。

Core 保存地區 ENU 多邊形、道路端點關係、門與牆的關係，以及幾何構件。共享 JSON loader 保證王室配置與四份原有共用資料各請求一次。沒有量測或宣稱新的 token 節省比例。

大衛場景移除舊孤立步徑，避免雙路網。其餘早期場景維持原樣；它們的共同空間配置仍待遷移。

## 驗收

- 泉點能沿圖抵達各階段所需目的地；所羅門目的地不在大衛段提前出現。
- 牆線變動會跟著改動入口／道路端點；不允許門洞超出牆段、重疊門洞、錯誤座標框架或提前連接未開放目的地。
- 住居外框在山脊範圍內，動線不穿住居外框。
- 實際道路三角形不穿牆體、院落牆、聖殿或柱；門楣位於通道上方，不按地面障礙物處理。
- 來源配置只有一份可編輯資料；並行帳本載入不重複登記衍生記錄。
- 地區／門／道路進入 Core，依共同生命週期與證據過濾；倒退、後期未知與既有主體仍可正確處理。
- 18 時代桌面／手機 viewport 回歸與資料缺失處理通過；真實手機與全城歷史準確度尚未因此完成。
