# Jerusalem 3000｜黎明書局策展集

Status: canonical curated collection for Issue #832
Date: 2026-09-24

## 定位

本策展集直接服務 **Jerusalem 3000｜三千年耶路撒冷時空重建**。它不是第二套研究系統；Dawn 仍保存 Work identity / search / routing，Jerusalem 3000 的 Terrain / Object / Lifecycle / Evidence / Event 五本 ledger 仍是工程 authority。策展集只負責把可核驗的書籍、圖集、地圖、考古報告、數位重建與影像資料組織成可閱讀、可檢索、可回到工程 evidence 的研究層。

排序硬規則：**中文在前，英文在後**。中文稀缺時不得用低權威來源補數量；Wikisource 永久禁用；政治／民族／戰爭爭議材料不進 Dawn canonical admission。涉及有爭議的歷史／考古判讀時，保存來源與分歧，不把單一重建方案寫成事實。

## A｜中文優先入口

### 中文書籍／通史
- 《耶路撒冷三千年》（Simon Sebag Montefiore, *Jerusalem: The Biography*）— 中文讀者的城市長時段敘事入口。只保存書目身份、版本與合法閱讀／購買指針，不重製受版權保護全文。
- 後續中文 discovery 優先尋找：耶路撒冷考古、聖殿山／第二聖殿、尼希米城牆、大衛城、拜占庭耶路撒冷、十字軍耶路撒冷、鄂圖曼耶路撒冷、十九世紀城市擴張、歷史地圖與攝影圖集。Admission 必須通過 rights / relevance / authority gate。

## B｜考古與城市地層

- Israel Antiquities Authority Publications Portal — 超過 10,000 篇開放取得的考古報告、研究、專著與會議出版物；Jerusalem 3000 的 Object / Lifecycle / Evidence ledger 首要學術來源池。
- IAA, *Jerusalem: Western Wall Plaza Excavations Volume I — The Roman and Byzantine Remains: Architecture and Stratigraphy* — 15 個地層，約跨 2700–2800 年，直接適合作為同一空間長時段 lifecycle 的證據樣板。
- IAA, *Western Wall Plaza Excavations Volume III* — 羅馬／拜占庭時期小型出土物與 contexts，補足建築之外的 material evidence。
- Jerusalem Journal of Archaeology — Hebrew University 開放取得、同行評審；特別保留 Spatial Digital Archaeology and History in Israel 專題作方法層來源。

## C｜地圖與城市形態

- National Library of Israel — Eran Laor Cartographic Collection：大型 Holy Land 地圖館藏，含 1486、1493、1560、1590、1698、約1734 等 Jerusalem 地圖／城市想像與測繪。
- National Library of Israel — 1945 Mandatory Jerusalem / Old City map：二十世紀城市形態與城門／道路比對層。
- UNESCO — Old City of Jerusalem and its Walls：World Heritage 邊界、座標、官方文檔與可授權圖像；作現代 Old City footprint / conservation reference，不作古代重建 authority。

## D｜圖集與歷史攝影

- Library of Congress — John D. Whiting Papers visual materials：3,200+ 影像，1870–1951，核心集中 1900–1940；含 American Colony in Jerusalem 的城市、人物與日常生活。
- Library of Congress — G. Eric and Edith Matson Photograph Collection：Jerusalem 大量歷史照片、全景與玻璃底片；部分條目標示 no known restrictions on publication，仍逐件保存 rights advisory。
- Library of Congress — Schick map 1894–95 photographic record：十九世紀末 Jerusalem cartographic evidence 的一個可定位節點。

## E｜既有 Jerusalem 3000 工程研究批次

以下五項保持為第一批 precedent Works，已屬現有 Dawn research shelf 的基礎，不另造副本：

1. EPFL DHLAB — Jerusalem 1840–1940：4D city / shared geodatabase / metadata + paradata。
2. Virtual Angkor：DEM/GIS、evidence-based model library、城市級 procedural distribution。
3. University of Cologne — The Muristan in Jerusalem：同一地點跨時期、3D 與 excavation / photographs / drawings 相連。
4. The Virtual Illés Initiative：Jerusalem historic maps / documents / 3D in immersive GIS。
5. openbibleinfo / 3D Temple Mount：browser-native 3D、來源分歧、geometry verification、reconstruction disclaimer。

補充方法 precedent：Rome Reborn，用於大尺度城市的 handcrafted monuments + procedural ordinary fabric；只吸收方法，不作 Jerusalem 歷史 evidence。

## F｜策展索引

每一 Work 進入本策展集時，至少標記：
- language: zh / en / he / ar / other
- medium: book / atlas / map / photograph / excavation-report / journal / 3d / gis
- period: Biblical / Second Temple / Roman-Byzantine / Early Islamic / Crusader-Ayyubid / Mamluk / Ottoman / 19C / Mandate / Modern
- spatial target: gate / wall / road / quarter / temple / church / water / terrain / city
- ledger target: Terrain / Object / Lifecycle / Evidence / Event
- evidence role: primary / excavation / scholarly synthesis / reconstruction precedent / visual reference
- rights: rehost / pointer-only / verify-per-item
- confidence: observed / reconstructed / inferred / disputed

展示排序：中文 → 其他東亞語言 → 英文；同語言內 authority 優先，其次 evidence proximity，再按時期與媒介組織。
