# Doré Context Economy — v0 acceptance

Status: implementation complete; empirical paired-run measurements pending real Codex task execution.

## Default route

Task -> resolve authority/surface -> ui_context -> bounded code evidence -> implement -> bounded tool/browser evidence -> verification -> explicit ui_expand only if insufficient.

Repository-wide reads are fallback only.

## What v0 proves

- one composable local gate exists;
- no hosted Jev/API dependency is required;
- code evidence is bounded;
- expansion requires an explicit reason;
- large tool/browser output is bounded;
- verified state is invalidated by changed inputs;
- repository instructions make this the default Codex engineering behavior;
- continuation prompts do not need to repeat the Jev instruction.

## What v0 does NOT claim

It does not claim a token-saving percentage yet. The benchmark protocol requires paired real UI runs. Provider token telemetry is optional; local context bytes and read/tool metrics are mandatory.

## Promotion rule

Promote this from v0 implementation to measured PASS only after real paired tasks show lower aggregate context consumption with no regression in correctness or human visual acceptance.
