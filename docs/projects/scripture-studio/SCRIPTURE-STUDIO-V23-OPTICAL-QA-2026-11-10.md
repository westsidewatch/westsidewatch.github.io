# Scripture Studio V23 — Typography and optical register QA

Status: isolated Draft engineering prototype. The site and P2 are not changed.

## Changes made

- English: native OS `Bodoni Moda SC`, OpenType `smcp`/`c2sc`, `font-variant-caps: all-small-caps`; the exact underlying KJV mixed-case string remains unchanged.
- Chinese primary: `Chiron Hei HK WS` 900, `PADG` 0, no synthetic bold. Chinese counter-reading: same family 200, `PADG` 0, no synthetic bold. Fallback clearly labeled if actual OS font faces are unavailable.
- New typography controls: **48/54/60/66px** fixed nominal sizes and **tight/classic/open** leading and tracking presets; no decrease in font size to fit.
- The optical register now measures DOM-generated actual bilingual runs in both impressions, then uses the column distribution gap to increase the short-axis occupancy. This is not the old max-longest-strip square-padding formula; all candidates remain generated by the existing ordered source/phrase solver.
- The report displays computed CSS typography and whether any real OS font faces have loaded.

## Results

Chromium test matrix: **4 viewports (1648/768/390/320) × 4 sizes × 3 density options × 3 mother-form candidates = 144 cases**. 144/144 preserved both exact originals, produced structurally legal interwoven layouts, and passed the DOM type-box occupancy gate. The seven strips retain four multi-switches and asymmetric ratios. This test does not establish poetic-editorial approval of optional secondary breaks.

54px tight, first candidate, offline font fallback:
- DOM type-box 842 × 1002 native px; virtual square 1066 px; measured occupancy 79.0% × 94.0%. Rotated reading swaps axes.
- Independent screenshot *actual ink pixel* bounding area (not merely CSS box): Chinese impression spans **76.3% width × 93.4% height**, English impression spans **93.6% width × 76.2% height**.
- Dark/light painted pixel coverage in preview: **5.8%** (Chinese) / **4.6%** (English). This is not the same as optical register bounds. The work still requires actual font-face validation and subjective artistic inspection; a “filled bounding rectangle” is not an award-quality stamp.

Other 54px presets: classic **84.6% × 94.0%** and open **88.3% × 94.0%** in the DOM typography box. Larger nominal type sizes lead to larger physical artboards and nearly unchanged *fractional* preview occupancy. Thus increasing point size alone is **not an effective substitute for genuine two-axis composition**.

## Explicit blockers

1. The local Chromium sandbox cannot load `Bodoni Moda SC` from Google Fonts or `Chiron Hei HK WS` from the official webfont CDN. CSS values 900/200 and all-small-caps are verified, but actual OS font provenance is **unverified**. Offline EB Garamond All SC and Noto Sans CJK TC are display-only fallbacks, never OS compliance.
2. The Isaiah 62:6 editorial secondary poetic breaks are study proposals, not source-edition official USFM lineation. In particular the optional partition inside `他們晝夜必不靜默。` remains pending editorial approval; `呼籲耶和華的，` stays protected.
3. True glyph contour / print-ready path extraction, final SVG export and manual 07-level editorial art direction remain unfinished. HTML + JSON export are available.
4. The observed actual ink fill is modest even when its bounding area is broad. Future art approval must inspect native OS strokes and internal whitespace rather than reporting outer box width as enough.
