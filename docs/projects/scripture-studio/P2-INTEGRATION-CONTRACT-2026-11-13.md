## 可直接重用的單一工具

- 母版：`static/experiments/scripture-studio-motherform-live.html`。
- 七個 P2 版塊共享同一套候選排字、量測、90° 旋轉和兩種印面；不能替不同版塊另建七套 HTML。
- 字型：同源自託管的 Chiron Heavy（900）／ExtraLight（CSS 200）及 Bodoni Moda SC（400，不能加粗），不准靜默使用字型 fallback；增減經文時要重建字集並通過 glyph coverage 驗收。
- 現有字形子集是七段試稿所需字集，不是全聖經字庫。用 one 工具的任意一節經文前必須增量補字或使用經核驗的完整字庫。
- `?section=01` 至 `?section=07` 已提供對應色彩與經文；`?embed=1` 去除獨立研究工作台的選案、導覽及檢視器資訊，只留下原雙印面。
- 同源父頁可以傳遞 `postMessage({type:'WESTSIDE_P2_SECTION',section:'04'}, location.origin)`，現有接收器僅接受同源訊息。

## 主站畫面與敘事

1. 每個 P2 版塊先保留原有刊頭／主題經文及既定入場節奏；雙向鉛字作為**章節內的一個編輯印版鏡頭**，不要覆蓋或替換既有影片、海報、經文閱讀工具與插圖。
2. 使用各版塊在 Design OS 的既有七色；中文主讀使用淺紙色／重字，英文主讀使用該版塊的主色／細字。中英不另造第八套配色。
3. 捲動進入印版時，保持一個連續母版的幾何與同一段經文：先呈豎排中文主讀，再作一次完整的 90° 轉向，進入橫排英文主讀；沒有淡入替代翻轉，也不在兩面之間重排詞句。支持反向捲動恢復。
4. 桌面容器採雙印面校樣供編輯審核；主站正式敘事只顯示正在閱讀的那一面。手機不得強塞兩個 1:1 印版並排；可一次一面，保持完整正方形及可讀的出處。
5. 出處位置沿用決定：豎版左下、橫版右上；出處應有充分視覺份量，不是螞蟻般的腳註。

## 技術接點（隔離預覽，不等於上線）

```html
<iframe
  title="P2 雙向經文鉛字校樣"
  src="/experiments/scripture-studio-motherform-live.html?embed=1&section=04"
  loading="lazy"
  style="width:100%;border:0;aspect-ratio:2 / 1"
></iframe>
```

目前 `embed=1` 用於工程審核。正式整合時建議把母版渲染控制抽成具名、隔離作用域的 JS 模組，配合 P2 現有 scroll progress 控制正反向 90° 轉向與單一印版顯示。不要注入全站全域 CSS，不要操作 P2 01–03 動效的父節點與 CSS。

## 上線硬門檻

- `node static/experiments/scripture-studio-p2-regression.mjs` 全綠；中英原文逐字、標點、經文出處與受保護語義片段不變。
- 七個版塊逐字 Chiron coverage PASS，200／900 自託管字型均成功載入；原研究用的 12 份 Isaiah-only 子集不作通用字庫。
- 1648、768、390、320px，七個版塊 × 兩種方向的真實瀏覽器截圖，及一份列印校樣；無 fallback、無疊字、無截字、無非自然分詞。
- 不能把「字型測試 PASS」當成「75% 光學填版 PASS」。短經文若缺少經審核的合法斷句而不足以滿版，應顯示不可正式出版，先完成編輯斷句或調整印版格式；不得任意拆字、複製經文或縮字充數。
- 必須檢查主站 01–03 的既有動畫無回歸，才可做獨立 P2 04–07 合併。
