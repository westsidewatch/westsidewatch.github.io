# Scripture Studio V17 — USFM 詩行匯入／語義斷句 QA

日期：2026-11-10。基礎：V16 HTML/CSS/JS 原生字印生成器。

## 已實作

- 在既有生成器中新增中文／英文 USFM 輸入與匯入操作。
- 實作不依賴網路的 **USFM 詩歌標記子集適配器**，辨識 `\id`、`\c`、`\v`、`\q1`、`\q2`、`\q3`、`\b` 與 `\p`；對不支援的標記、缺節號、缺詩歌標記與中英書卷章節不符，明確拒絕。
- 保留中文和 KJV 的原文；每個來源詩行變成一個不可任意拆開的語義單元。原文/分行同步校驗，不允許默默破壞 `呼籲耶和華的，`。
- 在工作台中顯示保留 q1/q2 層級的詩行結構、來源註記；範例明確標示為**編輯研究候選**，不冒稱權威譯本提供的原始 USFM。
- 用戶必須勾選人工覆核才可在來源詩行內加入新設計斷點。所有輸入仍保留精確原文全文比較；不使用按字數機械拆分。
- V16 既有雙印、46px 固定字號、200/900 選項、混排與佔有率拒絕機制保留。若詩行太少導致無合法混排版面，顯示不合格，不靠拆字或縮字掩飾。
- 排字計算採用 render ticket 防止切換經文或載入詩行後，舊非同步幀覆寫新狀態。
- 未通過排字驗收的版本禁止按完成作品匯出。

- 缺少 q 標記的偽 USFM 輸入被拒絕。
