# Gospel YouTube Channel Project｜福音 YouTube 頻道工程

> 狀態：立項與探索（Discovery / Research），**已確定主要受眾與雙語原則，尚未決定具體節目定位，未獲准上線**。  
> 建立：2026-11-08。管理方式：文件優先、假設可追溯、決策另行確認。

## 工程目的

研究在 YouTube 的觀眾機制、演算法、影片製作、AI 輔助、版權與變現規則之下，如何建立能長期運營、忠於福音使命、對陌生觀眾有實際吸引力的福音頻道。

**工程的目標是研究並制訂福音頻道可行方案，不是把先前討論的「AI 內容製作／數字營銷頻道」定為福音頻道方向。**

### 已確認的受眾與語言邊界（2026-11-08）

- **主要傳播對象：中文世界**，以中文語言社群中的福音傳播為主；不以單一國家或地域界定「中文世界」，涵蓋全球中文受眾。
- **中英文雙語**是工程必須遵守的傳播原則；不可在後續研究中取消英文接觸渠道。
- **英語世界不排除**：研究英文觀眾的可進入性與跨語傳播，但不因此把主定位改成泛英文頻道。
- 普通話／粵語、簡繁文字、英文字幕／配音／音軌／獨立版本等**實作方式尚未決定**，應比較可行性再定。
- 語言與傳播範圍已確認；具體節目類型、教會品牌歸屬和收入模型仍在研究。

## 邊界

1. 與現有 Westside Watch 主站、P2、ONE、橄欖山及其他產品的代碼和部署分離；此階段僅設立文件工程。
2. 與活水堂／Westside Watch 的關係尚未決定：不可假設為官方教會頻道，亦不可在未授權下使用其品牌、講員肖像、講道影音或現有頻道資產。
3. 福音內容應以經文、可信釋經、清晰敘事與有價值的觀眾體驗為中心；增長與變現是可持續手段，不取代福音使命。
4. 一切具體方案以研究與決策紀錄為準；未決假設不得在後續工程被當成既定規格。
5. 繼承倉庫根目錄的 [ENGINEERING-GOVERNANCE.md](../../../ENGINEERING-GOVERNANCE.md)。本目錄任何研究文檔不修改該治理契約。

## 現階段完成定義（DoD）

- 原始七個研究維度及首次討論得到可追溯的歸檔；
- 明確指出首次 AI 頻道建議**不是決策**；
- 建立第二階段福音頻道研究工作框架、方法、風險和驗收標準；
- 核實與記錄目前適用的 YouTube 重大政策；
- 主站零程式碼、零媒體資產、零部署修改。

本階段完成不代表已決定頻道名稱、開設帳號、購買工具或公開發布。
