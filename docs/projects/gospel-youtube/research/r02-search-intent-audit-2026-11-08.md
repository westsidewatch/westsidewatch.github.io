# R02｜中文福音觀眾問題：公開搜尋供應與需求訊號審計

**日期：2026-11-08** | **研究性質：搜尋結果 / 內容供應代理訊號；不是 Google Trends 搜尋量報告**。

## 審計問題

R01 的 30 條問題只有研究假設。R02 實際核查了其中五組核心問題的可檢索內容供應，對照 2026 年近月視頻級記錄，尋找進一步採訪／試播可驗證的入口。

**重要限制：** 網頁搜尋結果出現代表「既有內容被索引」，並不直接量度「有多少人在 YouTube 搜尋」。搜尋排序、地區、語言、個人化、搜尋日期、資料索引和現有機構 SEO 都會影響結果。**本輪沒有取得 YouTube 原生 Keyword Search Volume、Google Trends 各區 YouTube Search 對照曲線或一手未信者訪談；不得宣稱 R01 30 條問題已完成市場需求驗證。**

## 目前可以比較的四種「入口」，及不能偷換的概念

1. **搜尋型**（「耶穌是誰？」）：可被搜索，長尾潛力需未來追蹤；已有啟發和問答競品。搜尋結果存在 `≠` 搜尋量。
2. **相關性型**（「禱告是否有效？」「焦慮」）：從具體生活問題開始，需防止把健康、家庭壓力的痛苦工具化。高單片觀看 `≠` 高未信者進入率。
3. **文化型**（「祭祖和孝道」）：有真正的中文世界語境；需理解地區和宗派差異。話題有衝突 `≠` 話題適合煽動爭論。
4. **系列教育型**（逐卷 Bible study）：已有固定供應；時間積累與觀看回訪需內部數據，系列存在 `≠` 回訪率已證明。

## 下一步測量：可執行且不虛構數據的 G1 要求

### A｜標準化 YouTube 搜尋抽樣

待研究的詞組在**繁體中文（台灣／香港）、簡體中文、英文**分開研究，於同一 UTC 日期：
- 用瀏覽器未登入模式記錄搜尋網址與地區／語言；取前 20 個可觀察結果，排除付費廣告與不相關結果；
- 每個結果標記發布日、觀看顯示、頻道、是否可供初接觸者理解、主張能否查證；
- 在相同主題下再比較「生活問句」和「教會術語問句」能否發現不同類型的結果；
- 結果只是當時搜尋頁的**供應與可發現性截面**，不能解作全站需求或演算法流量來源。

### B｜Google Trends 的相對搜尋意圖檢查

以 `geo=TW`、`geo=HK` 和海外目標市場，使用 YouTube Search 篩選，統一時窗比較同組的 2–5 個相關詞；保留導出 CSV 或官方截圖與 URL。**Google Trends 的 0–100 是正規化的相對指數，不是實際搜尋次數；低流量詞可能沒有充分數據。** [Q15]

### C｜觀眾直接語句

不得在未經同意情況下推斷個人的信仰、家庭或移民狀態。研究樣本的目的是**理解怎樣解釋得清楚**，可自願招募 12–18 名中文使用者（有／無教會背景者），分別看同一題的不同開頭、測試是否理解及下一步想了解什麼；不儲存敏感宗教個資、無須詢問是否受洗／歸信。

### D｜第一個測試題池（按測試價值，**不是熱度排名**）

| 優先試驗 | 問題 | 所服務的假設 | 需要的比較 |
|---|---|---|---|
| P1 | **耶穌是誰？為什麼不只是歷史人物？** | 進入門檻／是否可理解 | 直接解釋 vs 人物敘事 |
| P2 | **如果神愛人，為什麼有苦難？** | 複雜人生問題能否得到可信回答 | 問答 vs 經文敘事 |
| P3 | **基督徒如何理解祭祖與孝道？** | 中文文化的獨特語境 | 不同華語地區語境差異 |
| P4 | **聖經是怎麼形成的？** | 歷史與可核實證據的需求 | 歷史圖解 vs 主持人解說 |
| P5 | **感到孤單時，福音究竟能提供什麼？** | 從生活問題到福音本質 | 人物訪談 vs 釋經短片 |
| P6 | **約翰福音第一章究竟在說什麼？** | 零基礎能否進入連續讀經 | 逐節研讀 vs 整體敘事 |

**目前先取 2 個作小樣本理解度測試，不用播放量作選題唯一指標；上述選題均未經批准拍攝。**
