## 0. 本輪取得什麼，沒有取得什麼

本輪依 R01 問題庫和 R03 品質建議，對 **12 個具體福音問題**進行公開網頁／影片搜尋，為每一題記錄實際可開啟的內容來源、語言／片型、可直接查證的具體資訊，以及下一步需要測試的進入障礙。

**重要方法限制：這不是 YouTube 原生搜尋結果排行。** 使用公開 Web 搜尋定位影片及官方資源，因此只提供「索引可見的供應」與「片型證據」。Web 排序與 YouTube 站內排序不同，而且本輪沒有以台灣、香港、加拿大登入 YouTube 執行同條查詢，**不能**從任何結果推導各地的搜尋量、CTR、流量來源、熱度、競爭度或 Search Content Gap。

公開觀看數僅在 YouTube 搜尋來源明列時記錄，為檢索時的累計觀測，不是同齡影片可比表現。所有精確觀看數保留為文檔的 *dated snapshot*，不納入推薦方向的量化排序。

## 3. 三組具體有意義的競爭模式

### 模式 A｜同題「完整課程」與「單問題短片」都已存在

Alpha 一集「耶穌是誰」約 25–30 分鐘；Jesus Film 某些福音核心主題有 3 分鐘、32 語言短片。

**能推出**：長形式課程與 3 分鐘解釋不是市場空白，跨語音／字幕供應也已成熟。  
**不能推出**：哪個片長 CTR 或留存更高、是否能更有效吸引未信中文觀眾。需要控制題目、時長與觀眾理解度。

### 模式 B｜同題「家庭具體問題」與「長篇主日講道」都已存在

V07 共享觀點用家族拿香問題、明確章節組織；V08 台北靈糧堂用歷史文化與經文深度展開。

**能推出**：華人家庭文化問題值得作兩種內容形式比較；不是從零開始。  
**不能推出**：具體問題式片一定勝過講道。兩者的頻道規模、曝光來源、影片時長和發布日期不同。

### 模式 C｜「禱告為何沒有回應」已有高承諾的標題與見證敘事

2026 年初兩支有公開觀看觀測的影片一支使用三個方法、另一支主打「神故意不回答」與 42 分鐘祝福。

**能推出**：題目已經存在商業化／增長型包裝，不適合宣稱無人做。  
**風險**：若內容暗示某個方法必然得到醫治、財務改善或神蹟，需更嚴格的倫理、經文及證據審核。不能只因部分公開觀看較高就用同一承諾。

## 4. 語言研究：新確認的國際化競品不是簡單中英雙語

- Alpha 除繁體中文字幕版，還有**粵語配音**和**福建話配音**的華人啟發系列，部分版本具有不同講員／文化元素；故「中文」內部的方言／口語差異是真實競爭維度。[官方廣東話版](https://studentleadershipcollective.alphacanada.org/preview/chinese-alpha-film-series-cantonese-dubbing/)、[官方福建話版](https://studentleadershipcollective.alphacanada.org/preview/cafs-hokkien/)
- Jesus Film Project 的兩支標準問題短片標示有 **32 個語言版本**；其中文平台頁面有繁／簡及其他文字資源。
- 官方 YouTube 允許有 Advanced features 資格的創作者自行上傳同片多語音軌、翻譯標題和描述，與**自動配音**不同；配音必須自己或外包提供、同步時長接近；亦能按音軌語言在 Analytics 觀察觀看與時長。 https://support.google.com/youtube/answer/13338784

**工程意義**：中文主受眾不只意味「繁體字幕 + 英文字幕」，還要在同題內容的文化語境、聲音和翻譯一致性上求證。尚不定案雙頻道／多語音軌方案。

| 方向 | 市場供應已證實 | 值得測的**產品差異** | 潛在短板 |

| 系列讀經 | BibleProject、獨立講員 | 單節／單卷可相互導航、視覺幫助理解 | 不同能力的觀眾會需要不同深度 |

以上是**待測產品方向**，不是決定頻道內容支柱；與既定的福音使命相比，沒有以廣告觀看取代目標。

## 6. 搜尋需求的實際欠缺：不能再把索引當搜尋量

- **已取得：** Web 可索引的內容供應、部分 YouTube 影片觀看及發布日期、片型／問題框架／語言版本。
- **尚未取得：** YouTube Studio Trends 某個已授權頻道中 28 日查詢興趣、台港地區相同查詢的 YouTube 原生搜尋頁比較、Google Trends *YouTube Search* 真實索引曲線、觀眾直接提問。
- **官方限制：** Trends 只有部分國家／語言可用，提供 28 日興趣而非絕對搜尋量；YouTube/Google 搜尋指標不能假設相同。https://support.google.com/youtube/answer/11962757
- Google Trends 0–100 是篩選條件下的正規化相對指數，不能被當作每月觀看數或搜尋人數。https://support.google.com/trends/answer/4365533

下一步如要聲稱某個詞「高需求／低供應」，需要逐題 E1（搜尋量／Trends）與 E2（供應）同時成立；目前 E1 **unknown**。
