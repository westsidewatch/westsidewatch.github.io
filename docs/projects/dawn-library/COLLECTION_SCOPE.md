# Dawn Library — Collection Scope

## Hard rule

黎明書局公開館藏的宗教範圍固定為：**基督教／聖經研究**。

這是資料入口、索引、封面預覽、策展、搜索與閱讀層共同遵守的硬規則，不是首頁推薦偏好，也不是單純的前台隱藏規則。

### 可收入

- 基督教聖經、註釋、神學、教會史、靈修、講道、宣教、禮儀、基督教藝術與相關歷史資料。
- 與聖經世界、古代近東、第二聖殿時期、早期基督教等直接相關的研究資料。
- **猶太教與猶太文獻可以作為研究資料收入**，尤其是希伯來聖經、第二聖殿、拉比文獻、猶太歷史、語言、考古以及基督教起源研究所需資料。它們屬於研究資料例外，不改變黎明書局的基督教館藏定位。
- 一般歷史、文學、語言、藝術、地圖、考古等非宗教資料，只要符合黎明書局既有選題與研究需要，可以收入。

### 不收入

其他宗教自身的經典、神學、靈修、教義、修行、傳記、宣教或宗教實踐類書籍不得進入黎明書局公開館藏，包括但不限於佛教、印度教、伊斯蘭教、錫克教、耆那教、神道、道教及其他非基督教宗教。

比較宗教或歷史研究只有在其主體明確服務於聖經／基督教研究時才可收入；不能以「宗教研究」名義讓其他宗教自身館藏重新流入。

## Enforcement

此規則必須在資料進入公開館藏之前執行。所有新增來源、bulk growth、canonical index、cover-preview shards、Cover Authority、搜索、策展集與後續閱讀層都必須繼承同一 scope gate。

禁止只在 CSS/UI 層隱藏。被判定為其他宗教自身資料的記錄應標記為 excluded，不生成公開封面，不進入公開搜索與策展候選集。

猶太研究資料使用 `jewish-research` 例外標記保留，不能被其他宗教排除規則誤殺。
