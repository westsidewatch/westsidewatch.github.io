# 黎明數據｜工程備忘

## 黎明書局：館藏、導航與閱讀能力

### 1. 輕薄的索引導航書局
黎明書局的底層前提不是「本站保存全部全文」。Dawn canonical identity 是館藏核心，維護書目、作者、語言、authority、分類、關係、封面預覽、索引與可靠閱讀去向。

目前 canonical 中已建立的二十餘萬個 Work 都是正式館藏。館藏身份不以本站是否持有全文為條件。後續擴充館藏，同樣以 canonical admission、索引與封面預覽為基本條件。

閱讀正文時優先使用抓取／按需調用能力建立當次閱讀資源；不把下載並永久保存全文設為運行前提。

### 2. 雜誌化導航
黎明書局不是普通搜索目錄。三晨星、光譜、策展集構成 editorial navigation：在大規模館藏索引上進行選題、聚合、關係建立與策展，讓重要的書、作者、議題與閱讀路徑上升到首頁和主要入口。

轉跳閱讀作品仍是完整館藏，也可進入搜索、索引、光譜與策展集的綜合分析。

### 3. 館藏身份與閱讀能力分離
館藏不分真假，也不因閱讀方式不同而改變身份。

- **黎明閱讀區**：Dawn 能合法、穩定地按需取得正文，送入 Reader，並進一步進入中文翻譯。正文可以是 session 級瞬時 materialization，不要求永久落庫。
- **轉跳閱讀區**：本站維持封面、索引、分類、策展與館藏關係，閱讀時前往可靠外部來源。只有書目、尚未確定閱讀入口的作品也繼續保留在館藏研究索引中。

把轉跳資源逐步提升為 Dawn 可讀，是閱讀能力升級，不是把「非館藏」變成「館藏」。

### 4. 第一可見性由工程能力決定
黎明書局自身需要形成中文方向的鮮明特點，但不預先用產品口號決定：

- 如果瞬時翻譯覆蓋率仍不足，首頁優先呈現**中文資源第一可見性**；
- 如果外文館藏已能穩定完成「按需抓取 → Reader → 中文翻譯」，且覆蓋量足以形成產品體驗，則提升為**瞬時翻譯第一可見性**。

兩種方向都不改變底層館藏、三晨星、光譜、策展集與轉跳閱讀結構，只決定首頁首先讓讀者看見什麼。

### 5. 後續雙軌
**主線：以真實可讀能力擴充館藏。** 先用現有館藏實測 Dawn 能穩定按需取得、閱讀和翻譯哪些來源與格式，把成功條件固化為閱讀能力標準，再優先吸收符合標準的新館藏。若大量高價值資源被同一技術缺口阻擋，再針對該缺口提升抓取、解析、Reader 或翻譯能力。

**支線：提升既有轉跳館藏的閱讀能力。** 轉跳區繼續正常作為館藏、索引和策展資源使用；同時研究新的合法抓取入口、格式解析與 acquisition 方法。來源一旦可以穩定按需取得正文，即增加 Dawn Reader／翻譯能力，不重建館藏身份。

### 6. 工程判斷原則
後續不得混淆：**館藏規模**、**導航能力**、**閱讀能力**、**Dawn 按需閱讀能力**、**黎明中文翻譯能力**。

黎明書局保持輕薄。正文不是館藏身份的必要組成部分；瞬時抓取、閱讀與翻譯是建立在館藏索引之上的能力層。
