# 第二部｜王的城

耶利哥留下來的是一座沒有留下建造者名字的城。蘇丹泉旁的人取水、挖溝、築牆、立塔，今天可以量出那些石頭的尺寸，推算工程需要多少人力，卻不知道第一個叫人把石頭搬過來的人叫什麼。幾千年後，兩河流域的城市變大，情形開始不同。南美索不達米亞缺少石材和木材，城市大量使用泥磚，真正困難的不是一個人會不會砌牆，而是成千上萬的人如何一起生活：河水要引進田地，渠道要疏浚，穀物要收入倉庫，土地、牲畜、工人和口糧需要計算。到主前3200年前後，烏魯克已經擴展到約250公頃，通常被視為人類最早的大型城市之一。大型泥磚公共建築支配城市景觀，牆面甚至嵌入彩色陶錐組成裝飾。城市擴大到這個程度，人的記憶已經不夠用了。考古學家找到的早期泥版沒有急著記錄英雄史詩，先記大麥、二粒小麥、麥芽、口糧和物資分配；文字最早的重要用途之一，是管理城市的帳。

這是一件很值得記住的小事。人類把話寫下來，最初留下的大量材料不是「我是誰」，而是「有多少」。有多少糧，有多少人，分出去多少，還剩多少。約主前3100—2900年的一塊原始楔形文字泥版，記錄大麥的分配，上面還壓著圓筒印章的圖像：一個被研究者稱為「祭司王」的人物牽著兩條狗，在蘆葦沼澤中驅趕或獵取野豬。城市行政、宗教權威、物資管理和一個居於中心的人，已經出現在同一塊不過幾厘米大的泥巴上。

王並不是有一天忽然戴著王冠走進城門的。城把陌生的人聚在一起，也製造出大量不能再由一家一戶處理的事情。水渠、倉庫、土地、工程、祭祀、糾紛都需要協調。原來分散在各家的東西逐漸有了公共尺度：我們的水渠、我們的糧倉、我們的神廟、我們的城。這個「我們」最後需要一張臉。城需要有人把眾人變成一個整體，王也很快發現，城可以把一個人的權力變成石頭。

到了烏爾，這件事已經可以拿在手裡看。賓夕法尼亞大學博物館收藏一塊約主前2100年的泥磚，長寬各34厘米，厚8.5厘米，是1926年英國博物館與賓大聯合考古隊從烏爾帶回的。磚上蓋著烏爾納姆的銘文，說烏爾王烏爾納姆為月神南納建造神廟，也為他建造烏爾城牆。磚還沒有乾的時候，一條狗從上面走過，留下了一個腳印。三千多年以後，王的名字和狗的腳印一起留了下來。

這塊磚比很多王權理論說得清楚。真正和泥、製坯、曬磚、搬運、砌築的人沒有留下姓名，建築留下的卻是王的名字。王的身體只有一個人的大小，城可以替他延長手臂；王只能活幾十年，磚上的名字可以活幾千年。烏爾納姆並不是孤例，古代近東的王反覆以修城牆、神廟、運河和宮殿記錄自己的統治。建造不只是工程，也是王權留下自身的方法。

《創世記》十一章把這件事放在一個更早、更簡單的場景裡。示拿地的人學會燒磚，以磚當石，以石漆當灰泥，商量建一座城和一座塔，「為要傳揚我們的名，免得我們分散在全地上」。經文沒有告訴我們工程預算，也沒有留下主持人的名字，卻把城市的一個古老願望保存下來：人不願分散，也不願消失。城提供聚集，塔提供高度，名字提供一種對死亡的抵抗。考古學不能證明一塊美索不達米亞的磚就是巴別塔的磚，《創世記》也沒有要求我們作這種辨認；值得注意的是，泥磚、瀝青、大型建造、城市與名字，確實都是古代美索不達米亞世界可以理解的東西。

以色列進入這部城市史時，有一段很長的時間沒有人的王。他們有十二支派，有律法、祭司、會幕和士師。《申命記》早已預見有一天百姓會要求一位「像四圍的國一樣」的王；到了撒母耳年老，這一天真的來了。百姓要求立王治理他們，理由很普通：別的國家都有。神對撒母耳說：「他們不是厭棄你，乃是厭棄我，不要我作他們的王。」這使以色列的立王從一開始就與周圍古代王國不同。問題不只是選出哪一個人治理國家，而是這群已經有王的人，仍然想要一個看得見的王。

撒母耳沒有用一句「王會腐敗」把事情說完。他列了一張帳。王會取兒子去駕車、跟馬、耕田、收割、製造軍器；取女兒製香膏、作飯、烤餅；取最好的田地、葡萄園和橄欖園；取出產的十分之一，取僕人、牲畜，最後連羊群也取十分之一。《撒母耳記上》八章反覆使用同一個動詞：取。百姓聽完，回答仍然是：「不然！我們定要一個王治理我們。」王要替他們判斷，走在他們前面，替他們爭戰。代價已經報給他們，他們還是要王。

到了所羅門，撒母耳那張帳有了建築的形狀。黎巴嫩的香柏要砍伐，巨石要鑿出，木材要運輸，工匠和勞役要組織。聖殿建了七年，所羅門自己的宮室建了十三年。《列王紀》沒有把宏偉建築和勞動成本分開敘述。等所羅門死後，百姓到示劍見羅波安，沒有先談香柏木和雕刻，只說：「你父親使我們負重軛。」一座王城從遠處看見的是宮殿、聖殿、城牆和門，走近以後還有人肩膀上的重量。

這也使《聖經》沒有把問題簡化成「壞王」。大衛正好使這種解釋站不住。他從牧羊人開始，被掃羅追殺，在曠野裡知道掌權者怎樣逼迫沒有權力的人；他成為王後，在拔示巴與烏利亞的事情上，一個人的私慾卻可以沿著王權一直傳到軍隊。大衛沒有親手在城外殺死烏利亞，只需要寫一封信。權力沒有創造一種新的罪，它使一個人的罪突然可以使用別人的手。

北國後來另建了一座王城。暗利用二他連得銀子從示瑪買下一座山，在山上築城，按原主示瑪的名字稱為撒馬利亞。它的希伯來名字 Šōmrôn 在《列王紀上》十六章的敘事中來自 Shemer，不能簡單翻成「守望之城」；它在聲音上卻與希伯來語表示守、看守的 š-m-r 靠得很近。一座王城建在山上，名字裡留下了一個「守」的回聲。後來的撒馬利亞有王宮，有象牙裝飾，有行政文書，有一個足以與周圍列國交涉的王朝。王宮旁邊偏偏有一塊葡萄園。

拿伯不肯賣。

這塊葡萄園很小，小到放在一個王國的地圖上幾乎看不見，卻把王城的問題縮到一個人和一塊地。亞哈想把它改成菜園，提出交換或付錢；拿伯以祖產為由拒絕。王回到宮裡悶悶不樂。耶洗別問他：「你現在是治理以色列國不是？」接下來的事情不需要大軍。長老、貴胄、書信、印、假見證和一場公開審判就夠了。拿伯死後，亞哈下去接收葡萄園，以利亞在那裡等他。城本來需要王處理眾人的事情；到了這裡，問題變成：當王自己成為問題，誰來限制王？

古代王城留下的東西往往很耐看。城門可以挖出來，宮殿基礎可以測量，象牙碎片可以放進博物館，王的名字可以從磚和碑上重新讀出來。王自己留下得很少。烏魯克的統治者不在了，烏爾納姆不在了，烏爾第三王朝也沒有因為把王名壓進磚裡而長存。亞哈的王宮成了考古地層，撒馬利亞後來又換過許多主人。所羅門的宮殿沒有留下來，第一聖殿也沒有留下來。人把王的名字寫進城市，城市仍然會倒；城市把王放大，也把王的有限放大。

奇怪的是，人並沒有因此停止要王。

《撒母耳記上》八章最值得反覆讀的不是百姓犯了一次政治錯誤，而是他們在知道代價之後仍然說：「我們定要一個王。」這個願望不能只用愚昧解釋。人需要判斷，需要秩序，需要保護，希望危險來的時候有人走在前面；人不願成為散落在地上的個體，希望有人把許多個「我」變成「我們」。人希望自己的城不倒，自己的孩子仍住在其中，希望自己的名字不在死後消失。示拿地的人要「傳揚我們的名」，烏爾的王把名字壓在磚裡，以色列人要求一位可以走在他們前面的王，幾件事情隔了很久，彼此並不陌生。

問題在於，王也是人。帶著罪的人坐上王位，罪沒有因為王冠而改變性質，只是得到更大的活動範圍。王城一座一座倒下，新的王仍然出現；王死了，人重新尋找下一位王。這件事比王權本身更難解釋。也許真正需要問的，不是人為什麼一再選錯王，而是人為什麼如此固執地相信：我們應該有一位王。

有一座城把這個問題保存了三千年。

它不在大河旁，不是海港，也沒有佔據古代近東最重要的國際商路。它坐在猶大山地，水源有限，地形侷促。論自然條件，它沒有多少理由成為世界的中心。王來過，帝國來過，聖殿建起又倒下，城牆拆掉又重新砌起。有人把它改名，有人禁止另一群人進去，有人隔了幾代仍然回來。三千年過去，人類沒有把它忘掉。
