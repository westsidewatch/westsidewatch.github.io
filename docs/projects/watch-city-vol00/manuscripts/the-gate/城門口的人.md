# 城門口的人

城門在古代從來不只是一個出入口。

一座城有多大，牆有多厚，門開在哪裡，決定了人怎樣進去，也決定了誰可以被擋在外面。商人帶著貨物從這裡進城，軍隊從這裡出發；消息、命令、審判和交易，也常常在這裡發生。考古學家在夏瑣、米吉多、基色等古城遺址中看到不同時期的城門結構。城門有門房，有狹窄的通道，有可以停留的空間。聖經裡的城門也常常是一個公共場所：波阿斯在城門口召集長老處理路得的贖業；押沙龍站在通往城門的路旁攔住前來求王判斷的人；亞伯拉罕購買麥比拉洞時，赫人的眾人和進城門的人都成了交易的見證。

人在城門口做決定。

《創世記》裡有兩個人，他們最初一起走路。亞伯蘭離開吾珥，又離開哈蘭，羅得也跟著他。到了迦南，兩人的牲畜和財物都多起來，土地容不下他們同住。亞伯蘭把選擇先交給羅得：「遍地不都在你眼前嗎？請你離開我；你向左，我就向右；你向右，我就向左。」

羅得舉目。

他看見約旦河的全平原滋潤，直到瑣珥，「如同耶和華的園子，也像埃及地」。那是一個很難拒絕的景象。水、草場、城市，都在眼前。於是羅得選擇約旦河的全平原，漸漸挪移帳棚，直到所多瑪。

經文沒有說他那一天決定成為所多瑪人。他只是選了一片看起來更好的土地。

這種選擇很少在當下顯出全部重量。

到了《創世記》十四章，羅得已經「住在所多瑪」。四王與五王交戰，所多瑪和蛾摩拉戰敗，羅得連同財物被擄走。亞伯蘭帶著家中生養的精練壯丁追趕，把羅得、婦女和人民都奪回來。

羅得回去了。

《創世記》十九章再見到他的時候，經文只用了一個極短的畫面：「羅得正坐在所多瑪城門口。」

從「向所多瑪挪移帳棚」，到「住在所多瑪」，再到「坐在所多瑪城門口」，中間沒有一場盛大的宣誓。聖經只是一次又一次告訴我們他在哪裡。

那天傍晚，兩個天使到了城裡。羅得看見他們，就起來迎接，俯伏在地，堅持請他們進自己的家。夜裡，所多瑪人圍住房子。羅得出去，把門關在身後。他知道這座城是什麼樣子，也知道客人在街上過夜會遇見什麼。

天亮以前，天使催促他離開。

羅得遲延。

最後，是天使拉著他、他的妻子和兩個女兒的手，把他們領出城外。《創世記》說，這是因為「耶和華憐恤羅得」。他離開那座自己一步一步走進去的城，最後並不是靠自己走得快，而是被憐憫拉了出來。

另一個人仍住在帳棚裡。

亞伯拉罕也富有，也有牲畜、僕人和土地。他曾經打敗諸王，也曾與君王交談，但《希伯來書》回看他的一生時，留下的不是一座以他命名的城，而是一頂帳棚。他「等候那座有根基的城，就是神所經營所建造的」。

帳棚可以拔起。

城牆很難。

亞伯拉罕不是沒有地上的生活，他只是沒有把地上的城當作最後的城。他築壇，也挪動帳棚；神叫他往哪裡去，他就往哪裡去。很多時候，他甚至不知道下一站究竟在哪裡。

羅得的道路則一點一點固定下來。先是眼睛看見，然後腳走過去，帳棚挪過去，家住進去，最後人坐到了城門口。

大多數時候，沒有人會聽見門關上的聲音。多年以後回頭看，才發現自己已經坐在城門口。

## 後記｜兩種豐盛

羅得最初看見的那片土地，《創世記》留下了一個很奇怪的描述：「如同耶和華的園子，也像埃及地。」

兩個比喻放在一起。

伊甸是神所栽種的園子；埃及的富饒則依靠尼羅河。對一個帶著大量牲畜的人來說，約旦平原幾乎把兩種豐盛同時擺在眼前：它有園子的樣子，也有埃及的樣子。

羅得所看見的沒有錯。那裡確實滋潤。

問題不在於水是假的、草是假的、城市是假的。真正困難的地方恰恰在這裡：很多選擇之所以難，不是因為一眼就能看出邪惡，而是因為它真的很好看，也真的能供應眼前的生活。

亞伯拉罕後來也變得極其富有。《創世記》沒有把貧窮當作他的義。他有牛羊、金銀、僕人，也有足夠的力量追趕諸王。兩人的差別從來不是一個人擁有、一個人不擁有。

一個人把豐盛看作可以選擇的地方；另一個人在神的應許裡等候還沒有看見的城。

羅得站在山上時，看不見所多瑪最後的火。他只看見一片滋潤的平原。

亞伯拉罕也看不見自己所等候的那座城。

**他只有神的話，和一頂仍然可以拔起的帳棚。**
