# Hosanna Home / 入城

This is the first executable Web surface for Vol.00 and simultaneously the opening sequence of 《一萬年的建城禮》.

## One work, two needs

Do not build a separate homepage hero film and article intro. Both consume `sequence.json`.

The homepage loops the approach / montage / Hosanna arrival. Entering the issue freezes the loop and will hand off to the city-depth / ten-thousand-year map sequence.
