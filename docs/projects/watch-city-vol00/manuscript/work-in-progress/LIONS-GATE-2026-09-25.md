# 獅子門

> Working checkpoint, 2026-09-25. 尚未完成最終全文修正；完成後併回 `JERUSALEM-BUILD.md` canonical 母稿。此 checkpoint 不取代 canonical。

獅子已經有些看不清。耶路撒冷東城牆上，門洞左右各有兩隻，一共四隻。幾百年的風從汲淪谷吹上來，雨水沿著石灰岩往下走，獸身的輪廓變鈍，石縫裡積著深色的痕跡。遊客站在下面，很容易接受今天這個名字：獅子門。

可是這四隻獅子從哪裡來，事情反而沒有名字那麼清楚。今天的門是鄂圖曼蘇丹蘇萊曼大帝十六世紀重修耶路撒冷城牆時建的。四隻石獸卻比門老。人們通常把它們和十三世紀的馬穆魯克蘇丹拜巴爾聯繫起來，因為拜巴爾使用獅子作自己的標誌；石雕很可能來自更早的建築，被後來的人拆下，再嵌進新城牆。原來是哪一面牆、哪一座建築，已經沒有十分確定的答案。

要找這四隻獅子，先離開耶路撒冷，走入1237年的那個冬天。蒙古人到了梁贊——今天俄羅斯莫斯科東南方向的梁贊一帶。

後來的羅斯人留下了一部《拔都毀滅梁贊記》。這部作品經過後世傳抄，不能把其中每一個細節都當作1237年的現場記錄，但人遭遇毀滅以後留下的恐怖沒有那麼容易消失。城被圍住，戰鬥持續數日；守城的人死去，蒙古軍進城。作品裡的死亡沒有多少選擇：男人、女人、老人、孩子、修士、神父，一起落進災難。教堂被焚燒，修道院被破壞，城中的財物被掠走。作者回頭看自己熟悉的土地，留下的不是一場普通戰敗，而是一個世界突然被抹掉以後的哀哭。

鋪天蓋地的蒙古人的馬繼續往西，鋪天蓋地的恐怖也繼續往西。羅斯諸城一座接著一座陷落，1240年基輔遭到毀滅，軍隊再向西進入波蘭、匈牙利。蒙古帝國的另一條戰線向西南伸展。人類歷史很少見過這樣漫長而廣大的征服：從東亞直到東歐，城市、草原、河流、山口被一支支騎兵連在一起。蒙古人並不是所到之處都只會屠殺，他們後來也會治理、徵稅、保護商路、吸收工匠和不同文明；可是對那些拒絕投降而被攻破的城市而言，這些後來的事情沒有多少安慰。蒙古戰爭留下的大規模屠殺、人口遷徙和城市毀滅，使他們尚未到達以前，恐懼有時已經先到了。

1258年，這種恐懼到了巴格達。巴格達腳下已經是我們熟悉的兩河世界。再往南，就是古代巴比倫所在的土地。《創世記》裡的巴別，《列王紀》末尾毀掉耶路撒冷的巴比倫，幾千年以後已經換了城市、帝國和語言。阿拔斯王朝以巴格達為中心將近五百年，學者、圖書、醫學、數學、天文以及從希臘世界翻譯而來的大量知識曾經在這裡聚集。蒙古軍攻破巴格達，哈里發被殺，人口遭到大規模殺戮，城市受到嚴重破壞。

蒙古人繼續向西。阿勒頗陷落，大馬士革投降。大馬士革就是大馬士革，《聖經》裡那座亞蘭城，保羅被大光照的大馬色。主前八世紀，亞蘭王利汛和北國以色列王比加曾經聯合抵抗向西南逼近的亞述，又想把南國猶大拉進來。亞哈斯害怕亞蘭和以色列，反過來向亞述求救。亞述人來了，先攻破大馬士革，再吞掉北國，最後兵臨耶路撒冷。以賽亞稱亞述為耶和華怒氣的棍。

一千九百多年以後，又一支從兩河方向來的大軍穿過大馬士革，向南走。十三世紀蒙古人的腳下，一直踩著《創世記》《列王紀》《以賽亞書》走過的路。

幾千年前，亞伯拉罕一家從兩河世界出發，沿著有水、有草、有城鎮的道路向北，到哈蘭，再轉向南方，進入迦南。幾千年後，大隊戰馬同樣需要河流、牧草和道路。蒙古軍不是在重走亞伯拉罕的腳印，可是幼發拉底河、敘利亞和迦南之間那副巨大的地理骨架沒有改變。亞伯拉罕帶著家眷和牲畜走過去，亞述人的軍隊走過去，巴比倫人的軍隊走過去，現在蒙古人的馬也走了過來。

哪一個更殘暴，很難回答。亞述人曾經把剝皮、斬首、堆積人頭的場面刻在自己的宮殿浮雕和王室銘文裡，讓後來的人知道反抗帝國會有什麼結果。巴比倫軍隊攻破耶路撒冷，城牆被拆，聖殿被燒，西底家的眾子在他眼前被殺，他最後看見的就是自己的兒子死去，隨後雙眼被剜。蒙古人的屠城又把另一種巨大而迅速的毀滅帶進十三世紀。殘暴沒有必要分出第一名。人在這件事上似乎沒有真正進步過。帝國換名字，兵器換形狀，死去的人還是人。這世上只有恩典和更大的恩典；殘暴之後，仍然只是殘暴。

蒙古軍越過大馬士革，前面就是加利利，再往南，是耶斯列谷。蒙古帝國的主力偏偏在這時開始回撤。大汗蒙哥死亡，帝國最高權力重新出現空缺，旭烈兀帶走大部分軍隊返回東方。龐大的蒙古馬群需要的水和牧草，也使敘利亞的長期軍事部署受到現實限制。旭烈兀留下怯的不花和一支規模小得多的軍隊控制敘利亞。南面的埃及又恰好出現了一個能夠迎戰他們的政權。馬穆魯克原來是被購買、訓練成職業軍人的軍事奴隸，主人依靠他們作戰，他們後來掌握軍隊，再後來自己成了主人。埃及蘇丹忽都思決定不等蒙古軍南下，率軍向北，其中一個重要將領叫拜巴爾，他也是一個「馬穆魯克」。

1260年9月，兩軍在艾因札魯特相遇。這片土地也打過太多仗。艾因札魯特在耶斯列谷東端、基利波山附近，後世長久把附近的泉與《士師記》的哈律泉聯繫在一起。基甸曾在水邊留下三百人，讓其他人回家，帶著這三百人面對米甸大軍。後來掃羅和約拿單死在旁邊的基利波山。向西望去，平原一直通向米吉多；這片古老戰場附近還有一場將要爆發、注定來臨的末日大戰——哈米吉多頓。

這不是一塊蒙古騎兵跑不起來的土地。耶斯列谷足夠開闊，古代戰車早就在這裡奔馳。蒙古人的失敗也不是一個原因造成的。蒙哥恰好死亡，旭烈兀恰好帶走主力，留守軍隊數量有限；馬穆魯克恰好完成軍事整合，忽都思選擇主動北上，拜巴爾這樣的將領又恰好在軍中。戰場上的佯退、調動和反擊最後把這些條件合到了一起。一邊是剛剛攻破巴格達、阿勒頗和大馬士革，一路從亞洲深處帶著巨大恐怖而來的蒙古軍；另一邊，是一群曾經被人買來的軍事奴隸。

馬穆魯克贏了。

在此以前，強悍的蒙古軍幾乎未嘗敗績。如今在一片同樣適合戰馬奔馳的平原上，一支同樣騎馬征戰、對他們而言陌生的軍隊，以大致相當的兵力迎面把他們擊退。這不是蒙古人暫時撤出戰場。怯的不花被俘，隨後被殺，蒙古軍向北潰退。對一支從亞洲深處一路打到歐洲、又從巴格達打進大馬士革的軍隊來說，這是一場真正的大敗。因為這場大敗，蒙古人後來多次來犯，卻始終未曾染指耶路撒冷。

從人的角度，每一個條件都可以解釋。把這些條件同時放在1260年9月的耶斯列谷，用神蹟來形容這場勝利，也不過分。以賽亞早已寫過一個外邦王的名字，那個人叫居魯士。亞述吞滅列國，以賽亞又稱它為耶和華怒氣的棍。尼布甲尼撒將要來的時候，以西結記下的卻是耶和華的話：「我要使巴比倫王尼布甲尼撒來。」

1260年的拜巴爾還不是蘇丹。三年後，他走進耶路撒冷。

拜巴爾來的時候，圓頂清真寺已經在聖殿山上站了五百七十多年。史料記下的不是一場盛大的入城儀式，而是一些很細小的事情。他登上聖所，查看需要修繕的地方，查宗教基金的收入和支出，催促敘利亞方面把修繕需要的東西送來。他禁止軍隊踐踏耕地，甚至有一個馬穆魯克因為拿了一點乾草餵馬受到處罰。他還為來到耶路撒冷的人修建住宿的地方。三年前，他在耶斯列谷帶著騎兵迎擊蒙古人；三年後，他在耶路撒冷管屋頂、帳目、乾草和房子。

他正在修的那座圓頂，是另一個人留下的。

那個人叫阿卜杜勒·馬利克，倭馬亞王朝第五任哈里發。685年他接掌的帝國並不安穩，穆斯林世界仍在內戰，大馬士革是倭馬亞政權的中心，麥加另有與他爭奪哈里發權位的阿卜杜拉·伊本·祖拜爾，北面還有拜占庭帝國。阿卜杜勒·馬利克後來重新集中權力，改革貨幣和行政，使一個迅速擴張、仍大量使用拜占庭與薩珊舊制度的帝國逐漸長出自己的政治和文化面貌。大約688年，他又在耶路撒冷開始一項工程。691至692年前後，圓頂清真寺完成。

它不是後來常見的那種大型會眾清真寺。整座建築首先是在圍著一塊石頭建造。

這塊石頭已經承受了太多人的記憶。猶太和基督教傳統把聖殿山與摩利亞山相連，後來又有人把圓頂下面的岩石直接認作亞伯拉罕獻以撒的地方；猶太傳統把這一帶與第一、第二聖殿和至聖所相連；穆斯林則把岩石與穆罕默德夜行登霄聯繫在一起。十字軍佔領耶路撒冷以後，又把這座穆斯林建築稱作 *Templum Domini*——主的聖殿。不同的人來到這裡，不斷替同一塊石頭增加名字。

石頭下面還有一個洞穴。

從圓頂內沿階梯走下去，地下的空間並不大。幾個祈禱位置又把亞伯拉罕以及其他先知的名字帶到岩石下面；不同傳統中還可以看到與摩西、以利亞等先知相關的紀念。這些名稱不能拿來證明某位先知曾經站在洞穴裡的某一個位置，它們首先告訴我們，後來的人如何理解這塊石頭。洞穴地面的一處凹槽又引出更多故事。有人把它與昔日至聖所和約櫃的位置聯繫起來，有人相信岩石下面還有更深的空間，也一直有人猜測第一聖殿消失之後再沒有出現的約櫃仍藏在聖殿山下面。

沒有人把它挖出來。

約櫃倒真的被人搶走過。《撒母耳記》裡，以色列人與非利士人打仗，先敗一場，便想到把耶和華的約櫃抬到戰場。約櫃一進營，全營歡呼，地也震動。他們彷彿以為把約櫃帶來，神便應當照人的意思替他們打仗。

結果還是敗。

以利的兩個兒子被殺，約櫃被擄。非利士人把約櫃帶進大袞廟，放在大袞旁邊。第二天，大袞倒在約櫃前。人把大袞扶起來。再過一天，大袞又倒，頭和兩手都斷在門檻上。以色列沒有派出一支軍隊把約櫃救回來，最後是非利士人自己預備新車，把它送走。

神不需要人來保護。

這句話到了1260年的耶斯列谷，不需要再說第二遍。

拜巴爾三年後站在聖殿山上，也不會按照我們今天這條線理解自己。他做的只是統治者要做的事情：查帳、修房子、管軍隊、保護田地。可是從梁贊一路走到這裡，事情已經留下另一種形狀。梁贊陷落，基輔陷落，巴格達陷落，阿勒頗陷落，大馬士革投降；蒙古人的馬到了加利利，在耶斯列谷被擋住。三年後，擋住他們的一個馬穆魯克走進耶路撒冷，不是拆牆，而是查看一座五百七十多年的建築哪裡需要修。

拜巴爾並不因此成為一個溫和的人。他後來成為蘇丹，繼續向十字軍控制的城市和堡壘進攻。凱撒利亞、阿爾蘇夫、薩法德、雅法、安提阿，一個接一個遭到他的軍隊攻擊。有些地方被拆毀，有些地方的人被殺或被擄。那個在耶路撒冷不准士兵踩壞田地的人，也可以在另一座城下令拆牆。人的身分從來不能替人的行為作保。蒙古人會建，馬穆魯克會毀；十字軍會建，也會毀。到了後面的「毀」，我們還會再碰見這些人。

耶路撒冷卻在馬穆魯克手裡繼續建。這不是幾年的插曲。從十三世紀中葉到1517年鄂圖曼人取得這座城，馬穆魯克統治延續兩百五十多年。今天沿著聖殿山西側走，仍能看到他們留下的宗教學校、旅舍、陵墓、拱門、商業設施和一層一層向街道伸出的石造立面。十字軍留下的東西被重新使用，阿尤布王朝留下的東西繼續使用，新的宗教基金又把敬拜、教育、商業和住宿編進同一座城市。城沒有因為換了主人停止生長。

1517年，主人又換。

鄂圖曼帝國進入耶路撒冷。二十多年後，蘇萊曼大帝大規模重修城牆。今天包圍老城的大部分城牆，就是這次工程留下。東面也建起一座新門。

有人把四隻更早的石獸嵌進門牆。

拜巴爾已經死去兩百多年，馬穆魯克王朝也不存在。四隻獅子卻到了另一個帝國的牆上。它們原來究竟裝飾哪座建築，為什麼被搬到這裡，已經說不十分清楚。幾百年的風繼續吹，石頭表面慢慢磨損，輪廓一點點變鈍。最後人乾脆用它們給整座門起了一個名字。

獅子門。

人手造的獅子，連自己的來歷都沒有完全留下。《聖經》裡的獅子卻一直還在。

雅各年老，把兒子們叫到身邊。輪到猶大，他說：「猶大是個小獅子。」接著是圭不離猶大，杖不離他兩腳之間。獅子、猶大和王權從這裡連在一起。參孫往亭拿去，一隻少壯獅子向他吼叫，耶和華的靈大大感動他，他徒手把獅子撕開；後來蜂在獅子的屍體裡作蜜，他便留下一個謎語：「吃的從吃者出來，甜的從強者出來。」大衛還只是牧羊少年，對掃羅說，獅子和熊來叼羊，他便追上去，從口中把羊救回來。到了所羅門，獅子堂堂正正進了王宮，寶座兩旁有獅子，六級台階又站著十二隻。

獅子可以是王權，可以是力量，可以是得勝，也可以是審判。阿摩司說獅子吼叫，誰不懼怕；彼得卻提醒教會，魔鬼也像吼叫的獅子，遍地遊行，尋找可以吞吃的人。

所以看見獅子，還不知道它是誰。

國王喜歡獅子，蘇丹喜歡獅子，帝國也喜歡獅子。人把自己想要的力量刻進石頭，掛在旗上，放在王座旁邊。拜巴爾的獅子經過另一個帝國的手，被嵌進另一面城牆，幾百年後還伏在那裡。

《啟示錄》第五章，約翰哭的時候，一位長老對他說：「不要哭。看哪，猶大支派中的獅子，大衛的根，他已得勝。」

約翰轉過身。

他看見一隻羔羊，像是被殺過的。

獅子沒有消失。真正的王站在那裡。

今天再走到耶路撒冷東面的城牆，四隻石獅仍伏在門上。拜巴爾的帝國沒有了，蘇萊曼的帝國也沒有了。風吹過汲淪谷，石頭繼續磨損，橄欖山還在對面。

沿著城牆再往前走，下一個古老的名字，是羊門。
