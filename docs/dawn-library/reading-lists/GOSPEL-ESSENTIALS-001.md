# 福音必讀：從信仰的提問走向門徒生活

> 黎明書局首發書單／2026-11-23／編輯試刊：待整體圖版、版次與瀏覽器驗收。

**編輯命題：** 對耶穌感到好奇、對教會仍有疑問的中文讀者，應如何讀到信仰核心，再進入真實生活？

本書單不是以論證贏過懷疑者，而是邀請中文讀者沿著耶穌身分、良知道德、現代疑難、神的屬性與門徒生活閱讀。不同作者不提供同一種回答，彼此辯證才有價值。

**讀者：** 慕道者、初信者、帶領福音小組的人，以及希望重新釐清福音的信徒

**閱讀次序：** 耶穌的身分 → 道德與理性 → 當代疑問 → 概念深掘 → 認識神 → 門徒生活

## 1｜真理的尋索：基督教是否可信 — 斯托得（John Stott）

**推薦理由：**先以耶穌是誰、祂做了什麼來理解福音，而非先要求讀者接受一套宗教規條；語言直接，很適合真正想了解基督信仰的人。

**閱讀指南：**這是基督徒的肯定性論證，應鼓勵讀者同時查考福音書，並辨識論述與一手經文之別。

**比較：**相較路易士由道德經驗起步，本書將讀者更直接帶回耶穌基督其人與救恩宣告。

**版本資料：** [出版社／出版方資料](https://eshop.ccl.org.hk/products/c066018p)

## 2｜返璞歸真：純粹的基督教 — 魯益師（C. S. Lewis）

**推薦理由：**以文學家的清晰類比與推理，討論良知、善惡、信仰共同核心及基督徒生活；對不願只接受標準答案的讀者尤其重要。

**閱讀指南：**其廣播式論證承載二十世紀英國文化語境，不等於所有哲學家都同意；同一原著另譯《我如何思考基督教》，不能重複算書。

**比較：**它比《真理的尋索》更側重公共理性與倫理論證；兩本並讀才能看見不同的入門道路。

**版本資料：** [出版社／出版方資料](https://www.wunan.com.tw/bookdetail?NO=12911)

## 3｜我為什麼相信？ — 提摩太・凱勒（Timothy Keller）

**推薦理由：**逐項面對宗教排他性、苦難、科學、聖經與疑惑，讓城市中的尋道者有機會把反對意見清楚說出來。

**閱讀指南：**書中的回應屬於作者的護教策略，不是每種文化處境唯一有效的回答；《為何是祂》是同一原著的另一中譯，須統一 Work。

**比較：**相較路易士從良知展開，凱勒的起點是現代城市讀者實際提出的異議。

**版本資料：** [出版社／出版方資料](https://shop.campus.org.tw/ProductDetails.aspx?ProductID=202377337)

## 4｜教我如何不信祂 — 史普羅（R. C. Sproul）

**推薦理由：**直接處理信仰看似矛盾之處，迫使讀者區分反對意見是否準確以及回應是否有充分理由。

**閱讀指南：**作者出自改革宗傳統，讀者需辨識其護教立場；對未信者不宜只拋出論點，應提供深入對話的空間。

**比較：**相較凱勒的城市與文化敘事，史普羅偏向概念釐清與論證拆解。

**版本資料：** [出版社／出版方資料](https://www.cc-us.org/shop/c9789869692908/)

## 5｜認識神（增訂版） — 巴刻（J. I. Packer）

**推薦理由：**當讀者開始思考上帝的屬性與關係，這本書把神學知識與敬拜、生命實踐連結，避免只停留在辯論階段。

**閱讀指南：**它比前三本概念密集，並具有明確福音派神學立場；讀者不應把討論上帝的性情誤認為能以概念完全掌握神。

**比較：**放在護教讀物之後，代表從『信仰是否合理』轉向『我所信的神是誰』。

**版本資料：** [出版社／出版方資料](https://shop.campus.org.tw/ProductDetails.aspx?productID=000098021)

## 6｜世界在等待的門徒 — 斯托得（John Stott）

**推薦理由：**以不隨波逐流、成熟、簡樸、平衡及對受造世界的責任等問題，把相信耶穌轉化為可檢驗的門徒生活。

**閱讀指南：**其論述出自作者晚年的牧養總結，不可將每項生活建議當成律法；也應注意不同讀者的具體責任與處境。

**比較：**以門徒生活作收束，讓《真理的尋索》打開的耶穌問題不只停在認知層面。

**版本資料：** [出版社／出版方資料](https://shop.campus.org.tw/ProductDetails.aspx?ProductID=000495219)

## 閱讀中應思考的問題

1. 你最大的信仰疑問，是對耶穌其人、對宗教團體，還是對世界的苦難？
2. 路易士與凱勒如何使用理性、經驗及文化作論證？
3. 護教作品的推論與福音書自身的見證應如何分辨？
4. 認識上帝如何與愛鄰舍、簡樸和成熟生命相連？
