# 教會歷史：誰記錄了教會的過去？

**選書方法：**原始史料、通史與華人史學互證  
**面向讀者：**希望掌握教會歷史縱深的中文信徒、主日學／查經帶領者、文化研究者  
**不提供：**只要人物年表或確證自己宗派永遠正確的讀者  
**讀者問題：**當我們談論『教會歷史』時，哪些聲音是原始證人、哪些是後來的敘事者、誰可能被遺忘？  

## 編輯論點

讓一部早期自我敘述、一部廣域教會通史、天主教入華文本、近代華人史著及台灣現場證言相互檢驗，而不是把教會史寫成不斷勝利的名人榜。

**閱讀秩序：**先有全球通史地圖 → 讀早期史學源頭 → 進入明清與台灣史料 → 轉至華人史家與近現代辯論。這個次序按理解方式而非書籍年代或出版社編排；困難作品可以慢讀、跳讀、重讀。

## 作品的獨立編輯位置

### 1. 《基督教史（上、下卷）》｜胡斯托・岡薩雷斯（Justo L. González）

**為何選：**先用廣角歷史建立年代與地域框架，之後才可辨識一手史料在哪些問題上有選擇。

**擔任的角色：**地圖｜提供跨時代的全球敘事輪廓。  
**應當注意：**通史的便利也可能令複雜地方史被壓縮；兩卷為同一作品／版本層級的卷次，不能當兩部入選。  
**與其他入選作品比較：**相較祁伯爾易讀總覽，本冊優先選擇更明確觸及婦女、全球南方與不同信仰相遇的修訂版。  
**建議閱讀層級：**入門→中階。  
**證據／文本審讀狀態：**bibliography_and_publisher_contents_only（不代表已完成全書審讀）。

### 2. 《教會史》｜優西比烏（Eusebius of Caesarea）

**為何選：**最有價值的不只是早期事件資訊，而是作者如何選擇使徒傳承、殉道與異端等材料，並使其形成有神學意圖的敘事。

**擔任的角色：**史料｜理解早期教會如何向後世書寫自己。  
**應當注意：**卷一第1章作者自述挑選史料；卷十對教會獲和平的頌揚尤其提醒讀者考慮權力與敘事的關係；『早』不等於中立。  
**與其他入選作品比較：**與岡薩雷斯並讀，讀者可直接比較『早期參與者』和『現代史學者』對事件的不同敘述目的。  
**建議閱讀層級：**進階。  
**證據／文本審讀狀態：**primary_book_i_ch1_and_book_x_ch1_to3（不代表已完成全書審讀）。

### 3. 《利瑪竇中國札記》｜利瑪竇（Matteo Ricci），金尼閣（Nicolas Trigault）整理／翻譯

**為何選：**它讓教會史從歐洲制度史走向明代中國的語言、知識與日常交流，也同時暴露外來觀察者的偏見。

**擔任的角色：**史料｜明代文化遭遇、知識轉譯與耶穌會入華敘事。  
**應當注意：**1615年拉丁文印本經金尼閣整理，不能稱為利瑪竇未經編修的逐日原稿；中文譯本又經其他語文傳遞，必須標明譯源。  
**與其他入選作品比較：**和馬偕敘事並讀，可比較十七世紀天主教與十九世紀新教如何分別理解中文世界。  
**建議閱讀層級：**中高階。  
**證據／文本審讀狀態：**historical_textual_origin_and_bibliography_only（不代表已完成全書審讀）。

### 4. 《中國基督教史綱》｜王治心

**為何選：**不只是後來學者研究中國基督教的對象，更可觀察一位中國基督教史家如何為自己的傳統組織歷史脈絡。

**擔任的角色：**史學｜回到20世紀前半中國作者自己的歷史敘述。  
**應當注意：**原版1940，後有重刊與影印；不可用現在史學的分類不加說明地稱其為『全面正史』，亦不可將重印年份當原著年代。  
**與其他入選作品比較：**與梁家麟的近代史敘述對讀，可看出不同世代華人基督教史學的問題意識。  
**建議閱讀層級：**高階。  
**證據／文本審讀狀態：**historical_bibliography_and_contents_only（不代表已完成全書審讀）。

### 5. 《福臨中華：中國近代教會史十講》｜梁家麟

**為何選：**讓中文讀者由華人作者建立近代史的主要坐標；對讀者最大的好處，是開始用史學方法追問自己所熟悉的教會見證。

**擔任的角色：**近代通史｜把1807–1957年的中國教會史寫成可進入的敘事。  
**應當注意：**時間段與近代新教史的聚焦應清楚說明，不能誤認等於中國基督教全史，也不能取代天主教與更早歷史。  
**與其他入選作品比較：**若只先讀一本華人作者的近代教會史導論，暫以本書優先於更專門的段琦研究。  
**建議閱讀層級：**入門→中階。  
**證據／文本審讀狀態：**bibliography_and_editorial_description_only（不代表已完成全書審讀）。

### 6. 《福爾摩沙紀事：馬偕台灣回憶錄》｜馬偕（George Leslie Mackay）；歷次編譯者另記

**為何選：**值得入選，恰恰因為它既是一位宣教者的珍貴見證，也是一份需要旁證的外來觀察材料。

**擔任的角色：**地方現場｜藉台灣日常、教育、宣教與族群接觸閱讀歷史。  
**應當注意：**不同中文譯名《台灣遙寄》《台灣六記》《福爾摩沙紀事》等可能對應同 Work 的不同 Edition；族群與殖民語言須配合台灣本地及原住民族史料。  
**與其他入選作品比較：**與《利瑪竇中國札記》並讀，不是證明兩種宣教有同一模式，而是看不同時代他者如何描述地方社會。  
**建議閱讀層級：**中高階。  
**證據／文本審讀狀態：**archival_bibliography_and_structure_only（不代表已完成全書審讀）。

### 7. 《奮進的歷程：中國基督教的本色化》｜段琦

**為何選：**把書單帶出宣教成就史，閱讀中國基督教怎樣在政治、文化與教會主體之間形成自己的身份與辯論。

**擔任的角色：**批評｜由本色化爭論重新理解本土教會形成。  
**應當注意：**非信徒學術視角與信徒史家不是誰天然勝出，應按各自資料、問題、價值取向作比較；2004與後續版次分開。  
**與其他入選作品比較：**與王治心、梁家麟構成三代中文作者的不同寫作位置，形成此書單最重要的對照。  
**建議閱讀層級：**高階。  
**證據／文本審讀狀態：**publisher_introduction_and_research_context_only（不代表已完成全書審讀）。

## 被比較但未入選首冊

- **祁伯爾《歷史的軌跡：二千年教會史》：**適合易讀通史，但首冊已有岡薩雷斯《基督教史》擔任全球通史；避免兩部概覽掩蓋中文第一手史料，保留為閱讀程度替代選項。
- **只以西方宗派興衰為主的歷史暢銷榜：**不能代表中國、東方教會與原住民族等地方歷史主體。
- **沒有一手來源的宣教英雄傳奇：**作信仰見證可能感人，但不宜替代史料考證。

## 讀者可帶著的問題

1. 歷史記載與神學詮釋之間如何互相影響？
2. 中文教會史由誰書寫，西方／本土視角何以不同？
3. 同一歷史事件中哪些人的見證沒有被記錄？
4. 如何在尊重信仰見證的同時保持史學批判？
