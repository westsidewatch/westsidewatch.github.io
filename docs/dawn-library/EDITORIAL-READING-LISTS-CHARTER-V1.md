# 黎明書局｜精品書單核心編輯能力 V1

> 2026-11-22｜內部編輯研究，不是已出版的書單；前次來源驅動的 PR #1412 已關閉，禁止恢復其選書方法。

## 一、唯一上游原則

**先有讀者與編輯問題，後有值得推薦的作品。最後才尋找合法中文閱讀來源。**

我們的出版品不是網址、書量或免費 PDF，而是可信的閱讀判斷：能指出一本書何以出色、適合誰、如何讀、值得與什麼作品並讀、在哪些地方可能被誤解。**書源搜尋不能決定作品的文學、神學或歷史價值。**

## 二、既有三欄目保持原樣

架構權威：`docs/MASTER_SITE_ARCHITECTURE.md §4.1`。

- 三晨星：經過評估的資源，此刻哪些特別值得留下和推薦？
- 光譜：資源、經文、思想與歷史之間的知識關係如何呈現？
- 策展集：如何設計一條跨書籍、圖像、經文、史料及工具的學習道路？

本**內部編輯室**是它們的研究與評審上游，不是第四個公眾欄目。同一作品在不同書單中有不同編輯理由，正式 Work 身份仍唯一。

## 三、八種成熟編輯方法；二十四個可選企劃

### 1. 歷代經典｜經典評選
- **值得反覆讀的經典**：哪些作品能穿越時代、仍可挑戰今日讀者？ 選法：思想深度與跨時代影響；避免：有名就必讀。
- **慢讀之書**：什麼文本值得花一年而非一天讀完？ 選法：閱讀深度與注釋導引；避免：書越厚越經典。
- **改變教會的思想爭論**：哪些關鍵分歧改變了信仰歷史？ 選法：正反原典與歷史背景；避免：只選勝方。

### 2. 薦書者與閱讀權威｜具名推薦
- **牧者的書房**：牧者曾在何時、為何推薦這本書？ 選法：直接推薦證據與獨立編輯判斷；避免：講道引用等同推薦。
- **神學家的案頭**：一位學者如何建立自己的閱讀思想？ 選法：可核查的薦讀、書評及課程脈絡；避免：被引用等同被推薦。
- **兩種傳統的答案**：不同教會傳統對同一問題如何讀書？ 選法：平行書單與比較評議；避免：假裝只有一種立場。

### 3. 內在生活｜靈性緩讀
- **內在生活**：如何從宗教忙碌走向與神相交？ 選法：靈修經典加上語境與批評；避免：靈性成功學。
- **禱告的學校**：禱告是技巧、習慣還是關係？ 選法：實踐、神學與文本對讀；避免：操練保證有效。
- **苦難中的禱告**：痛苦、沉默與盼望如何被書寫？ 選法：見證、詩歌與神學比較；避免：以傷痛作煽情。

### 4. 教會歷史｜史料導讀
- **教會史的十個現場**：誰記錄了教會的歷史？漏了誰？ 選法：原始史料與史家觀點對讀；避免：英雄榜代替史學。
- **中國教會的記憶**：華人教會如何記憶自身歷史？ 選法：地方史料和不同主體並讀；避免：只見外國宣教士。
- **宣教與文化的相遇**：福音與地方文化曾如何互相改變？ 選法：第一手記述與文化史研究；避免：用單一勝利敘事。

### 5. 聖經細讀｜經文導讀
- **與一卷書同行**：一本聖經書卷如何引出一個閱讀世界？ 選法：經卷與註釋的分層選讀；避免：只列熱門註釋。
- **福音書四讀**：四福音書異同有何閱讀價值？ 選法：並讀敘事而不消除差異；避免：以求同抹平文本。
- **釋經方法交鋒**：同一段經文為何有不同可靠解法？ 選法：方法教材及案例比較；避免：一本方法書包辦一切。

### 6. 人生與牧養｜讀者處境
- **牧者的困難書架**：事奉倦怠與群體衝突時讀什麼？ 選法：牧養現場與專業邊界；避免：閱讀代替治療。
- **職場與召命**：工作與敬拜有何內在關係？ 選法：神學、職場經驗及倫理；避免：成功神學。
- **生命的下半場**：衰老、照顧與盼望如何彼此連結？ 選法：照顧見證與信仰反省；避免：把老人當作問題。

### 7. 思想、藝術與公共世界｜跨學科批評
- **科學與信仰**：論點和證據應如何區分？ 選法：專業資格與論證檢驗；避免：科普口號。
- **基督教與藝術**：圖像如何表達信仰、權力與歷史？ 選法：美術史、神學與原作；避免：只有漂亮圖片。
- **公共世界的基督徒**：信仰如何回應文化與公共責任？ 選法：不同論證與其盲點；避免：政治同溫層。

### 8. 華人原創與文學｜中文原創主張
- **用中文思考上帝**：有哪些華人原創思想真正不可忽略？ 選法：中文神學原創性與文獻影響；避免：只有英譯中著作。
- **文學中的福音**：小說、詩歌如何打開信仰想像？ 選法：文學品質與信仰張力；避免：把文學當宣傳。
- **普通人的教會史**：書信、日記與口述如何保存華人信仰？ 選法：第一手記錄與考證；避免：只有名人故事。

這是**編輯方法庫**，不是24份已完成推薦，更不要求湊齊書籍數量。每個企劃可以有不同形式：署名推薦、考據書單、慢讀方案、經典編評、彼此衝突的雙書對讀、閱讀順序導覽或華人原創研究。

## 四、出版前六關

1. **立意**：具體的讀者問題、編輯主張、讀者與非目標讀者、閱讀形式；只有「基督教好書100本」不算主張。
2. **證據**：具名薦者須有直接薦書證據；經典價值需有文本、歷史與評論；學術書要見原典和研究傳統。書店及出版社書目只證實書存在，不能證實品質。
3. **比較**：逐本記錄作品核心論證、獨特貢獻、最適讀者、相近替代品、落選作品與理由；沒有比較不是編輯。
4. **覆核**：主題專業判斷與中文讀者適用性至少兩種審讀視角；不具備人員時標明「待獨立覆核」，不可假裝有評審會。
5. **版本**：作品評議成立後，才辨識中文譯名、原著／譯著、Edition、出版者與授權。是否免費不反向影響入選價值。
6. **刊發**：署名薦書與本館評語分開；真正取得合法免費書源才標為「免費閱讀」；來源失效不自動取消作品價值，僅更新讀者入口。

## 五、各種證據能支持什麼？

| 證據 | 可支持 | 不可推論 |
|---|---|---|
| 原著、史料、逐章筆記 | 文本真實論點、原始敘述 | 必然是好書 |
| 牧者本人署名薦書或可核原記錄 | 誰在什麼場合薦了哪本 | 本館也推薦、薦者說過未見評論 |
| 多評委的獎項、獨立書評 | 已有某種判斷與評選標準 | 中文譯本已出版或無爭議 |
| 課程書目及出版社頁 | 教學選用、書誌資料 | 一定具經典性或獨立認可 |
| 網站免費可讀 | 有實際閱讀通路 | 內容品質好、可轉載 |

**出版風險**：必須保留宗派與神學脈絡；一份書單不代表全體基督教共同評價；對華人原創、女性書寫、地方教會史料和不同傳統留有深入閱讀的空間。不用同溫層同意度、下載量、名人照片或熱門程度代替評議。

## 六、三個方法驗證試稿（均尚未經完整審讀）

### 1. 內在生活：從自我省察到神同在
**問：**內在生命是外在活動的替代品，還是回應神的另一種生活尺度？

**編輯論點：**比較自我省察、日常神同在、群體操練三種靈性語言；不把不同傳統抹平。

**讀者：**願意慢讀、反思的中文基督徒；**不適用：**要求立即有效的心理或醫療處方。

**比較方式：**跨時代的附註對讀。**取捨：**更深刻的經驗文學不一定適合剛接觸靈修的讀者。**拒選例子：**只有即時見效口號的靈修捷徑書。

- **《懺悔錄》**（奧古斯丁）：從渴望與悔改進入自我省察；注意：重視文本全貌，避免只摘名言
- **《與神同在》**（勞倫斯弟兄）：日常生活中的禱告觀；注意：中文譯名和底本有待逐本辨識
- **《屬靈操練禮讚》**（理查・傅士德）：讓個人靈修與共同體操練互相映照；注意：處理傳統及實踐方法的差異

**研究證據 ID：**renovare、foster。**目前只確認方向和薦書證據，未完成中文版次及全文審讀。**

### 2. 教會歷史：從原始記錄到華人現場
**問：**歷史書如何區分誰說了什麼、憑何知道，以及誰被遺忘？

**編輯論點：**史料、歷史敘事與地方觀點應分層閱讀，不做偉人名單。

**讀者：**有基本信仰背景的中文教會讀者；**不適用：**只想背誦年代的人物速覽。

**比較方式：**史料與史家雙聲部導讀。**取捨：**一手記錄有價值，但它的敘述立場也需要校正。**拒選例子：**沒有原始證據的十大教會英雄榜。

- **《教會史》**（優西比烏）：接觸早期教會自我敘述；注意：不可視為完全中立史書
- **《歷史的軌跡：二千年教會史》**（祁伯爾）：以後期概覽辨識年代脈絡；注意：認識其史學與宗派立場
- **《福爾摩沙記事》**（馬偕）：把台灣歷史場景納入閱讀；注意：需要與本地第一手記錄對讀

**研究證據 ID：**ala、cstt。**目前只確認方向和薦書證據，未完成中文版次及全文審讀。**

### 3. 牧者的書房：核實真正被推薦過的書
**問：**推薦者是誰，在什麼場合薦書，黎明書局是否獨立同意其推薦？

**編輯論點：**具名推薦紀錄只是證據，不等於黎明書局自動認可。

**讀者：**教會閱讀小組與牧養同工；**不適用：**名牧背書廣告。

**比較方式：**有來源的薦書證據卡＋獨立評議。**取捨：**具名聲譽不能代替本館閱讀，且推薦者可能有特定宗派處境。**拒選例子：**把講道引用當成推薦、把書店文案當成牧者說法。

- **《40 個創意祈禱》（一書兩冊）**（克萊爾・丹尼爾）：2026香港聖公會資料列為陳謳明大主教的薦書；注意：推薦事實已見書單，作品品質尚未獨立審讀；推薦者：陳謳明（原始紀錄 hk）
- **《為何上帝容許苦難？》**（羅賓・基爾）：2026香港聖公會資料列為郭志丕主教的薦書；注意：不可虛構原薦者的理由；推薦者：郭志丕（原始紀錄 hk）
- **《在失序中抱緊上帝：千禧世代的信仰心法》**（潘正行）：2026香港聖公會資料列為謝子和主教的薦書；注意：是否適合本館讀者另行獨立評審；推薦者：謝子和（原始紀錄 hk）

## 七、外部編輯制度先例

- **tgc**：[福音聯盟2025圖書獎](https://tc.tgcchinese.org/article/tgc-book-awards-2025) — 11類別、評選程序與神學標準。
- **hk**：[香港聖公會2026十本好書閱讀運動](https://www.stjohnscathedral.org.hk/files/site/4/pew_bulletin/20260426_Chinese%20Pew%20Sheet_260424170744.pdf) — 具名牧者、主教與書目的直接證據。
- **cstt**：[基督教研究智庫睿智書單](https://cstt.tw/smartbooks/) — 經典中文譯本與華人相關閱讀材料。

借鏡的是選書機制，不把外國獎項、宗派標準或出版社銷售導向自動變成本館價值判斷。ALA 提供一般館藏管理與多元觀點的參考，黎明書局保持自身福音與中文文化定位。

## 八、機器與人工的責任界線

機器可檢查：是否有選題問題、比較性主張、排除規則、具名推薦來源、作品身份及沒有偷偷把免費網址當成品質證據。

機器不能判斷：真正的神學深度、文學品質、史料批評、作品是否具永久價值。這些必須有可追溯的實際閱讀及編輯簽核。

`scripts/check_dawn_editorial_lists.mjs` 是此計劃的結構驗收，不是自動推薦演算法。原有網站、Design OS、P2 及三個欄目沒有改動。
