# 黎明書局｜中文精品選書母單 V1

> **狀態：編輯選題初稿（40 目標書目／10 個閱讀問題），不是已可閱讀的館藏。**  
> 建立日期：2026-11-22；僅編輯文件，不得自動發佈到網站。

## 1｜為什麼先有書單

中文讀者是第一優先。原有英文資料量大，但以免費下載能力主導搜尋會導致無目的地入庫。改為 **編輯問題 → 中文精品目標書目 → 版本／版權／免費閱讀通路核驗 → 館藏編輯**。不以網站、出版社、熱度、下載量決定是否值得讀。

## 2｜與三晨星、光譜、策展集的關係

本文件是 **進入三個編輯欄目前的內部編輯採購／選書母單**，不是增設第四個面向讀者的新欄目：

- **母單**：先回答「中文世界有哪些作品值得我們主動尋找、維護和核驗？」；即使尚未有合法免費版本，也可選入。
- **三晨星**：完成核驗後，哪些已可用資源值得此時特別推薦；有具體出版時機與讀者情境。
- **光譜**：書與經文、思想、歷史、人物、文化、不同觀點有何關聯，不等於「主題書架」。
- **策展集**：把書、聖經、史料、圖像、課程、工具編成實際可行走的學習路線，不是此母單的同義詞。

**來源政策：** 先查完全免費、合法、無須帳戶的原出版方／公共資源；其次才用免費註冊或免費訂閱的外部平台；若僅見付費版保留目標書目而不冒稱免費；不得擅自鏡像 PDF、掃描或封面。my-elibrary.net 是補充候選來源，非主力或宣傳入口。

## 4｜查找和入館雙重關卡

**先選書，不先搜尋 PDF。** 對每部依次：① canonical Work／作者／語言／原名；② 中文譯名與不同 Edition／出版社／年；③ 查主站 canonical 全量索引防重；④ 依優先級探查合法公開全文（出版社、公共圖書館、授權電子書，最後才是免費註冊平台）；⑤ 獨立驗證讀者可直接讀多少、是否須帳號、地域、下載權限；⑥ 封面與版本一致、授權符合展示方式；⑦ 編輯閱讀並撰寫獨立推薦文字；⑧ 再交由三晨星／光譜／策展集消化，不讓工程術語進入讀者界面。

狀態嚴格分開：

- `editorial-target`：值得找，**不代表有電子版**。
- `edition-verified`：核實中文版本與出版資料，**不代表免費**。
- `free-access-verified`：有合法免費可訪問正文及指定閱讀範圍，標示實際限制；**不等於可轉存本站**。
- `editorially-reviewed`：已實際審讀作品，確認內容、難度及用途。
- `library-admitted`：符合 canonical Work/Edition/Source/Cover/Rights、呈現和讀者操作驗收，才可正式公開。

**風險提示：** 學術課程用書、書店精選與出版社本版展示並不等於獨立品質獎項；它們是篩選證據，最終評價由黎明書局自己的編輯審查決定。譯名、套書分冊、作者／編者欄及出版版次均待逐冊核定，不能以本表當作已核定的書目紀錄。香港與台灣的神學傳統、宗派立場及學術方法不同；不應以無爭議或單一神學路線作唯一入選標準。
