## 1. 十字架的影子 / The Shadow of the Cross

Status: **FULL RECORD / 完全記錄 — CONTENT IDEA / CENTRAL THEME**

### 原始記錄

> 有個提法叫做「十字架的影子」，說白了舊約就是耶穌基督的預表，十字架的影子就是指的預表。我們這個從創世紀到啟示錄，不僅僅是讓聖經動起來，我們的唯一主題就是主基督，那麼這個十字架的影子就是那道金色的刻線，黎明晨星照耀的第一抹光，所以我們要突出的，就是這光這影子這預表這十字架，這樣整部影片，就有了真正要表達的，真正要彰顯的，真正要說的話。

### 製片約束（由原始記錄導出，非原始文案）

- 影片從創世紀到啟示錄的中心不是「讓聖經動起來」這個技術效果；整部作品的唯一主題是主基督。
- 「十字架的影子」是整部影片理解舊約預表與基督中心敘事的一個核心電影語言。
- 已確立的金色刻線不只是視覺連接物；在這一內容構想中，它承載「光／影子／預表／十字架」的連續敘事。
- 「黎明晨星照耀的第一抹光」與創世記起初出現的金色刻線形成作品最早的基督中心視覺提示；它應一路參與從創世紀到啟示錄的彰顯，而不是成為孤立的特效。
- 後續腳本、Camera Spine、Doré anchor、經文浮現、預表與應驗的安排，都要接受同一個內容問題：它是否使整部影片真正指向、彰顯並述說主基督與十字架。

### 與既有三重生命原則的關係（製片註記）

既有的「光是活的／恩典是活的／神的話是活的」不被取消。這一記錄進一步給出整部影片的中心指向：光、恩典、經文以及舊約預表不是彼此分離的視覺題材，而要在整部聖經長卷中共同指向主基督。最終腳本化時，必須避免把預表處理成機械的一一對照圖解；應讓「十字架的影子」成為貫穿敘事、影像與 Camera 發現過程的電影語言。

## 2. 製片記錄本身就是出版內容 / Production Becomes Publication

Status: **FULL RECORD / 完全記錄 — PUBLISHING REQUIREMENT**

### 原始記錄

> 腳本，經文，文配圖，加上鏡頭軌跡，時空隧道算法等等一些製片過程，要出雜誌的，出雜誌之前，是一期journal。

### 出版鏈（製片約束）

《十字架的影子》的製片過程不得只留下最終影片。從現在開始，具有內容、視覺、神學或工程價值的中間成果都同時視為可出版素材。正式出版順序固定為：

**Production Record → Journal Issue → Magazine**

Journal 是第一個公開編輯版本：在電影與技術仍然活著、仍在形成時，先保存一次完整的思想與製片現場。Magazine 是後續經重新編輯、設計與組織後的成熟出版物；不得用 Magazine 反過來抹掉 Journal 中保留下來的形成過程。

### 必須保存的出版素材

- **腳本 / Script**：從 `בְּרֵאשִׁית / Bereshit` 開始的場景、故事、節奏、十字架影子的顯明次序，以及每一場最終定稿。
- **經文 / Scripture**：中文經文、KJV、必要的希伯來文／希臘文原文，以及經文之間的預表、呼應、應驗關係。
- **文案 / Copy**：自寫文案全部保留中英文母稿；其功能是最後、小而克制地點出「十字架的影子」，不得取代經文成為主要敘事。
- **文配圖 / Text × Image**：經文、文案與 Doré 原作的選擇理由、構圖關係、金線、光、文字顯影及最終畫面。
- **鏡頭軌跡 / Camera Spine**：每一場鏡頭為何停留、尋找、等待、靠近、進入、看見與繼續前行；保留軌跡圖、時間、方向、速度、16:9 frame planes 與視線邏輯。
- **時空隧道 / Camera Tunnel**：保留 16:9 時間平面沿 Camera Spine 形成蜿蜒攝影隧道的推導、實驗、失敗與最終方法；核心原則為以 2D Moving Painting 建立 tunnel skeleton，只把 2D 無法解釋的 residual 立體化。
- **製片算法與工程 / Production Algorithms & Engineering**：Simple World First、Complexity as Residual、Camera-conditioned Moving Painting、2D/3D activation boundary、visibility/compute forecast、repair、hidden surface、版本迭代及實際驗收數據。尚未被實證為算法的構想不得在出版物中虛稱新算法；應保留它如何從製片實踐中形成的證據。
- **動畫語法 / Motion & Scripture Performance**：經文本身作為動畫項目；字、光、線、原文、停頓、顯影、局部自然運動與 Typography 如何隨時間表達意義。
- **版本演進 / Iteration Record**：V1 到後續版本不是推翻重做，而是同一作品逐層顯影；保存每次增加的「必要差異」以及沒有啟動昂貴能力的原因。

### Journal 的定位

這一期 Journal 不是電影廣告或完成後的幕後花絮，而是《十字架的影子》的**第一份製片出版物**。它應讓讀者同時看到：經文如何成為腳本、Doré 原作如何成為世界、鏡頭如何成為追逐主腳蹤的眼睛、文字如何指出影子，以及一條主要由 2D 圖片構成的 16:9 時空隧道如何逐步形成。

因此，從第一場 `בְּרֵאשִׁית` 開始，每個正式 Script Node 都必須天然具有兩種輸出：

**Film Output + Editorial Record**

製片資料不是影片完成後再補寫的出版材料；**製片本身就是 Journal 與未來 Magazine 的採集過程。**
