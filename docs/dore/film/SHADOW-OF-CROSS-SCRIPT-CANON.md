# 十字架的影子 / THE SHADOW OF THE CROSS — Script Canon

Status: **SCRIPT CANON**

## 最高主題

**主題是主耶穌基督。**

《十字架的影子》是觀看整部聖經的方法。時間長河承載祂的故事；Doré 原作提供世界；鏡頭帶領眼睛尋找、等待、辨認並跟隨主的腳蹤。

**鏡頭，就是追逐主腳蹤的眼睛。**

不是只選取明顯的「十字架預表」而捨棄其他歷史。從創世記到啟示錄的完整聖經時間長河都要存在；十字架的影子在其中被逐步看見與顯明。

## 腳本方法

盡量讓經文自己做文案、讓經文自己說故事。自寫文案只在必要時出現，作用不是替經文講解，而是在最後輕輕點明：這裡是十字架的影子。

每個 Script Node 可記錄：

**Scripture → Human Need / Divine Action → Shadow → Unresolved Tension → Christ Fulfilment → Scripture Echo → Final Short Copy**

舊約不得因觀眾知道新約答案，就假裝當時人物已經看見全部答案。讓問題在歷史中保留，直到基督使它顯明。

## 第一場必須從起初開始

整部作品不從抽象的預表清單開始，而從聖經時間真正開始：

**בְּרֵאשִׁית / BERESHIT / 起初**

`בְּרֵאשִׁית` 本身就是第一場 Scripture Cinema。希伯來文字及其字母／組合的象徵性神學閱讀，可透過光、Golden Line、Typography、停頓與逐次顯影，使「子、約、手、頭、荊棘、王冠、樹」等關係被眼睛逐步發現，最後帶出片名：

**十字架的影子**

**THE SHADOW OF THE CROSS**

這種字母／組合閱讀在作品中應明確作為神學／象徵性閱讀，不虛稱為歷史語源學證明。

片名顯影後，重新回到完整的 `בְּרֵאשִׁית`，再進入創世記 1:1。

第一場的自寫點題文案固定為：

**起初，就是主基督。**

英文保留正式雙語母稿；最終英文措辭在英文版編輯階段可作語言級校訂，但不得改變中文核心意思。

## 經文與自寫文案的層級

**神的話最大、最久、最先；我們的話最少、較小、最後。**

自寫文案全部中英文成對保存。未來可從同一母稿輸出中文版與英文版，而不是完成後再臨時翻譯。

資料層至少區分：

- `scripture.zh`
- `scripture.kjv`
- `copy.zh`
- `copy.en`

英文經文固定使用 **KJV**。

主要標題可採中文較小、英文較大的品牌層級；經文閱讀則以中文為主，KJV 可作第二閱讀層與視覺／空間文字。自寫點題文案不得在尺度上壓過經文。

16:9 母版的第一版比例基準：中文經文約 `0.050–0.065H`；KJV 約 `0.032–0.045H`；出處約 `0.018–0.022H`；自寫中文文案約 `0.026–0.032H`；自寫英文約 `0.018–0.024H`。比例可因場景校準，但「經文 > 自寫文案」是硬規則。

## Gaze / Camera Grammar

Camera State 的基礎語法：

**SEEK → WAIT → NOTICE → FOLLOW → APPROACH → BEHOLD → CONTINUE**

在最終完成中可進入：

**DWELL**

「追逐」不代表攝影機永遠向前。等待、靜止、凝視都是真實鏡頭狀態。重要時刻甚至應該動得更少。

十字架可以是 BEHOLD：Camera Spine 停下、長卷近乎停下、Golden Line 匯聚、經文顯明，不依靠 3D 奇觀製造高潮。復活之後仍然繼續跟隨；BEHOLD 不是 END。

## 文字本身就是動畫

經文不是影片上的字幕層，而可以是完整動畫項目。意義隨時間被揭示，本身就是動畫。

同一句經文可依 Performance Intent 採取不同表演：宣告、呼喊、等待、應許、回答、顯明、頌讚。文字可整句出現、逐詞顯影、從刻線／牆面浮出、由光找到、沿 Golden Line 建立關係；但所有動效必須服從經文意義。

共享時間線：

**Scripture Node → Gaze → Camera → Text → Light → Line → Natural Motion → Silence**

## 約伯節點範例

約伯記 9:33 的「在我們中間沒有聽訟的人，可以向我們兩造按手」表達人不能自我稱義、渴望一位居間者的深層需要。這個問題可以在歷史中保持未解，後由提摩太前書 2:5「在神和人中間，只有一位中保，乃是降世為人的基督耶穌」回答，並與約翰福音 5:22、希伯來書 4:16 等形成回聲。

約伯場次不必立即把新約答案貼在畫面上。讓眼睛先 SEEK / WAIT，讓歷史保留渴望；後來在基督裡才 BEHOLD。
