# 十字架的影子 — Shadow Map Editorial Canon

Status: **RESEARCH / EDITORIAL / FILM CANON**

## 研究目標

在正式選鏡頭之前，先盡可能完整地找出舊約中指向主耶穌基督、祂的位格、工作、受苦、代贖、中保、祭司、君王、救贖、復活、生命、神與人同住等內容的經文、人物、制度、事件、器物、祭禮、意象與象徵性閱讀。

這份工作不是為了直接決定影片鏡頭，而是先建立 **完整 Shadow Map / 十字架影子總表**。

之後再與 Doré 原作逐項對比，選出最關鍵、最有視覺力量、最能承擔整部影片節奏的節點進入正式拍攝。

## 完整優先於取捨

此階段以 **recall / 完整性** 為優先，不因某一個影子可能不進影片就省略它。

研究時必須盡量跨越不同來源與傳統：

- 新約明確建立的 typology / fulfilment
- 舊約彌賽亞預言與應許
- 聖約與救贖歷史中的人物、事件、制度、祭物、聖所、職分、節期、器物
- 教會歷史與成熟聖經神學長期辨認出的 Christological patterns
- 早期教父、宗教改革、福音派／改革宗／福音主義等對基督預表的主要整理
- Hebrew / Greek lexical, textual, intertextual resources
- 象徵性／字母性神學閱讀（必須與歷史語源學、語法學分級，不得混淆）

## 證據分級

不要把所有「影子」說成同一種證據強度。至少區分：

1. **A — NT Explicit**：新約明確指出或直接建立對應。
2. **B — Messianic / Promise**：舊約文本本身帶有明確彌賽亞／救贖應許，新約有應驗或強回聲。
3. **C — Canonical Typology**：人物、事件、祭禮、制度、職分等在整本聖經正典結構中形成穩定基督論對應。
4. **D — Historical Theological Reading**：教會歷史中長期、廣泛使用的基督論閱讀，但不是新約直接標註。
5. **E — Symbolic / Devotional Reading**：如字母、形狀、象徵性拆解等，可作神學藝術閱讀，但不得宣稱為歷史語源學或文本原義證明。

此分級不是用來刪除 E，而是讓讀者知道每一種閱讀「以什麼方式成立」。

## 與 Doré 原作的第二階段對比

Shadow Map 完成後，才開始 **Shadow × Doré Crosswalk**。

選片不只看神學重要性，也要看：

`Theological Weight × Narrative Necessity × Doré Availability × Visual Power × Camera Potential × Rhythm Position`

因此影片只會拍攝 Shadow Map 中最關鍵的一部分。

## Magazine：完整研究本身就是正式稿件

因為 Vol.01 是《十字架的影子》創刊特刊，**完整 Shadow Map 不只是內部研究資料，而是雜誌正文的一部分。**

它應以真正的稿件形式編輯，而不是附錄式資料 dump。可按聖經時間、類型、證據層級、人物／制度／祭禮／預言等形成不同 editorial sequences。

雜誌因此保留影片無法全部容納的神學視野：

**Film = selected critical shadows**

**Magazine = the fuller field of shadows**

## 未被影片採用的影子：End Credit Scripture Roll

凡已進 Shadow Map、但最後未被影片主體採用的影子，不視為被淘汰。

它們在影片最後以類似人員字幕的方式滾動播出，形成一段 **End Credit Scripture Roll / 影子名錄**。

這不是傳統 credits，而是作品最後一次回到 Scripture：

- 經文位置
- 影子名稱／極短描述
- 必要時 NT echo

以緩慢、莊嚴、可閱讀的方式連續出現。

它的意義是：

**影片只能跟隨其中一些腳蹤，但整本聖經中仍有更多影子繼續指向基督。**

因此沒有進入主片的材料仍然在作品內部被尊重、被命名、被留下。

## 出版／電影關係

關鍵選取 → 正片

未採用但成立的影子 → End Credit Scripture Roll

這三者共用同一份 Shadow Map source of truth，不建立三套互相漂移的資料。
