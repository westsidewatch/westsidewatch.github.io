# Doré Film Records Index

Status: canonical record index

This is the authoritative entrypoint for records under `docs/dore/film/`. It distinguishes active production constraints from bounded experiment evidence. A file being present here is never, by itself, proof that a film, render, provider path, or visual acceptance is complete.

## Operational production records

- `DORÉ-FILM-PRODUCTION-HANDBOOK.md` — active production handbook and content constraint record.
- `DORÉ-ANCHORED-WORLD-ROUTE-01.md` — selected first real anchored-world route; implementation progress remains distinct from research confidence.
- `DORÉ-ANCHORED-WORLD-ENGINEERING-TRANSLATION.md` — engineering translation supporting Route 01.
- `aw011-anchor-corridor-v1.json` and `tools/*` — operational route/tooling artifacts. Tool presence is not visual acceptance.

## Experimental evidence

- `EXPERIMENTAL-FILM-01.md` — experiment specification; its own acceptance requires judging the rendered film, not CI alone.
- `CAMERA-SPINE-EXPERIMENT-01-ACCEPTANCE.md` — objective engineering PASS while director-level visual review remains explicitly required.
- `CANVAS-PLACEMENT-EXPERIMENT-01-ACCEPTANCE.md` — bounded placement experiment evidence.
- `camera-spine-experiment-01.*` and `canvas-placement-experiment-01.json` — experiment artifacts, not canonical architecture.

## Authority boundary

`operational` means actively used by the film engineering line. `evidence` means a bounded result, experiment, acceptance, or artifact. Neither means the whole Doré Film system is complete.

Cross-system identity and current truth remain governed by System Atlas and GitHub canonical records.
