# Westside Watch Magazine Vol.01 — Production Note Canon

Status: **EDITORIAL / PRODUCTION CANON**

## 工程目標

工程正式以 **Westside Watch Magazine Vol.01《十字架的影子 / THE SHADOW OF THE CROSS》創刊特刊** 為總成果；但核心製片工作仍是拍攝從創世記到啟示錄的長卷。

這不是從「電影工程」轉去「雜誌工程」。兩者是同一個工程：

**Scripture → Script → Doré Long Scroll → Camera Spine → 16:9 Camera Tunnel → Film → Journal → Magazine Vol.01**

## 整部特刊就是製片筆記

Vol.01 不做「電影完成後的介紹刊」。整本特刊的內容就是電影如何被看見、被理解、被設計、被試驗、被拍攝、被修正、被完成的製片筆記。

因此，**記錄不是附屬工作，而是正式製片工序。**

任何具有神學、腳本、視覺、鏡頭、算法、工程、失敗或判斷價值的節點，在發生時就應留下 Editorial Record，不等待影片完成後回憶補寫。

每一個正式 Script Node 必須同時產生：

**Film Output + Production Note + Editorial Material**

## 必須持續採集

1. 經文：中文、KJV、必要的希伯來文／希臘文，以及經文互文與應驗。
2. 腳本：故事、節奏、場次、問題與回答、十字架影子的顯明位置。
3. 雙語自寫文案：短、小、最後出現，只負責點題；經文始終為主。
4. 文配圖：Doré 原作選擇、構圖、裁切、光、Golden Line、Typography。
5. Camera Spine：SEEK / WAIT / NOTICE / FOLLOW / APPROACH / BEHOLD / CONTINUE / DWELL 等視線狀態與實際軌跡。
6. Moving Painting：原作如何只靠 translate / crop / scale / time 先完成最簡單的電影運動。
7. 16:9 Camera Tunnel：每一時間平面、相鄰平面的變化、2D tunnel skeleton 與必要的 sparse residual volumes。
8. Compute Map：什麼完全不需要生成；什麼只需 2D；什麼才需要 depth、parallax、hidden surface、repair 或 selective 3D。
9. Style as Compute：Doré 刻線、黑白、靜止人物、光暗、慢長鏡頭如何直接減少計算與生成需求。
10. Scripture / Motion Grammar：字、光、線、原文、停頓、顯影、自然場運動如何成為動畫。
11. 工程版本與失敗：V1 之後每一個必要差異、測試、視覺失敗、修正與保留理由。
12. 算法形成：不預先虛稱新算法；保留 `camera state → 2D sufficiency → illusion failure → minimum added capability → fidelity / compute result`，讓真正的方法從製片證據中形成。

## Editorial Principle

**整部特刊，就是製片筆記。**

它可以保留草圖、軌跡、frame planes、測試畫面、Script Node、經文關係、錯誤版本、比較、演算與最終畫面。不要把形成過程清洗成一份光滑的「成果介紹」。獨立雜誌的價值就在於讓思想、信仰、影像與工程形成作品本身。

Journal 是正在發生的製片記錄；Vol.01 是這些記錄經過真正編輯與鏡頭式排版後形成的正式創刊特刊。
