# Westside Watch Magazine Vol.01 — Cinematic Editorial System

Status: **EDITORIAL CANON / 特刊排版原則**

## 刊序

**Vol.00**：《守望，一座光明的城》——零號刊／創刊前號。

**Vol.01 正式創刊號**：《十字架的影子 / THE SHADOW OF THE CROSS》——電影化特刊。

Vol.01 的形成鏈：

**Production Record → Journal → Westside Watch Magazine Vol.01**

## 原始構想

> 這一刊是特刊，連排版都要用鏡頭語言排版。

> 這是做獨立雜誌的感覺。

## 核心原則

Vol.01 不把電影內容裝進普通 Magazine 模板，而把 **Camera Spine 壓進紙張**。

**Camera Spine → Page Spine**

電影中的時間、停留、推進、平移、切換、凝視與顯影，在紙面上轉化為翻頁、跨頁、裁切、尺度、留白、連續畫面與文字出現次序。

讀者的翻頁本身就是攝影機運動。

電影：

**Camera Spine → F0 → F1 → F2 → F3**

特刊：

**Page Spine → Spread0 → Spread1 → Spread2 → Spread3**

兩者應盡可能共用同一套 Script Node 與 shot metadata，而不是電影完成後重新做一套互不相關的排版。

## 紙上鏡頭語法

- 跨頁可作為 16:9 Frame 的紙面變體。
- 翻頁 = Cut / 時間前進。
- 連續跨頁 = Tracking Shot。
- 大量留白 = Hold / Stillness。
- 逐頁局部放大 = Push-in。
- 連續改變裁切位置 = Pan。
- 黑頁／白頁 = Transition / Silence。
- 經文跨頁逐步顯影 = Scripture Animation 的紙面時間版本。
- Typography 不只是排版；字級、位置、停留、消失與重現共同構成鏡頭節奏。

## 開篇

卷首之前設一個獨立 opening page，只放：

**「仰望為我們信心創始成終的耶穌。」——希伯來書 12:2**

不加解釋，不加自寫文案，以大量留白讓經文先說話。這一頁是整本特刊的 **opening shot**。

翻頁後才進入 `בְּרֵאשִׁית / Bereshit`。

## Bereshit / Title Reveal

`בְּרֵאשִׁית` 的電影片頭與 Magazine title reveal 同源：希伯來文字與字母／組合關係逐步被光發現；中文承擔理解，英文參與視覺構圖；金線連接逐步顯出的意象。最終才顯出：

**十字架的影子**

**THE SHADOW OF THE CROSS**

片名不是普通封面標題，而是由閱讀／觀看過程顯影出來。

## 經文與文案層級

經文為主。我們自己的雙語文案較小、較少、最後出現，只負責點出這一段「十字架的影子」。

**Scripture tells the story. Our words reveal the shadow. Typography becomes cinema.**

## 製片與出版同源

每個正式 Script Node 天然產生兩種輸出：

**Film Output + Editorial Record**

電影是流動的《十字架的影子》；Magazine 是可以翻閱的《十字架的影子》；Journal 保存它如何被看見、如何被做出來。

因此，拍攝長卷與製作西望創刊特刊不是兩個工程。每完成一個經文節點，同時保存經文、雙語文案、Doré 原作、文配圖、Camera Spine、動畫、16:9 Camera Tunnel、製片方法與工程發現。

**攝影機走過時間，讀者用手重新走一遍。**
