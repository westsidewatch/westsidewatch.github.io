# Doré browser screenshot gate v1

Input: local preview.html generated by build_dore_visual_preview.py.
Output: screenshots at 320, 375, 768 and 1440 CSS pixels plus screenshots-manifest.json.

Command:

    python3 scripts/capture_dore_editorial_screenshots.py --preview local/dore-editorial-preview/preview.html --out local/dore-editorial-screenshots

Requirements: Python Playwright and an installed Chromium browser executable. No installation or download is performed by the script. Missing dependencies or a missing image fail instead of being reported as successful.

Each screenshot captures the browser-rendered local image and live text, waits for fonts, and records image decode and title visibility. Screenshot existence is not proof of editorial quality. Human review must still check portrait identity, crop, negative space, print texture, color accuracy and legibility. Publication remains blocked.

The preview is a standalone approximation, not the production Hugo template. The next adapter should capture production template previews rather than assume parity.
