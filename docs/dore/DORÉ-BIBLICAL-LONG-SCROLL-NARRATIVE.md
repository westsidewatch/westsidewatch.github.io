# DORÉ Biblical Long Scroll — Narrative Constitution

> Status: CANONICAL NARRATIVE SOURCE  
> Project: DORÉ Original Works / Biblical Dynamic Long Scroll  
> Related baseline: GitHub Issue #583  
> Date recorded: 2026-09-10

## 這不是作品集

這部作品不是把 241 幅 Gustave Doré 原作橫向或縱向連續移動，做成一個「會動的 Doré 作品集」。

它要從《創世記》一直走到《啟示錄》，讓整部聖經的世界在 Doré 的黑白原作中逐漸活起來。

241 幅 Doré 原作不是 241 個獨立頁面，也不是 241 個互相重置的動畫 scene。它們是整條連續聖經世界中的 canonical anchors——原作錨點。原作提供那些被 Doré 凝固下來的聖經時刻；長卷則讓這些時刻重新獲得之前、當下與之後，並讓不同時代、不同書卷、不同插圖之間形成一個連續的世界。

整卷不是「一幅畫動完，再換下一幅」。它必須讓觀看者感到自己一直沒有離開這一卷，只是沿著聖經歷史從一個時代進入另一個時代。

---

## 第一個動起來的是：光

**第一個動起來的是光，因為光就是神，是神的榮耀。這部長卷要讓人看見神的榮耀如何從《創世記》一直到新天新地。**

一切從《創世記》的「要有光」開始。

在此之前，Doré 的世界是黑白的、靜止的。

第一個真正發生的運動，不是人物，不是鏡頭，不是水，不是雲，也不是頁面 transition，而是光。

這個光首先以**金色的刻線**出現。

它不是把 Doré 原作染成金色，也不是在黑白版畫上覆蓋一層現代 glow、gradient 或粒子特效。Doré 的世界仍然保持版畫的黑白。金色首先服從 Doré 自己的刻線語言：線被刻出、延伸、聚集、分開、穿過、被遮擋、重新出現。

光是第一個活起來的動效。

更重要的是：**它一旦在「要有光」中活起來，就不能在下一幅插圖重新歸零。**

它不是每頁各自播放一次的金色動畫。

它從創世開始就進入整卷的生命，從開始一直活到結尾。

它可以是一根線，也可以成為很多線；可以放射、垂落、流動、升騰、穿透、分叉、匯聚、隱沒。它可以進入水、雲、火、天空、天梯、星、翅膀和不同的 Doré 構圖。它可以離開一幅插圖，穿過兩幅插圖之間的時間與空間，再進入另一幅插圖。

它是穿插不同插圖之間的聯繫紐帶，也是穿越不同書卷、不同時代的連續視覺生命。

創造之光、雅各的天梯、雲柱火柱、會幕與聖殿的榮耀、先知異象、伯利恆的星、耶穌受洗時的鴿子與從天而來的光、約旦河的水、復活清晨，以及最後新天新地，都可以讓這一道從創世開始的光不斷被觀看者重新認出。

這裡所說的「像聖靈一樣」，首先描述的是它在整卷中的生命狀態：它不是頁面效果，而是一個從創世到終末持續存在、持續運行、持續工作的存在。

但視覺表達不需要粗暴地建立「每一道金光 = 聖靈」的圖例。整卷要表達的是神的榮耀如何貫穿聖經歷史。

---

## 光不是唯一可以動的東西

不能因為光是第一個動起來的，就禁止其他事物動起來。

**光是第一個動效，不是唯一的動效。**

人物可以動，動物可以動，水可以流，雲可以走，天使的翅膀可以展開，山川與空間可以參與轉場；在敘事需要時，人物、自然、建築、空間甚至可以參與不同 Doré 原作之間的連續世界。

不能預先用一套形式主義的 motion rule，把聖經事件凍結在 Doré 原作所捕捉的某一個瞬間。

尤其不能用「保持原作靜止」之類的工程規則去否定神蹟。

**這是萬萬不能夠的。**

因為光照之後，會有生命。

動物會活起來。

人會得醫治。

瘸子會站起來。

風浪會止息。

紅海可以分開。

水可以流出。

死人可以復活。

凡經文本身記載發生的創造、醫治、神蹟、復活與更新，都必須保留真正「發生起來」的動態可能。

Doré 原作是視覺與歷史錨點，而不是囚禁聖經事件的畫框。

工程規則不得否定經文事件。

我們可以忠於 Doré 的人物、構圖、氣質與版畫世界，同時恢復這個被 Doré 凝固的聖經瞬間之前和之後所發生的事情。

邊界不是「不許動」。真正的邊界是：不憑空製造聖經沒有發生的神蹟，不為動畫效果篡改經文，不讓技術特效取代神蹟本身。

經文說發生了，就必須允許它發生。

---

## 第二個動起來的是：恩典

**第二個動起來的是恩典。光帶來生命，而生命，是活的。**

所以這部作品中的生命不能只是背景性的微動。

光臨到之後，受造世界開始回應。

這可以成為整卷非常深的一條運動秩序：

> **光臨到 → 恩典發生 → 生命回應。**

創造中的生命可以出現；飛鳥可以飛起；走獸可以活動；人可以行走。

到了救贖歷史中，恩典的運動不只表現在自然世界，也表現在人的恢復：病者得醫治、瞎眼者看見、癱子起來行走、枯乾的手伸開、死人復活。

因此，世界不是因為我們「需要更多動畫」才動起來。

**世界因為有生命而動起來。**

這是第二個核心原則。

---

## 第三個動起來的是：神的話語

**第三個動起來的是神的話語，因為神的話是活潑有功效的。**

> 「神的道是活潑的，是有功效的……」——希伯來書 4:12

但是這一層目前不能草率決定它的動畫形式。

因為整本聖經都是神的話。

所以「神的話如何動起來」不應被簡化成幾句經文字體飛入、逐字出現、kinetic typography，或者每到一節經文就播放一次文字效果。

如果整部聖經都是神的話，那麼「話是活的」很可能應該存在於整部作品更深的運行機制裡，而不是一個局部 UI 效果。

這一點目前**先記錄神學與敘事原則，不預設具體視覺答案**。

後續 Doré Exploration 必須單獨探索：如何讓觀看者真正感受到「神的話是活的」，同時避免把聖經降格為動畫字幕。

---

## 三重生命原則

目前整部動畫的文案與敘事核心，可以先收斂為三句：

> **光是活的——我們看見神的榮耀。**  
> **恩典是活的——我們看見生命被賜下、醫治、復起與更新。**  
> **神的話是活的——整部聖經如何作為活的話運行，仍要繼續探索。**

這三條高於金線、人物動畫、跨圖、鏡頭、scroll、transition、parallax、GSAP 或任何其他具體技術規則。

技術服務於這三件事，而不是反過來讓這三件事服從技術。

---

## 從黑白到全彩

整部長卷的大部分時間，Doré 世界保持黑白。

金色不是人物或景物的染色，而是光的刻線。

從《創世記》「要有光」開始，這道光在黑白世界中奔跑、穿行、連接、照射、隱藏、重新出現。它經過整部舊約，進入新約，經過基督的事工、神蹟、十字架、復活、教會與終末。

到了最後的新天新地，整部作品才第一次發生根本性的色彩轉變。

這不是突然切換到另一張彩色插圖。

是從創世記開始一直活著的光，終於照遍整個世界。

光所到之處，黑白世界第一次顯出真正的顏色。

水、樹、天空、城、受造世界逐漸從 Doré 的黑白世界中顯出色彩。

最終，新天新地成為整卷第一次、也是最重要的一幅**全彩世界**。

所以最後的全彩不是風格變化，也不是視覺獎勵。

它是整卷敘事的完成：

> **光 → 生命。**  
> **光 → 恩典。**  
> **光 → 醫治。**  
> **光 → 神蹟。**  
> **光 → 復活。**  
> **光 → 萬物更新。**

從「要有光」開始，到新天新地，觀看者最終看見的是：

> **神的榮耀如何穿過整部聖經，直到萬物都在光中。**

## 對工程的約束

這份文件首先是作品文案與敘事憲章，不是 motion implementation spec。

後續任何工程方案都必須接受以下檢查：

1. 是否仍然讓光成為第一個活起來的元素？
2. 光是否從創世開始保持整卷級別的持續生命，而不是每個 scene 重置？
3. 是否允許光所帶來的生命、恩典、醫治、神蹟和更新真正發生？
4. 是否有任何技術規則錯誤地禁止了經文明載的事件？如果有，技術規則必須退讓。
5. Doré 原作是否仍然是 canonical visual anchor，而不是被任意改寫？
6. 金色是否仍然主要作為「光的刻線」而不是對黑白世界的染色？
7. 是否保留「神的話如何活起來」作為尚待探索的核心問題，而不是過早降格為文字動畫？
8. 最終新天新地的全彩是否由整卷一直活著的光所完成，而不是一次普通的 palette transition？

如果一個動畫方案看起來漂亮，卻違反以上原則，就不屬於這部作品。
