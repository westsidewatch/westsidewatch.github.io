# Westside Design OS｜First Look 階段性備忘

> 狀態：第一階段「一靜」共用基礎已提交，尚待視覺及 CI 驗收。此備忘是工程進度與下一階段交接記錄，不代表七個 First Look 已完成或部署。

## 一靜、一動：全站唯一設計架構

- **一靜**：七個 First Look 共用同一個固定視覺畫框、邊界、比例規範與 Design OS 設計權威。包括字體、品牌色、刻線、光影、導航、響應式與無障礙規則。
- **一動**：畫框內的內容按版塊需求播放、滾動、滑動、切換或揭示。教會的「開門 → 門後有什麼 → 進門」是 **同一 OS 中的專屬互動模式**，不是獨立設計系統。
- **內容就是體驗**：能在 First Look 直接觀看、閱讀、探索或使用的內容，不設多餘的二次跳轉。
- **禁止擬物化**：雜誌不是一本被打開的實體雜誌，黎明書局不是一本被打開的實體書。數位編輯內容在同一舞台呈現，不強制翻頁動畫。
- **福音識別**：每個版塊保有經文長卷、固定主題經文與經譯本校對後才啟用的每日經文。教會永久核心《約翰福音》7:38；白晝咖啡館《馬太福音》6:34。經文只是共用識別層，**不是整個工程的主線**。

## 導航層級定案：First Look 即第一層的版塊展示首頁（2026-10-10）

**不是兩個重複首頁。** First Look 是第一層內直接體驗七個世界的窗口；版塊首頁是第二層完整的內容索引與導航中心。兩者共享同一世界的設計語言，但用途不同。

1. **第一層 First Look**：以「一靜」共用畫框承載「一動」的內容瀏覽、影片播放、滑動與閱讀。盡量不要求點擊；用戶應能先充分體驗內容。
2. **有目的的點擊**：點擊文章、影片、書籍、講道或工具時，**直接進入該專項內容**，不可先強迫訪客經過版塊首頁。
3. **專項閱讀 → 版塊首頁**：專項內容中的明確「返回版塊」導航，回到該版塊的完整首頁／索引；**版塊首頁 → 第一層**：再透過明確「返回第一層」導航回到全站 First Look。
4. **瀏覽器 Back 不應被劫持**：原生瀏覽器返回應遵循實際瀏覽歷史，從專項內容返回原先的 First Look 是正常行為；上述「專項 → 版塊 → 第一層」是**網站顯式層級導航**，不是強行插入瀏覽器歷史記錄。
5. **直接連結也必須成立**：從搜尋、分享連結或外部來源直接打開專項內容，仍能藉由「返回版塊」與「返回第一層」導航定位，不依賴上一頁是否存在。
6. **例外不變成第二套架構**：教會在第一層使用開門／揭示／進門的專屬互動；各世界的專項內容可有不同操作，但導航階層與 Design OS 權威一致。

### 層級返回的 UI 節制（補充定案）

- 此處的「返回」專指**網站自己的層級導航**，不是瀏覽器 Back。
- **層級關係必須存在，但不等於每個頁面必須顯示返回按鈕。** 優先由現有導航、品牌標識、版塊入口及必要時的層級導覽承擔；不堆疊多個返回控制。
- First Look 的沉浸展示應避免功能性返回按鈕干擾；深層專項閱讀也不預先固定返回控制的位置、數量或形式。
- 在全站最終資訊架構及各專項內容的深度確定之前，**暫不把「每個專項頁必有明確返回按鈕」作為硬性驗收條件**。只驗證可理解的層級歸屬及可到達的版塊／全站導航路徑。
- 待第二層與更深層內容完成後，再統一決定何處需要顯式返回，何處使用導航標識或自然路徑即可。

**工程驗收**：每個 First Look 中，沒有明確閱讀目的的滾動、滑動、切換及預覽不應造成頁面跳轉；只有有意識的進入動作才導向對應的專項 URL。專項與版塊之間、版塊與第一層之間須有可理解且可到達的導航路徑；不強制逐頁配置返回按鈕。

## One Look｜共用互動卡片導航契約（2026-10-10）

橄欖山的講員卡片是全站可重用的**動態內容選擇器**，不是只屬於講員頁的特殊導航。One Look 是 First Look 共用體驗語法的稱呼，**不另建第二套設計系統**。

- **一靜**：卡片長廊仍位於 Design OS 統一靜態畫框內，遵循同一字體、色彩、尺寸、可設計區與無障礙規範。
- **一動**：滑動、滾動、懸停、鍵盤聚焦、選取卡片時，優先在原畫框內更新主內容，不因一般探索跳到版塊首頁。
- **有目的的進入**：只有明確的「閱讀全文／觀看專項／進入工具」等意圖才導航至具體第二層 URL；不可把卡片選擇默認為跳頁。
- **七個適配**：橄欖山＝講員／系列；天堂電影院＝影片／排片；西望雜誌＝十二個固定編輯欄目／欄目文章；黎明書局＝書籍／出版物；以馬忤斯＝經卷／查經／工具；白晝咖啡館＝每日主題／經文；教會＝聚會／事工／見證（不得取代開門主互動）。
- **共用的是能力，不是強制同形**：可採橫向長廊、編輯式卡片、節奏式切換等，是否使用自動連續移動由內容與可用性決定。
- **動效可用性**：尊重 reduced-motion；懸停及鍵盤聚焦可暫停自動移動；克隆卡片不進入輔助技術或鍵盤順序；手機觸控可操作；不能遮住影片字幕。
- **工程策略**：抽出共用 selector / state / event contract，再讓七個版塊透過內容 adapter 接入；不複製橄欖山整套 CSS／JS，不創建新的 OS。

此節是設計及工程契約，**尚不代表七個版塊已完成互動卡片部署**。

## 全站接入執行規範（2026-10-10）

- **唯一接入範圍**：全站七個 realm（church、magazine、bible、sermon、book、cinema、life）；所有 realm 均採 `data-ws-first-look` 與 `data-ws-first-look-mode` 的共用契約，不另開平行入口系統。
- **單一選取器**：需要卡片選擇的版塊共用 `static/js/westside-one-look-selector.js`。選擇卡片只更新本畫框的對應內容面板，進入具體文章、影片、工具等才導向正式內容 URL；沒有資料權威的版塊不得填假資料。
- **設計權威**：靜態舞台幾何、字體、色彩、動效、響應式與可設計區繼承既有 Design OS；realm 只提供內容與經批准的視覺差異，不再建立一套 realm CSS authority。
- **驗收矩陣**：七個 realm 各檢查桌面／手機、鍵盤／觸控、reduced-motion、內容實際可用、正確直達連結、返回層級及不遮擋；影音另驗證播放器及字幕；教會另驗證開門；雜誌核對十二欄正式資料。
- **部署護欄**：禁止在缺少正式資料或實際播放驗證時宣稱七個 First Look 已完成；CI、PR 合併與正式站驗收分別記錄。


## 首頁與 First Look 的正確關係（2026-10-10 修訂）

- **通則**：First Look 完成時，同時構成該版塊可用的首頁；不要機械地在 First Look 後再建立重複的版塊首頁。
- **影音類先行**：橄欖山與天堂電影院是同一類影片播放型首頁，先驗證共用播放舞台、封面預覽、字幕及內容切換，再將已證實的底層能力交付全站。
- **雜誌特殊例外**：西望雜誌 First Look 的十二張滾動卡片是十二個永久欄目；它與完整雜誌首頁（出版、期號、文章索引）在資訊架構上不等同，須分別承擔不同功能，不能因與橄欖山同為十二卡而歸為同一施工類型。
- **工程決策原則**：共享卡片數量不是工程依賴；以內容形態、技術共性、已存在資產及驗收風險安排階段。每一階段回到全站工程表，避免局部細節替代主線。
- **修正先前衝突**：本文前述「First Look 一律是第一層、版塊首頁一律是第二層」的概括只適用確實需要獨立完整索引的類型，不能強制用於橄欖山、天堂電影院等 First Look 即首頁的版塊。

## 全站視覺品質基準與工具參考（2026-10-10）

- **品質標準**：以 Awwwards、Webby Awards、FWA 等優秀獲獎網站作為品質參照，而非宣稱已獲獎。完工後及每個主要階段持續自檢排版、留白、視覺層級、色彩、動效、微互動、響應式與原創性，直到沒有明顯可提升之處。
- **工具研究池（非依賴清單）**：awesome-design-md、brands-design-md、design-harness-components 用於研究品牌規範與元件治理；polish、quieter 用於發布前視覺精修與節制；GSAP、gsap-skillpack、mist、personal-website-animation、flapkit 用於研究滾動、轉場、沉浸動效；image-to-ui-skill、prototype、black-white-ui-prototyping 用於視覺還原與原型比較。其他截圖列示工具只作候選，不自動安裝。
- **接入原則**：先核對開源授權、實際維護狀態、成本、效能、無障礙與既有 Hugo/JS/CSS 相容性。可直接利用現有功能時不引入新依賴；不為了工具而重建網站，不設第二套 Design OS。
- **品質驗收**：桌面與手機真實截圖、文字不拉伸不重疊、色彩符合全站禁用規則、內容可讀、動效尊重 reduced-motion、互動可用、頁面性能與視覺一致性，均須有實際證據；不能以主觀『獲獎級』替代測試。
