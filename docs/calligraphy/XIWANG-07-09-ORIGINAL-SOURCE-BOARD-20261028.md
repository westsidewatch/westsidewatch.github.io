## 2. 09 流動書風的米芾線索（來源等級 B；**不是已完成的「西望」配對**）

**XW-M01 米芾《吳江舟中詩》卷，約 1095，美國大都會藝術博物館，Object No. 1984.174。**

- [Met 館藏頁及原件公開圖](https://www.metmuseum.org/art/collection/search/39919)：**Public Domain**，作品級來源及作者均可核實，米芾草書，紙本墨跡。
- [單字「西」標為米芾《吳江舟中詩》](https://www.sftj.com/897F/3396118.html)：字典索引提供字的位置線索，但尚待對照 Met 原卷。
- **「望」尚未找到同卷可核實例字**。其他「望」字的米芾署名字典索引（如《快雪堂法帖》《御賜澄清堂》）是**別種傳本／摹刻環境**，不能當成同卷真跡。

**判斷：**米芾具有 09 基準的研究價值，但原頁「望」核實前，不得將「米芾西＋來源不明望」稱為米芾真跡集字。若只找到「西」，先留在 Source Board 的單字區，**不要編造缺字**。

## 3. 同一篇原文但不是同一件書跡：嚴禁混淆

- 蘇軾原卷：**西望夏口，東望武昌**。
- 趙孟頫上列卷／冊：館藏釋文記載 **東望夏口，西望武昌**（與蘇作互易）。
- 蘇軾 1083 親書 ≠ 趙孟頫 1299 卷 ≠ 趙孟頫 1301 冊 ≠ 另一件趙氏冊 ≠ 張照清人臨本。
- 徐州博物館清代摹刻蘇軾《前後赤壁賦》是**摹刻碑版**，不是可用來替代原墨跡的「蘇軾原筆」。若研究碑刻風格，應另列碑帖 source-type。

## 4. 兩種母本的評分規則（只針對字）

| 觀察項目 | 07 基準 | 09 基準 |
| --- | --- | --- |
| 「西」的上橫 | 粗重但可辨識起承，支撐結構 | 一筆發勢，落筆後自然牽引身部 |
| 「西」內白 | 筆畫粗不堵死，重心端正 | 有空間方向、收放與斜勢 |
| 「望」中段 | 結構不鬆散，上下連貫 | 提按真實，線條有往下的行筆 |
| 「望」最後一筆 | 長但有骨，穩住整個雙字 | 舒展但不亂飛，收筆真正完成運動 |
| 縱排兩字關係 | 同一根垂直重心，兩字的黑白份量相承 | 有流動的氣脈但不糾纏，**仍須可讀** |
| 禁止 | 只增加碑刻顆粒；厚得像圖示；用陰影變「高級」 | 筆畫任意變形；飛白空洞；把AI字冒充書家 |

不為了「做滿十二種」而擅自改古人筆畫。沒有原字就保留缺字狀態，沒有實質結體差異就不增新候選。

## 5. 下一個可以實作的 Gate（不是成果宣稱）

1. 從 NPM 的原圖下載、Wikimedia PDF 中，先取得 **蘇軾 XW-S01、趙孟頫 XW-Z02** 的**原幅**，核實圖片權利、像素大小與 hash。
2. 根據館藏的「西望」完整文本，找到**對應的原圖頁／開／區塊**；人工確認「西／望」是同一處連續兩字。
3. 輸出 **原幅局部 → 帶鄰字上下文的原始雙字 → 白底黑字比較**，每幅標明館藏 ID、原作品及複製權利；**只裁切、等比縮放、併排，不重描／補筆／修字**。
4. 蘇／趙對照若通過筆畫、重心、篇幅比例考核，再用現有 Potrace 和 VTracer 做單源向量化實驗。
5. **只有人工批准後**才在西望 10 號 Contents 測試 SVG，不替換受保護資產，不與金線等裝飾混用。
