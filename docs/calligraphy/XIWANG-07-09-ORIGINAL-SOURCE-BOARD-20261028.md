## 4. 兩種母本的評分規則（只針對字）

| 觀察項目 | 07 基準 | 09 基準 |
| --- | --- | --- |
| 「西」的上橫 | 粗重而有骨，支撐結構 | 起筆果決、提按有力，不能細弱漂浮 |
| 「西」內白 | 墨量厚實但不堵死，重心端正 | 墨量仍要足，藉斜勢壓出張力而非靠細線裝巧 |
| 「望」中段 | 結體有承重，上下連貫 | 強勁連接、沉雄行氣；不能細碎、虛飄 |
| 「望」最後一筆 | 長而有骨、力量壓住整個雙字 | 遒勁有壓迫感，氣勢舒展但不賣弄飛白或飄帶 |
| 縱排兩字關係 | 沉穩厚重、黑白份量相承 | 同樣雄渾，但力量沿斜勢推進；仍要可讀且有大字刊名的分量 |
| 禁止 | 只增加碑刻顆粒；厚得像圖示；用陰影變「高級」 | 靈動纖細、飄逸清秀、炫技飛白、筆畫亂飛；把 AI 字冒充書家 |

**一票否決條件：**原字若呈現輕盈、秀逸、疏朗、細線密集、技巧凌駕骨力，即使是真跡、即使來源權威也不入品牌候選。不能只靠加粗、拉伸、飛白濾鏡假造力量。

不為了「做滿十二種」而擅自改古人筆畫。沒有原字就保留缺字狀態，沒有實質結體差異就不增新候選。
