# R186 · 底紋與線的功能區域
使用者確立：底紋、線條有功能區域的區分功用；不是放上就好，而是讓區域變得清晰。第02關，從R185 1d5da20實際評審出發，僅深化首幅至經文與研讀接縫，不重畫原底紋，不改雙印、負方、小章、2q正文寬度或下游內容。原34組刻線、墨量、裁切完整保留。
本輪構成：章節2q保持紙面與寬閱讀；研讀1q承接首幅B正形的既有淡金19%色面，從原B底部的刻線起點(1+offset,3)沿接縫轉向實際研讀左邊界x=2q，34組線在接縫疏密過渡、6組主線沿區域邊延續，長度隨研讀實際高度決定，非懸空裝飾。線與底紋共同界定經文、研讀；新增線位於頭部留白與研讀左側安全帶，留白負方即時貼不改。手機保持原閱讀流，仍待獨立藝術深化。此處為候選，不新增卡片、工具或正式網站功能。
多雷輔助（本輪實查原始案例）：Pentagram https://www.pentagram.com/news/philbrook-museum-of-art 說明磚形模組如何組織網站各區與導航；Experimental Jetset https://www.jetset.nl/archive/the-whitney-tapes 說明作品及文字可限制識別線的範圍。轉譯：幾何應使功能區域可辨識，線的起止由實際內容決定；不是任意增加線條。公開案例研究，未運行獨立多雷引擎。
驗收：同一頁有/無延伸線對照、原紋源碼及裁切不變、2q正文和1q研讀共邊、線延伸至實際區域終點且不侵入文字；實際截圖評審是否讓區域更清晰並有獨特藝術性。其他史地、時間軸、串珠及索引將依同一原則分階段深化，不聲稱已完成。母印、地圖、實際多寫與全章仍未解，未完成本輪實際評審不進03。
