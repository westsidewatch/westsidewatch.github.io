第02關；承接R177使用者方向肯定。R177瀏覽器實測見上一輪文檔。首幅雙方、q、425px印面、中央負方即時貼不改，保留候選底紋對照。唯一主要目標：讓下半部的共同方邊有內容關係，不再只靠對齊與獨立短線。
## 本輪實作
1. 章節選讀沿左q，章故事沿中q，神學定位及四研讀問題沿右q；研讀刊頭跨後兩方，使用原資料而非空卡片。更正選讀座標順序。 
2. 六段時間軸維持折返，四組四福音合參分別依經節接入事件1、2、4、6；不新增未有來源的合參。事件2與5的共同中軸為重點，取消無直接閱讀作用的浮動接縫線。
3. 背景四項按內容拆成兩個有關聯的場：復活日及以馬忤斯與原圖和八條圖說相鄰；摩西先知詩篇、從耶路撒冷到萬邦與四串珠共用構圖場。沒有刪原資料。原圖111仍失敗，不用虛假地圖替代。
4. 66卷索引、原配圖、兩原經文印面、原章、P2、OS、其他六版保持不變。仍非全章閱讀器或已接通多寫。
