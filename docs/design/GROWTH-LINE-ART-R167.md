# R167 · The Engraved Edge / 刻線的藝術深化

承接使用者確立的成長線規則（R166）。R166 Chromium 技術通過，但真實 1440px 截圖顯示 03/05/06/07 候選刻線穿越刊頭、閱讀正文與書封；形態仍太接近放大小章。本輪不採納 R166 材質為正式母本。保留其幾何來源與歷史校樣，先針對未定稿的03/05做藝術修正。

- 03 以馬忤斯 E1/E2：原來兩個等大方形的邊緣做精細平行偏移，逐刀形成方角與粗細節奏；兩側相對180度，32單位共同負方保持空白。圓角只限刻刀轉折，非新圖形母語。
- 05 黎明書局 B1/B2：64單位前後方、24單位投影深度，取上折面與右折面。刻線沿相應方邊延伸，微曲率研究承接現有開卷鉛印母本的頁緣曲線，非引用外部圖形。正面仍為閱讀留白。
- 真實圖文對照：新增候選層，預設原稿。每個SVG有幾何遮罩和真實閱讀區遮罩（根據實際內容元素的矩形及1.6單位退讓，逆投影到SVG座標）。未著墨區不以紙色實塊覆蓋。響應式更新。原版與細印、密印、三種墨量、隱去印記對照。
- 細節：候選狀態的以馬忤斯閱讀邊與書局中縫沿原有軸線，以1px及22%光學墨量校樣；書局三個目錄項改用共邊分隔研究，去掉普通彩色UI式標籤，不改文字。手機不強行加垂直分隔線。原稿保持。
- 字體、圖片、經文、版塊入口、城垛及原有其餘五版塊全保留；06/07維持R154，不以此輪重新設計。沒有假定任意新字體、返回鍵或全站線寬定稿。
