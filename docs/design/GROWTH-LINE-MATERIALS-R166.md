# R166 · 成長線：從構形、印刷到全站元素的生成規則

2026-11-27 使用者確立：所有元素，包括底紋的形態、用量、位置、構成、變化，字體運用、排版位置、圖片裁切、導航返回及任一短線的粗細位置，都應可追溯本輪成長線。不是把方形或印章印到每個位置，而是每個元素的幾何、功能、閱讀層級有理由。從新天新地雙方、教會套嵌與新耶路撒冷、光照教會七步推導。經文、內容與可用性仍優先；不把幾何誤作神學固定位置、配色或正文變形。依手冊9.6、9.10–9.20；保留歷史原稿，須藝術評審才進 OS。

## 材質的生成

底紋 = 方形構成的允許區（遮罩） × 刻線方向（原邊、折線、光向） × 線寬、間距、墨量（光學層級） × 內容禁入區。四個值都需來源。校樣百分比是 120×120 平面的幾何允許區，不是實際墨像素占比，不是正式頁面通用配額。三種疏、中、重印是研究樣本而非新 OS token。原有 SVG 與 P2 資料不得覆寫。

### 01 活水堂西區 · 套嵌 / A06 / I01
- 生成：外方與內方套嵌成為水流的兩側與天井；原有分流刻線不重畫。
- 位置：外方四周；天井絕對留白；56.3%（構成容許區）。
- 墨量：0.24 / 0.48 / 0.76；原刻線粗細不變。
- 內容禁入／用途：只在外圍或開紅海構圖兩側；中央建築、經文及禮拜文字不被紋理侵入。
- 字體：重字標立於外方；細字及日程落在清晰天井
- 裁切：白模完整保留；不切十字架、屋頂或天井
- 細節：取外方與天井的共軸邊，形成短線和入口定位
- 母本狀態：protected_reference；/experiments/assets/living-water-contour-engraving-v10.svg。

### 02 西望 · 橫向 / A01 / P01
- 生成：橫向雙方成為編輯雙頁；紙地本身就是留白，版線來自兩個底邊及中縫。
- 位置：兩方下緣及中縫（不是底紋）；0% 固定底紋。
- 墨量：0.25 / 0.5 / 0.75；分欄細線為原方邊；不另加裝飾星野。
- 內容禁入／用途：不做全刊固定底紋；依內容選圖，局部印刷線只服務分欄、引文或頁碼。
- 字體：英文刊頭與中文副題沿同一橫軸，信章保持獨立
- 裁切：兩張主圖各使用方形窗口，必要時保留原畫幅
- 細節：兩段50單位線與4單位方間距，導出雙頁節拍
- 母本狀態：no_fixed_texture；無固定材質。

### 03 以馬忤斯 · 交織 / P02 / P03
- 生成：由原方的邊折返，兩族刻線以共同方窗分隔；這是交織的材質裁切，並非再次描畫完整交織小章。
- 位置：左上、右下交織場；中央32×32方窗空白；42.7%（構成容許區）。
- 墨量：0.18 / 0.35 / 0.58；近折角粗、遠端細；兩組線重不同但原方等大。
- 內容禁入／用途：刻線以兩側書頁的外緣進入，正文及共同方窗保留純紙；不是滿版經緯網。
- 字體：書卷與章次沿原方邊；中英經文印面正立
- 裁切：圖版與地圖佔另一方；重要地名不裁切
- 細節：交點前後順序決定線段中斷；返回原閱讀位置不加箭頭
- 母本狀態：new_candidate；materials/r127/324943.svg。

### 04 橄欖山 · 縱向 / A02 / P04
- 生成：縱向上下雙方形成高差與山勢；保留原有連續等高線的相位，非兩張重複貼圖。
- 位置：縱向兩場同一底圖；中縫不填墨；37.6%（構成容許區）。
- 墨量：0.22 / 0.45 / 0.76；沿用原地形粗細、曲率。
- 內容禁入／用途：上下連續裁切，人物與講道經文有清晰安全區；不改已確認的卡背或P2地形。
- 字體：講員名稱、題名與經文沿縱軸；不壓人物
- 裁切：人像面部不裁切；地形連續而非卡片重置
- 細節：上下方邊形成垂直閱讀節奏與欄目節拍
- 母本狀態：protected_reference；/images/p2-realms/v15/04-olive-terrain-continuous-mother-v76.svg。

### 05 黎明書局 · 立體 / V02 / V05
- 生成：由前後等大原方的對應邊產生上折面、側折面；刻線像書頁的層疊，不另畫無關花紋。
- 位置：上與右兩個派生面；正面留空；21.3%（構成容許區）。
- 墨量：0.18 / 0.38 / 0.62；折邊主線與內頁細線同向；層間不等密。
- 內容禁入／用途：只在書脊、上沿、側沿及版芯外緣；正視方留給完整書封、同冊圖版、經文。
- 字體：書名與作者維持正立，折面只決定錨點
- 裁切：書封原比例 contain，不切文字
- 細節：由折角生成版芯細線、書脊及目錄分段
- 母本狀態：new_candidate；/images/p2-dawn-letterpress-engraving-v1.svg。

### 06 白晝咖啡館 · 受光 / L01
- 生成：兩個平面光域共用未著墨方形；墨量隨離共同光域的距離變化。
- 位置：兩方外緣，中央共同方窗留白；42.7%（構成容許區）。
- 墨量：0.12 / 0.26 / 0.42；向光窗靠近線更細且間隔更疏。
- 內容禁入／用途：只在光域外緣；大留白供日常生活文字。R154 原藝術不替換。
- 字體：生活正文細字以純紙承載；大英文不壓入光窗
- 裁切：圖像按內容裁切，中央光域不放裝飾
- 細節：受光邊緣以稀疏線點提示；不替代日曆控制
- 母本狀態：study_only_R154_locked；materials/r127/256145.svg。

### 07 天堂電影院 · 投影 / L02 / L03
- 生成：由光向位移生成承影輪廓，再扣去共同方形。沿投影方向以半色調及刻線表達墨影。
- 位置：承影場；共同方窗不著墨；52.4%（構成容許區）。
- 墨量：0.18 / 0.38 / 0.65；投影方向等距刻線，遠端逐步減墨。
- 內容禁入／用途：只在銀幕外的承影場與幕帳邊緣；影片16:9及字幕全部不著紋。R154 原藝術不替換。
- 字體：片名及字幕位於乾淨區域，避免在紋上小字
- 裁切：影片與海報原畫幅優先；不把影片強切為方
- 細節：光影的邊決定幕緣短線；返回和播放功能分離
- 母本狀態：study_only_R154_locked；materials/r127/324077.svg。

## 每個設計元素的可追溯記錄（下一輪落地必填）

| 元素 | 幾何依據 | 視覺／功能理由 | 驗收 |
|---|---|---|---|
| 刊頭、英中標題 | 原方邊、共軸、折面落位 | OS 大英文小中文及字重角色不變；以內容階層決定重心 | font-family/weight 與原 OS 一致；無單字孤立回行 |
| 兩方經文 | 原方錨點及展開 | 大構圖主導，不放大小章；保持真方與原始母版 | 方形、正立、無遮擋；原 V18 分行仍待驗收 |
| 正文、圖說 | 負空間及讀序 | 紙地承載閱讀，刻線退讓 | 對比、行長、手機完整閱讀 |
| 圖片裁切 | 方形或投影邊界 | 内容優先；人物臉、書封、地圖地名、影片畫幅不可破壞 | 實際內容人工比對，必要時 contain |
| 小章 | 已批准識別母本 | 無字可辨，獨立身份；不是普通功能 icon | 同紙同墨、24/32/48/64 陰陽印、無標誌對照 |
| 城垛 | 原有不等寬節奏、方角轉折 | 選擇性目的地提示或版緣收束 | 保留原章、節奏；不加永久大牆 |

| 短線 | 原方邊的具體起終點；折線或光向 | 分欄、印刷收邊、圖文關聯、導向；無功能／無母形來源則刪除候選 | parent ID、起終座標、線寬／間距、光學作用；不能任意固定一條全局線寬 |
