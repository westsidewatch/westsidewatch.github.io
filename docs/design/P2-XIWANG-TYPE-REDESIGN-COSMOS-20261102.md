## 1｜本輪新增的視覺語法，而不是傳統書法與現代字體二選一

12 張截圖反覆出現下列成熟手法，目標是理解「兩個字如何成為版面」，不是將其中的海報照搬：

- **字骨當作版心與建築：** 大字近乎承擔整張海報的版面骨架；不是貼在圖片上的小 Logo。
- **字內留白與讀序：** 黏連、交錯、切面、斷續的負空間，讓厚畫仍能認出原字；「字內白」的重要性與黑筆畫相同。
- **視覺質量不依賴等線加粗：** 筆畫局部凝結、局部收束；粗細、傾向和承重有設計，而不是整字一味加粗。
- **單字作為圖像，微字作為索引：** 極大兩字與極細英文 folio、晨星金線、Contents 形成階層；小字不與刊名爭主角。
- **疊印是印刷結構，而非無意義濾鏡：** 可辨的套印位置／印版相位／底墨與面墨關係，不用 7 個字影假裝七層重疊。
- **動效來自字的組織方式：** 形體的揭示、錯版的校準、筆畫負空間的打開，最後停留畫面本身仍需成立。

## 3｜三條具體新字形方向（排序與取捨）

### A｜「筆骨・活字」 / INK-BONE LETTERPRESS — **第一優先，建議實作**

**目的：**把張即之真實大字的筋骨和當代漢字海報的結構設計合成一個有生命的**原創字標**，不是替原本的水墨掃描貼上科技特效。

- **字骨：**沿 07「方闊、有承重的結體」與 09「沉雄、真實提按」雙線重新設計每一筆的落點／重心／內白。新「西」上橫作真正的視覺樑，四周不封死；新「望」上中下分區要能一眼串成一字，最下方主筆承重，尾筆保留短而有力的收束。
- **筆畫：**只在轉折和鋒端加入來源可解釋的墨肉、濃淡與**自然飛白**；當前母本有價值的濕潤筆觸應保留作參考。禁止隨機雜訊、合成墨裂、均勻機械粗黑、硬擠成仿宋體／篆隸。
- **負形：**重新調整「西」字腹的空間及「望」字上半部的擠壓關係；以 22.02.33／22.02.50／22.02.59 的當代字形研究校準，字的**內白是結構，不是亂挖洞**。
- **兩字合體：**仍為上「西」下「望」，兩字視覺黑量與垂直重心要連成一組印版；可有輕微非對稱或局部筆勢銜接，但**不能把兩字拼成不可讀的單一符號**。
- **空間層次：**一層深墨主印、一層**極輕微**黎明金 registration；輪廓、凹處、筆觸的轉折已先能單色成立，才允許有限 1–2px 視覺套印。不能以七個相同字影敷衍七層重疊。
- **動效：**不重新發明進場：晨星照亮上方第一處金色刻痕→墨字順勢從原有位置顯現→主印與套印由微錯位校正到印版吻合→左頁留出 Contents 編輯空間。滾動逆向可以完整倒帶。字型本體停留時不變形、不震盪。

**初選理由：**同時接收這批海報真正的**大形體、字內留白、當代套印**，又符合 2026-10-28 已批准的「真匾額大字、張即之、雄渾、有墨肉」約束。這是**字形重設**，不是舊 SVG 重新調顏色。

### B｜「反白字骨」 / CUT-COUNTER — **真正有設計感的備選**

**目的：**朝 22.02.41／22.02.50／22.02.54 的幾何漢字設計再推進，把大字轉化為黑白正負形的精準對位。

- 在 A 的正常筆法骨架之上**重畫字內白**，讓一部分大筆畫借雕版負形而非薄輪廓分出。
- 選擇性做局部平行切面或中段透氣孔，但每處都必須對應**真正筆畫的受力／轉折**；不得任意「圖案化」。
- 與多雷原版畫直接建立關係：白洞或深墨筆畫對位原有刻線，**不使用另一張效果圖，也不遮住多雷主要敘事人物**。
- **主要風險：**如果被做成科技字模或直線黑體，就失去「西望」過去確立的書寫根源；與 A 並行做一個可讀性的對照候選，不作既定主案。

### C｜「墨勢重疊」 / CALLIGRAPHIC PHASE — **09 強動勢對照案**

**目的：**保留原來的書寫速度、真實墨跡和氣勢，讓受控的七段進程由不同筆段／負空間揭示，而不是把七色直接刷上兩字。

- 兩字均保持巨字筋骨，在 09 路線強化上下主筆和斜勢，但**不成亂草、不纖細、不拖長炫技尾巴**。
- 將新原生 SVG 拆成若干具有筆順和設計意義的區段（**不是按顏色分七個副本**），與晨星的升起及 Contents 的出現同步。
- 七層重疊沿 P2 既有的核心視覺機制表達為**墨線與印版的累積／錯位校準**，不是全套七色貼花。
- **風險：**可能與當前 v02 過於接近；若靜止畫面還只是較濕潤的書法字，沒有清楚的**重排字內白與雙字重量**，判作未成功變更而非新版本。

## 4｜交付不是「12 種濾鏡」，而是可比較的原創字稿

下一輪按先前已確立的古匾研究序列，**新方案只做 3 個母方向，先集中到 A**；每個方向若通過基本字法，可沿 A–D（大楷→有行意大楷→大行書→可讀大行草）等級作小批差異版本，**不是把 12 張截圖硬仿成 12 種造型**。

**每個進一步候選必須提供：**

1. **黑字／白底**、無特效、無背景的「西」「望」兩個繁體字，明確看到筆起、轉折、字內白與承重；以 288×454 先做與舊字可量測的比例對比。
2. **黑底／白字反轉**檢視重心、筆畫狹窄處堵塞與飛白邊界。
3. **P2 真實雙頁合成**：左原多雷城市滾動（原圖不動）、晨星原件、左下兩字、右側既定雜誌封面；至少正常版與 Contents 最終版，不是單張海報或孤立的 SVG 截圖。
4. **動態簡譜**：沿既有 scroll progress 接入「星光→墨／字→印版校準→目錄」，反滾同一路徑；\`prefers-reduced-motion\` 靜止時仍保留完整二字。
5. **完整原生 SVG 路徑**，獨立 \`xi\`／\`wang\` glyph groups、可獨立維護的 ink／registration／engraving 資產，保留真實的曲線拓撲，不能把圖變成文字貼圖或依賴雲端字體服務。
6. **未經人工通過，不替換現有母本或正式刊頭**；不因臨時驗收圖看起來大氣就覆蓋現有產品資產。

## 6｜得獎級藝術驗收：實際檢查，不是宣稱

**核心拒絕項（任一項不過即退回）：**

- **遠讀 3 秒：**不看提示能立刻辨「西望」，而不是書法練習／科技漢字／不明兩字。
- **字骨承重：**「西」頂部和「望」最下方有真實大字氣魄，筆畫交匯處不鬆垮，也不變機械粗黑。
- **黑白光學校準：**兩字黑量相稱，中央空隙和字內白有節奏，縮至左下時仍保留可見的筆勢。
- **現代化是結構性的：**相對 MOTHER v02 至少能說明**三個可見、具體的字形改善**（內白、重心、收筆、兩字合體），而不只顏色、描邊、陰影或字號。
- **場景合成：**晨星與西望是一組有因果的視覺，不互相遮擋；多雷原作版畫、右側刊頭與 Contents 都仍然有主次。
- **動效實際驗收：**desktop 1648×928、768px、390px、320px；正反 scroll、滾動速度、鍵盤、reduced-motion、Safari/Chromium 的 SVG mask，沒有被裁切、延伸或破壞七重疊。
- **輕重對照：**只有大字／正文使用必需重量；細字仍用 OS 極細角色，主標之外的小信息**不能**變粗。
- **來源與權利：**每個歷史筆法研究和外部海報案例標明「研究來源」與「可重用資產」的不同；不假稱「現成開源字型」；禁止導出用戶上傳圖片作主站資產。

**決策：**本輪批准的是**下一輪設計／施工方向 A「筆骨・活字」**，B 和 C 為保留對照；**並非已批准任何字形圖稿、已完成替換、獲獎級最終驗收或上線**。新樣稿只能在 P2 Draft 的 isolated preview 供人眼比較，待人工審視後再選真正的 Vector Master。
