# Emergence / Italian Editorial DNA

Status: research-driven design subproject
Surface: Doré Design only (not main-site navigation)
Parent capability: `publishing.dimensional-writing`
Parent design idea: **浮現 / Emergence**

## Purpose

Turn research on Italian magazine history, editorial design, photography, typography, spatial grammar, cover systems and visual irony into immediately usable image-generation direction.

This is **not** an `italian-magazine-style.css` preset and not a museum archive. The unit of use is an editorial visual grammar that can be selected by a person or invoked by Doré.

Primary loop:

`research → editorial grammar → prompt recipe → cover visual → evaluation → refined grammar → Doré reuse`

A user should eventually be able to provide any source image, choose an editorial family, and obtain a cover treatment through a corresponding prompt recipe without copying a publication logo or reproducing a historical cover one-for-one.

## Initial DNA from the previous research round

1. **Progetto** — editor, writer, photographer, graphic designer and architect participate in the same act of construction.
2. **Structure before freedom** — a stable order gives deviation semantic force.
3. **Content generates form** — subject ontology should generate layout instead of content being poured into a template.
4. **Density has semantics** — size, repetition, proximity and crowding can carry argument.
5. **Contrast creates thought** — adjacent pages / states can create a third meaning.
6. **Irony without explanation** — visual sequence and layout can complete a judgement that prose should not over-explain.
7. **Rhythm over consistency** — editorial identity is continuity of intelligence, not identical pages.
8. **Spatial language → temporal language** — paper gives page / spread / sequence / turn; Emergence adds state / persistence / accumulation / disappearance / return.

Working axiom:

> Text writes in language. Layout writes in space. Emergence writes in time.

## Initial editorial families

The first atlas seeds six research families rather than six immutable styles:

- Domus / Gio Ponti — architectural object as editorial world
- Domus / Italo Lupi — rigor, clarity, collage, scale shift and visual irony
- Ottagono / Unimark — modular grid, industrial precision, disciplined asymmetry
- Abitare — inhabited space, photography, domestic scale and cultural journey
- Casabella — architectural criticism, typographic authority, analytical restraint
- IL / Intelligence in Lifestyle — modular information density, illustration, diagrams and contemporary editorial studio logic

These are research labels. Prompts must describe transferable visual grammar rather than request exact logos, mastheads, copyrighted layouts or one-to-one cover replicas.
