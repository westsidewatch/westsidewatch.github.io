# Campo Grafico 1933 — Issue Ledger / Pass 01

Status: ACTIVE RESEARCH
Parent: `publishing.dimensional-writing`
Purpose: train Doré aesthetic judgement and full magazine-layout capability, not a Campo Grafico imitation style.

## Canonical research rule

Each issue is treated as an editorial experiment. Extraction unit:

`issue -> editorial problem -> cover -> spread/layout -> image -> typography -> material/production -> sequence -> transferable grammar -> emergence translation -> evidence confidence`

A grammar enters the Atlas only when it is transferable beyond the historical artifact. Surface resemblance, copied mastheads and period cosplay are failures.

## Year I grammars promoted from Pass 01

1. `publication-as-workshop` — a magazine can expose how visual culture is made.
2. `cover-as-threshold-object` — cover is not a thumbnail; it changes the state of entry.
3. `foreign-object-insertion` — external artifacts may preserve local visual identity inside the issue.
4. `attached-evidence` — specimen/invitation/postcard/document can function as evidence, not illustration.
5. `layout-as-editorial-subject` — layout itself may become part of the publication's argument.
6. `production-knowledge-as-editorial-content` — type, machines, foundries, inks, paper and reproduction are legitimate narrative dimensions.
7. `distributed-production-as-editorial-ecology` — editorial identity can coordinate multiple specialist makers rather than flatten them into one house style.

## Doré capability consequence

This corpus is not being built as a historical mood board. It trains three coupled judgements:

- **Aesthetic Judge** — why a visual relation is right or wrong for this content.
- **Editorial Spatial Composer** — how image, type, evidence, blank space, insert, sequence and material relation write meaning.
- **Temporal Translator / Emergence** — how print operations such as flap, insert, attachment, interruption, persistence and return become meaningful digital states without turning into generic animation.

Target capability chain:

`content ontology -> editorial judgement -> spatial grammar -> material grammar -> sequence grammar -> temporal grammar -> issue-specific design`

The final objective is full magazine design: cover, article opener, spread, long-form pacing, image field, captions, sidebars, inserts, transitions, issue rhythm, ending and production/export — all generated from editorial meaning rather than a fixed template.
