# P1 Light Comparison — mature references only

P1 applies four existing live motion references over the same Living Water Candidate 04 second-page base. It does not invent a fifth production effect.

- A — Martin Renou, ThreeJS Caustics: https://martinrenou.github.io/threejs-caustics/
- B — Codrops / Lucas Bebber, Rain & Water Effect: https://tympanus.net/Development/RainEffect/
- C — Ameobea, three-good-godrays (pmndrs postprocessing): https://three-good-godrays.ameo.design/
- D — React Bits, LightRays: https://www.reactbits.dev/backgrounds/light-rays

The third-party live runtimes exist only inside Motion Lab P1. Living Water Candidate 04 production remains dependency-free until a direction is selected.
