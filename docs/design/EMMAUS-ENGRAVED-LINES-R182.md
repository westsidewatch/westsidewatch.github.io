# R182 · 以馬忤斯線與底紋的共同構成
第02關。使用者兩次修正：輔助線應使交織母形可見；各版塊裝飾線須因底紋而異；不是因線取消底紋，而是線與底紋配合。R181原稿保留。兩個2q方相錯q，交集負方承接即時貼，交叉處交替斷開；A單刻線、B雙刻線、C疏密刻線三個候選，不是單純增減不透明度。底紋以V5既有雕版候選的變化線距、墨量、疏密為參照，沿同一方邊生成12組細刻線，與構成主線共存，獨立切換。原V5與上一輪刻線保留為對照；取消底紋只供觀察，絕非默認或交付方向。原經文、章、P2底紋、內容、OS均不改。版面文字與插圖內部僅作必要避讓，中央交集無填墨；不以空白色塊遮蓋。底紋未定稿。
多雷輔助：實查 Experimental Jetset https://www.jetset.nl/archive/the-whitney-tapes （線與圖文共同界定餘空），Met https://www.metmuseum.org/es/perspectives/materials-and-techniques-printmaking-engraving （雕版以疏密刻線產生色調）。公開案例與工藝研究，未運行獨立多雷引擎。評審須比較同一版面四種線狀態且底紋保留、B配原V5/無底紋對照、可辨識交織、內容優先及線紋共存。既有母印valid、原圖111、功能接入未解。未驗收不進03。
