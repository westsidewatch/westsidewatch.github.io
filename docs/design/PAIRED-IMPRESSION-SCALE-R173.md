# R173 · 橫向雙印的尺度與版心重力
Gate 01–02, R172 基準 236d472. 本輪只研究西望一項藝術問題，不試圖完成全站。七版塊連續性須回到 R172 整體比較，其餘六域不改；R154、原章、原經文、原海報及 OS 不變。
多雷輔助：Pentagram MoMA https://www.pentagram.com/work/moma （尺度、慎重裁切和固定格網形成強烈主次）；MoMA 設計總監 https://www.moma.org/explore/inside_out/2013/04/08/one-typeface-fits-all-at-moma/ （固定字體也可形成豐富設計）；Josef Müller-Brockmann 訪談 https://www.eyemagazine.com/feature/article/reputations-josef-muller-brockmann （格網使內容有秩序，非任意分割）。轉譯為同內容同OS的三種印面尺度，其他元素沿方形邊緣重排。公開案例查證，未直接運行獨立多雷引擎。
A 4.5單位，佔25.31%，保留R172 A方向並修正原標題/文字分配框重疊；B 5.5，佔37.81%，印面成主體且封面仍有獨立展示區；C 6.5，佔52.81%，雙印幾乎佔滿下方版心，封面收縮至卷首。三案皆完整原印面，未修改原經文或圖形，色字規範相同。面積不等於藝術品質；C可能使封面失去編輯身份，B可能較均衡，須真實截圖評審才可選擇。
驗收：固定8:5研究畫布，逐對檢查分配框無碰撞；真實兩印方形及目標尺度、字片載入、字級/字重/字體紀錄、封面及章圖載入、溢出；實際Chromium原版與ABC校樣，必要時退回修正。原V18仍未批准，不能宣稱正式印刷驗收；不新增全局規則。藝術目標：大章主導而不犧牲刊頭、封面及閱讀，形成後續可比較的尺度依據。未達目標不可進下一關。
