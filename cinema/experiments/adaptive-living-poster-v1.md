# Adaptive Living Poster v1 — JESUS

Status: experiment
Canonical resource: `cinema:video:jesus-film:jesus`

This experiment tests Doré UI state continuity on the existing Holy Light Cinema resource.

States: `settle -> focus -> expand`.

The same canonical resource progressively reveals editorial metadata and a small chapter preview. The current Jesus Film Project source remains an official-source handoff, so this experiment does not copy provider media. The watch action opens the verified official source.

Acceptance:
- canonical resource id remains unchanged;
- no second video database is introduced;
- settle/focus/expand works without page navigation;
- reduced-motion is respected;
- mobile collapses to one column;
- existing collection and VideoMoment search remain available.
