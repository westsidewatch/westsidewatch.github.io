# Dimensional Writing Growth Acceptance v0

This cut turns `publishing.dimensional-writing` from a static plan seed into a capability that can accumulate editorial judgment from real manuscripts.

## Growth loop

`understand -> find-center -> detect-gaps -> choose-dimensions -> excavate -> make-perceptible -> propose -> judge -> return -> reread`

The author manuscript and thesis remain authority. The loop may propose deepening, but it may not silently rewrite thesis.

## Hard judge gates

A proposal is not admitted unless it explicitly passes all six gates:

- thesis preserved
- author voice preserved
- dimension earns a return line
- evidence supports the claim
- media participates in the argument
- reader burden is not increased

Passing the Core judge still does not equal author acceptance. Author approval remains required.

## Editorial growth data

Every author decision is append-only growth data with:

- original text
- Doré proposal
- accept / reject / revise / defer
- reason
- author revision
- thesis relation
- source basis
- context

This is the substrate for the future Westside Editorial Preference Dataset. It is not yet model fine-tuning data by default.

## First living corpus

Vol.01 `The Shadow of the Cross` is the first live corpus. Vol.00 and Vol.02 must later challenge and generalize the same capability rather than introduce per-book exceptions.

## Next acceptance cut

Wire the loop into the existing `publishing.dimensional-writing` capability dispatcher so a real manuscript compile can emit proposals, judgments and ledger-ready decision records while preserving the existing Dimensional Publication Plan contract.
